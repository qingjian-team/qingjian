# 简词键盘 Android 实验版

基于青简 Core 的 Android 26 键全拼输入法原型，支持 Android 8.0 及以上 ARM64 手机。中文候选旁显示一种英语译词；提供英文直输、符号页、深色键盘和系统输入法切换。

这是非官方实验版，名称为「简词键盘」，不使用上游 logo。没有云联想、神经模型、桌面统计页及共享主题设置。显示面暂用 Android Canvas，尚未接入共享渲染器；此原型用于讨论 Android 平台接入方向。
