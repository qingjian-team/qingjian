# 字级 Transformer 重打分：评测（2026-09-08）

## 做了什么

- 训练：训练仓库 `../train`（私有，与本仓库并列放在 `~/Github/Projects/qingjian/` 下）在中文维基完整 dump + LCCC（12.7 亿 token、字表 19147）上训了两档字级 decoder：
  small 23M（ppl 21.7）、base 36M / 上下文 256（ppl 19.2），4090 上各约一小时。
- 推理：`crates/qingjian-neural`（candle），与训练脚本的 Python 打分对拍一致。M1 上 Metal 后端最快：空前文单条 6 ms，
  64 字前文 × 8 条 133 ms；CPU（Accelerate）约慢一倍，candle 自带 gemm 再慢一倍。按 token 算吞吐很低，是每层十几个小算子的调度开销在主导。
- 接法：Core `sentence::convert_paths` 出 Viterbi 前 6 条路径，`Engine` 按 `路径分 + λ·(神经分 − 静态二元分)` 重排，
  神经分只替换静态二元的判断，个人 n-gram、用户加分、敲错代价原样保留（早先试过 `(1 − λ)·路径分 + λ·神经分` 的线性混分，
  λ 0.5 时个人计数被稀释得厉害）。前文是本会话最近上屏的 64 个字符。只有 CLI `--neural` 接它。

## 明细说明回放这把尺子在整句上量不准

最好的一档（静态 λ 0.25 前文 64）逐条对账：变差 43 条、变好 45 条。变差里一大批是**模型对、日志错**：
`shurukuang` 日志选了 输入狂、模型给 输入框；`tiaoshi` 条是 → 调试；`gengkuai` 更会 → 更快；`jiaohu` 叫和 → 交互；

误选也照记，所以基线在整句上天然占便宜。真正模型错的：我的 → 沃德 ×4（云端学来的错读音用户词），资料 → 字了，才对 → 猜对。
变好的是 候选框 ×4、我之前 ×2、实际 ×2、不显示 ×2、增量、实现、下载、本地、目录、资源库、重写、进度 这类实词。

## 进壳（2026-09-08 晚）

1. **前文 KV 缓存**（`qingjian-neural::PrefixCache`）：前文在一次组句里不变，每层的 K / V 算一次存下来；每条候选只算「前文最后一个 token + 候选」这一小段，
   前文缓存部分不含最后一个 token，它的输出分布正好给候选第一个字用。Metal 上 64 字前文 × 8 条 133 → 28 ms，空前文 8 条 20 ms；
   剩下的是每层十几个小算子的调度开销，CPU（candle gemm）同样的活要 73 ms，还是 Metal。与 Python 对拍不变。
2. **Core 异步重排**（`engine/rescoring/`）：一次查询里整句转换会跑好几遍（纠错变体、中英混输比分），所有路径文本进一张「前文 + 文本 → 神经分」缓存；
   同步打分器当场补分（评测每句 69 → 27 ms），异步的先记下缺分的文本，壳停键后 `request_rescoring` 一次送后台线程（几条攒一批），
   `poll_rescoring` 收到后再 `query` 一次就全在缓存里。CLI `--neural-async` 走同一条路，300 句上与同步结果逐句一致。
3. **壳**：模型随包 `Resources/model/`（56 MB fp16），后台线程加载 + 预热后接上；每键先读应用光标前 64 字当前文（应用给不出退回本会话历史），
   停键 80 ms 请求、20 ms 轮询，结果到了只重画当前页，翻过页或动过高亮不打扰。`[model] enabled` 开关在「云服务」页。
   TextEdit 端到端：`houxuanshengcheng` 候选声称 → 候选生成，`shururizhi` 输入日至 → 输入日志。

## 结论与下一步

模型有信息、接法成立，**在不带日志偏差的尺子上过了「整句 +2 个点」的门槛**（+4.3）。回放上看到的「整句变差」是尺子的问题。下一步按顺序：

1. 延迟已解决到能进壳（上一节）；再往下是算子合并或量化，以及模型后台加载的 12 秒（首次 Metal 编译）。
2. 应用上下文已接：IMK 的 surrounding text 当前文，评测集里的「上文」就是它的模拟。
3. 数据：语料里没有技术文本，`输入框`、`候选框`、`全绿`、`服务商` 这类词靠个人微调补；闲时训练那一步才是「越用越像自己」的来源。
4. λ 缺省已从 0.25 提到 0.5（0.75 最高但与 0.5 只差 0.3 个点，留点余量给个人 n-gram）。
5. 发版：数据包要带模型，权重许可另定。
