# 神经 P2C 的延迟 spike（2026-09-20）

## 为什么先量这个

考虑把架构从「词库召回 + n-gram 排序 + 神经重排」换成「带噪拼音 → 神经 P2C 直接生成汉字候选」，
词库降级为专名 / 用户词 / fallback。换不换的第一道门槛不是准确率而是延迟：

重排慢了只是候选顺序晚一点变，候选本身一直在；**P2C 当主候选，候选的存在本身就依赖模型**，模型慢了就没候选。
而且拼音前缀每敲一键就变，整句要重解码一次。所以先量清楚一次重解码要多久，赢不了这一关，准确率再高也进不了壳。

## 怎么量的

`crates/qingjian-neural/examples/p2c_bench.rs`。拿现有的字级模型（现位于 `data/models/hanzhang-zhiwei`，full-small 23M，字表 19147，上下文 128）
当代理，跑真正的 beam search：前文进 KV 缓存，逐字推进，每步把 `beam × vocab` 个延长取回 CPU 挑 top-k，再按 beam 顺序重排缓存。

**偏差说明**：现有模型不带拼音条件，P2C 真模型会多一路拼音编码。但每键增量那一档（下表）说明拼音前缀是可缓存的、成本可以忽略，
解码的成本主导项——beam 条并成一批逐字推进的前向——与条件从哪来无关，所以量级成立。真模型若改层数 / 宽度，按比例缩放即可。

环境：M1 mac，`--features metal` 为 Apple GPU（f16），不带 feature 为 CPU（candle 自带 gemm，f32）。
Windows 端是 CPU 推理，参考 CPU 那一列。每档热身 3 次、取 10 到 30 次的中位数与 p95。

## 成本拆解（前文 64 字，中位数）

| | beam 4 / 8 字 | beam 8 / 16 字 | beam 8 / 24 字 |
|---|---|---|---|
| Metal：只前向 | 56.8 | 145.9 | 221.6 |
| Metal：+ 取回 CPU | 61.4 | 160.5 | 245.4 |
| Metal：完整（挑 top-k + 重排缓存） | 74.9 | 222.4 | 342.4 |
| CPU：只前向 | 137.7 | 329.4 | 502.8 |
| CPU：+ 取回 CPU | 137.7 | 330.0 | 507.1 |
| CPU：完整 | 141.0 | 344.6 | 520.6 |

**前向是绝对瓶颈**：Metal 上占 66%，CPU 上占 95%。把 top-k 搬上 GPU 最多省掉 Metal 那 28%
（beam 8 / 16 字 222 → 160 ms），救不了量级。降延迟只能动模型本身：更浅 / 更窄、更小的 beam、更短的解码长度。

## 结论

1. **P2C 做不了同步主候选。** 用户打字 5 到 8 键每秒（间隔 125 到 200 ms），而 beam 8 / 前文 64 / 16 字一次重解码
   Metal 要 218 ms、CPU 要 416 ms。每键重来一次的话，候选永远追不上手速。
2. **放进现有的异步槽位是可行的**，但要挑配置。现在壳是停键 80 ms 触发重排，重排 16 到 34 ms，约 100 到 120 ms 出结果。
   P2C 换进去：Metal beam 4 / 8 字是 80 + 68 = 148 ms，勉强；beam 8 / 16 字是 80 + 218 = 298 ms，明显能感觉到。
   CPU 端同样配置要 80 + 207 = 287 ms 与 80 + 416 = 496 ms，Windows 上基本只剩最小那一档能用。
3. **前文要计费。** 前文 64 字让解码成本翻倍（Metal beam 8 / 16 字：90 → 218 ms）。整句评测集上前文值 1 到 2 个点，
   P2C 里要重新算这笔账。
4. **因此 P2C 不该当架构替换，该当第二来源**：词库出同步候选保住手感与标注（词性 / 译文 / 等级），
   P2C 在停键后补 OOV 与纠错。这条路线下上面这些延迟都落在可接受区间。

## 复现

```bash
cargo run --release -p qingjian-neural --example p2c_bench --features metal -- data/models/hanzhang-zhiwei   # Apple GPU
cargo run --release -p qingjian-neural --example p2c_bench -- data/models/hanzhang-zhiwei                    # CPU
```

换模型就换最后那个参数（`.qjm` 单文件或三件套目录都认）。表格格式固定，以后训出真 P2C 模型跑同一条命令直接对比。
