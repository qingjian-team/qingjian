- **macOS**：从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单中青简的几项），名为「偏好设置」。
- **Windows**：开始菜单的「青简设置」，或悬浮状态条上的 ⚙，名为「设置」。

修改即时生效，没有「保存」按钮。

| 页 | 内容 |
|---|---|
| 通用 | 学习语言（英语 / 日语）、每页候选数 1 至 9、双拼方案、英文模式候选开关与「终端 / 编辑器中不给候选」；Windows 另有「中文模式标点转全角」与「英文模式标点转全角」 |
| 候选窗口 | 外观（跟随系统 / 浅色 / 深色）、排布（竖排 / 横排）、拼音显示位置（行内 + 窗口 / 只在行内 / 只在窗口）；Windows 另有「悬浮状态条」开关 |
| 快捷键 | 翻页键对、算式与问字的前缀键、上屏第一 / 第二条译词的修饰键、删除候选的修饰键、翻译选中文字的组合键；「恢复默认快捷键」 |
| 模糊音 | 九条勾选 |
| 词库 | 随包领域词库开关，导入 / 开关 / 移除用户词库，见 [词库](dictionaries.md) |
| 云服务 | 开关、云端词格数、服务地址、模型、API 密钥、「测试连接」按钮 |
| 统计 | 输入量与词汇量，见 [统计](../learning/statistics.md) |
| 高级 | 详细日志、记录输入日志、清空输入日志、在编辑器中打开配置文件 |
| 关于 | 版本与构建号、官网与 GitHub 链接、许可证、随包数据来源、隐私说明、打开日志目录、复制诊断信息 |

## 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 输入法菜单（macOS）

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时增加一条灰色的错误说明，此时沿用上一份可用的配置，输入法不退出。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在编辑器中打开配置文件」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。
