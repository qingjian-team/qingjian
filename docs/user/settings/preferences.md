## 打开设置

- **macOS**：输入法菜单（菜单栏「中 / 英」状态项，或系统输入源菜单中青简的几项）中的「设置…」。
- **Windows**：开始菜单的「青简设置」，或悬浮状态条上的 ⚙。
- **Linux**：应用菜单中的「青简设置」。

修改即时生效，没有「保存」按钮。

左上角的搜索框可按设置项名称、选项文字或说明中的词查找，例如搜「英语」可找到「译文」。点击结果（或按 `Enter` 选第一条）跳到对应页并标出该项，`Esc` 清空搜索。
标题旁的 ⓘ：鼠标悬停显示简短说明，点击打开本文档或相关文档中对应的段落。

## 旧版设置

本版本保留旧的设置窗口作为备用，新设置窗口无法打开或某项不生效时可改用它：macOS 输入法菜单中的「旧版设置…」；Windows 任务栏「中 / 英」图标右键菜单中的「旧版设置…」，或开始菜单中的「青简旧版设置」。
两者修改同一份设置。旧版设置将在下一个版本移除；遇到需要改用旧版的情况，请[反馈](../help/feedback.md)。

### 繁体输出

「输出字形」选了繁体后，候选与上屏文字按 OpenCC 转成繁体（只换字形，不换用语：软件 → 軟件；台湾与香港的字形取舍不同：裡 / 裏），见 [繁体输出](../input/traditional.md)。云端词与整句补全同样转换。引擎内部仍按简体处理：用户词、词频、输入统计与输入日志都记简体，译词照常显示。

### 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。
macOS 上可以把这一行展开成多行：在「外观」页的排布下面勾选「横排时 ↑ / ↓ 展开成多行」（缺省不勾，不勾时横排下的按键与以前一样：
`↑` / `↓` 逐个移动高亮，`←` / `→` 移动拼音光标，`Esc` 清空）。勾选后立即生效：
按 `↑` / `↓` 会把这一行展开成 6 行的矩阵（一行对应一页候选），同时换到上一行或下一行；`←` / `→` 改为在候选之间移动（没展开时也是，拼音光标改用 `⌥ + ←` / `⌥ + →`），
数字键选的是高亮所在那一行的第几个，高亮移出矩阵上下边缘时按行滚动，翻页键一次翻一屏。展开后窗口大小在这一轮输入里保持不变；超过四个字的候选在格子里截断显示为「…」，
高亮到它时矩阵下方给出完整内容。继续输入拼音或按 `Esc` 收回单行。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 自定义短语

每条一行：启用开关（标签为输入码）、候选位置、内容的第一行、「编辑」；末尾一行「新增…」。
新增或编辑在弹出的卡片中进行：填写 1–32 个小写英文字母的输入码、1–9 的候选位置和内容（可多行），点击「保存」。编辑时卡片左侧有「删除」，需点击两次确认。`Esc` 或「取消」放弃修改。
内容可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置；云端词只使用不影响固定位置的剩余格。若固定位置超过第一页容量（例如第 9 位、每页 5 项），本次查询不显示云端词。位置跨页时按当前页的序号选择。

同一个输入码的位置不能重复，冲突时卡片中提示原因并保留草稿；停用规则也保留其位置。没有足够普通候选时保留空位，空位不能上屏。
编辑期间若规则被其他窗口或外部文件修改，保存会提示并保留草稿，不覆盖新规则。英文模式不触发自定义短语。

直接改配置文件时，某一条短语写错（位置不在 1–9、文本不是字符串、与前面的条目占同一个位置等）只跳过那一条，其余短语和其他设置照常生效，日志里记下是第几条、错在哪；在这页保存时，跳过的条目原样留在文件里，不会被删掉。

### 系统的文本替换

macOS 上，「自定义短语」页的「也用系统的文本替换」（缺省开启）打开后，系统设置「键盘 → 文本替换」中的条目在输入拼音时同样可用：
输入码敲全后短语出现在该输入码最靠前的空位（页中的规则优先占位），`Space` 或数字键上屏。
只有输入码全为小写英文字母的条目可用；系统设置中新增或修改的条目在下次切换到青简时生效。它们不在页中列出，修改需到系统设置。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页的「在编辑器中打开」可打开它，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法；Linux 上 `[general] preedit` 与 `[general] input_log` 例外，改完要重启青简服务。
