偏好设置从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单里青简那几条）。改完立即生效，没有「保存」按钮。

| 页 | 有什么 |
|---|---|
| 通用 | 学习语言（英语 / 日语）、每页候选数 1 到 9、双拼方案、英文模式候选开关与「终端 / 编辑器里不给」 |
| 候选窗口 | 外观（跟随系统 / 浅色 / 深色）、排布（竖排 / 横排）、拼音显示位置（行内 + 窗口 / 只在行内 / 只在窗口） |
| 快捷键 | 翻页键对、表达式与问字的前缀键、上屏第一 / 第二个译词的修饰键、删除候选的修饰键、翻译选中文字的组合键；「恢复默认快捷键」 |
| 模糊音 | 九条勾选 |
| 词库 | 随包领域词库开关、导入 / 开关 / 移除自己的词库，见 [词库](dictionaries.md) |
| 云服务 | 开关、云端词格数、接口地址、模型、API 密钥、「测试连接」按钮 |
| 统计 | 输入量与词汇量，见 [统计](../learning/statistics.md) |
| 高级 | 详细日志、记录输入日志、清空输入日志、在编辑器中打开配置文件 |
| 关于 | 版本与构建号、官网与 GitHub 链接、许可证、随包数据来源、隐私说明、打开日志目录、复制诊断信息 |

## 横排与拼音位置

横排时候选排成一行，只给高亮的那个在下面单独一行显示译词，页码在行尾。
「只在窗口」显示拼音适合终端和部分 Electron 应用，它们把行内拼音画得难看。

## 输入法菜单

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时多一条灰色的错误说明，此时沿用上一份能用的配置，输入法不退出。

## 直接改配置文件

所有设置都在一个 TOML 文件里，「高级」页有「在编辑器中打开配置文件」。保存后一秒内生效，不用重切输入法。
