- **macOS**：从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单中青简的几项），名为「偏好设置」。
- **Windows**：开始菜单的「青简设置」，或悬浮状态条上的 ⚙，名为「设置」。

常规设置修改即时生效；快捷文本的启用开关即时生效，新增或编辑在点击「保存规则」后生效。

| 页 | 内容 |
|---|---|
| 通用 | 学习语言（英语 / 日语）、每页候选数 1 至 9、双拼方案、英文模式候选开关与「终端 / 编辑器中不给候选」；macOS 可选择默认中文标点全角或半角，字母和数字不变；Windows 另有中英文标点开关 |
| 候选窗口 | 外观（跟随系统 / 浅色 / 深色）、排布（竖排 / 横排）、拼音显示位置（行内 + 窗口 / 只在行内 / 只在窗口）；Windows 另有「悬浮状态条」开关 |
| 快捷键 | 翻页键对、算式与问字的前缀键、上屏第一 / 第二条译词的修饰键、删除候选的修饰键、翻译选中文字的组合键；「恢复默认快捷键」；页底列出组句中不可更改的固定键（全表见 [按键与快捷键](../getting-started/keys.md)） |
| 快捷文本（macOS） | 设置输入码、固定候选位置、任意长度文本与启用状态；支持新增、编辑、删除 |
| 模糊音 | 九条勾选 |
| 词库 | 随包领域词库开关，导入 / 开关 / 移除用户词库，见 [词库](dictionaries.md) |
| 云服务 | 本地整句模型开关（见 [本地整句模型](../input/local-model.md)）；云联想开关、云端词格数、服务地址、模型、API 密钥、「测试连接」按钮 |
| 统计 | 输入量与词汇量，见 [统计](../learning/statistics.md) |
| 高级 | 详细日志、记录输入日志、清空输入日志、在编辑器中打开配置文件 |
| 关于 | 版本与构建号、官网与 GitHub 链接、许可证、随包数据来源、隐私说明、打开日志目录、复制诊断信息 |

## 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 输入法菜单（macOS）

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时增加一条灰色的错误说明，此时沿用上一份可用的配置，输入法不退出。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在编辑器中打开配置文件」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。

## 自定义快捷文本（macOS）

「快捷文本」页以常驻表格显示启用状态、内容和固定候选位置，可直接勾选启用或停用。点击「+」新增，双击已有行或点击「编辑…」修改，选中后点击「−」删除。新增或编辑时，填写 1–32 个小写英文字母的输入码、1–9 的候选位置和文本，点击「保存规则」。文本可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置；云端词只使用不影响固定位置的剩余格。位置跨页时按当前页的序号选择。

同一个输入码的位置不能重复，新增和编辑冲突时提示并拒绝保存；停用规则也保留其位置。没有足够普通候选时保留空位，空位不能上屏。选择已有规则后可编辑、停用或删除。

默认中文标点模式会保存，重启后仍生效；选择半角不会改变快捷文本中的全角标点。英文模式不触发自定义文本。
