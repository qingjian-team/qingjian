- **macOS**：从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单中青简的几项），名为「偏好设置」。
- **Windows**：开始菜单的「青简设置」，或悬浮状态条上的 ⚙，名为「设置」。

常规设置修改即时生效；自定义短语的启用开关即时生效，新增或编辑在点击「保存规则」后生效。

### 繁体输出

打开「繁体输出」后，候选与上屏文字按 OpenCC 转成繁体（只换字形，不换用语：软件 → 軟件）。云端词与整句补全同样转换。引擎内部仍按简体处理：用户词、词频、输入统计与输入日志都记简体，译词照常显示。

## 中文、外语与词性的字体（macOS）

在「候选窗口」页分别选择「中文字体」和「外语字体」，各自下方可选择字号、勾选加粗。输入英文时，英文候选使用外语设置，后面的中文释义使用中文设置；同一页中英候选混排也分别生效。「词性字号」独立控制 `n.`、`v.`、`prep.` 等标记，默认 12 磅，字族与加粗沿用外语设置；不改变分隔点或注音的字号。选择即保存，下一次显示候选时生效，重启后仍保留。三项字号范围均为 8–48 磅。

emoji 旁的中文提示（如「🔶 大」「🗼 塔」）同样使用中文字体、字号和加粗；英文提示（如「😀 smile」）使用外语设置。emoji 图案本身保持原有绘制方式。

字体和颜色设置下方有「实时预览」，以「学习 v. learn」和「learn v. 学习」两行展示中英双向效果；第一行的 learn 展示不熟单词色，第二行的中文释义展示普通词色。修改任一字体、字号、加粗或颜色后立即更新，无需切回输入窗口试打。预览跟随外观与渲染引擎；示例始终并排显示，不随横排设置改变。

中文需要字体本身有中文字形，例如 Songti SC 或 Kaiti SC。仅有英文字形的字体仍可用于学习译词；字体未安装或缺少某个字形时，自动使用系统字体补齐。没有粗体面的字体会合成加粗。序号和页码保持原来的大小。

已有中文与外语字体设置原样保留。手改配置时，「外语字体」沿用 `[general] font`；中文字体用 `candidate_font`，中文 / 外语字号用 `candidate_font_size` / `annotation_font_size`，加粗用 `candidate_bold` / `annotation_bold`；词性字号用 `pos_font_size`。

## 候选框颜色（macOS）

在「候选窗口」页点击色块，可以分别设置整体底色、候选字颜色、单词词性颜色、普通单词颜色、不熟单词颜色和选中区域颜色。使用系统取色器选色，立即保存，重启后仍保留；每项右侧的「恢复默认」只还原这一项，其他配色与字体不变。

「普通单词颜色」与「不熟单词颜色」互相独立，词熟悉后自动转为普通词色。已有的「单词颜色」保留为普通单词色；不熟单词未自定义时使用原来的橙色。两种颜色都可单独恢复默认，不会影响学习记录。「单词词性颜色」也用于词义之间的分隔点。自定义色在浅色、深色外观下保持一致，未自定义的部分继续跟随外观；可以在实时预览里直接检查文字与底色的搭配。

原始生词规则：学习译词累计被看到不足 3 轮时使用不熟单词色（默认橙色），达到 3 轮后使用普通词色（默认灰色）。每次上屏时，当前候选页中的译词各记一轮，同页重复词只记一次；逐键刷新不累计。英文候选的中文释义不计入这份学习词汇记录，私密输入也不累计。自定义显示色不会删除或重置学习记录。

取色器也支持透明度。手改配置时，`[general]` 的六项分别是 `candidate_background_color`、`candidate_text_color`、`candidate_pos_color`、`candidate_word_color`、`candidate_fresh_word_color`、`candidate_highlight_color`，填写 `#RRGGBB` 或含透明度的 `#RRGGBBAA`。空字符串或无效色值使用默认色。

## 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。
macOS 上可以把这一行展开成多行：先在「候选窗口」页的排布下面勾选「横排时 ↑ / ↓ 展开成多行」（缺省不勾，不勾时横排下的按键与以前一样：
`↑` / `↓` 逐个移动高亮，`←` / `→` 移动拼音光标，`Esc` 清空）。勾选后立即生效：
按 `↑` / `↓` 会把这一行展开成 6 行的矩阵（一行对应一页候选），同时换到上一行或下一行；`←` / `→` 改为在候选之间移动（没展开时也是，拼音光标改用 `⌥ + ←` / `⌥ + →`），
数字键选的是高亮所在那一行的第几个，高亮移出矩阵上下边缘时按行滚动，翻页键一次翻一屏。展开后窗口大小在这一轮输入里保持不变；超过四个字的候选在格子里截断显示为「…」，
高亮到它时矩阵下方给出完整内容。继续输入拼音或按 `Esc` 收回单行。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 输入法菜单（macOS）

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时增加一条灰色的错误说明，此时沿用上一份可用的配置，输入法不退出。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在编辑器中打开配置文件」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。

## 自定义短语（macOS）

「自定义短语」页以常驻表格显示启用状态、内容和固定候选位置，可直接勾选启用或停用。点击「+」新增，双击已有行或点击「编辑…」修改，选中后点击「−」删除。新增或编辑时，填写 1–32 个小写英文字母的输入码、1–9 的候选位置和文本，点击「保存规则」。文本可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置；云端词只使用不影响固定位置的剩余格。若固定位置超过第一页容量（例如第 9 位、每页 5 项），本次查询不显示云端词。位置跨页时按当前页的序号选择。

同一个输入码的位置不能重复，新增和编辑冲突时提示并拒绝保存；停用规则也保留其位置。没有足够普通候选时保留空位，空位不能上屏。选择已有规则后可编辑、停用或删除。

编辑期间若规则被其他窗口或外部文件修改，保存会提示并保留草稿，不覆盖新规则。保存会保留现有短语条目的注释。

默认中文标点模式会保存，重启后仍生效；选择半角不会改变自定义短语中的全角标点。英文模式不触发自定义短语。

### 系统的文本替换

「自定义短语」页勾选「也使用系统设置『键盘 → 文本替换』里的条目」（缺省勾选）后，系统文本替换中的条目在输入拼音时同样可用：
输入码敲全后短语出现在该输入码最靠前的空位（页里的规则优先占位），`Space` 或数字键上屏。
只有输入码全为小写英文字母的条目可用；系统设置中新增或修改的条目在下次切换到青简时生效。它们不在页里的表格中列出，要改请到系统设置。
