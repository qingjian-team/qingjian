## 随包词库

基础词库 8.7 万条，另有 11 本领域词库随包：法律、医学、地名、成语、诗词名句、IT、财经、饮食、动物、汽车、历史人物。
缺省只开启成语，其余在「偏好设置 → 词库」勾选。领域词库只影响「是否有这个词」，不改变整句转换的权重。

## 导入用户词库

「偏好设置 → 词库 → 导入词库…」，接受三种格式：

- 青简 TSV：每行 `词<Tab>拼音<Tab>词频`，拼音音节间以空格分隔。
- Rime 的 `.dict.yaml`：读取名称、版本、词条及 `import_tables` 引用的分表，支持 `columns` 自定义列顺序。缺省词条格式为 `词<Tab>拼音[<Tab>权重]`，拼音音节间以空格分隔，非整数权重按 1 处理。头里有 `license` 时一并保留；没有声明时请查阅原词库的许可证。
- 青简 `.qj`：他人制作的词库文件，自带名称与许可证。

TSV 与 Rime 词库导入时，`lue` / `nue` 自动统一为 `lve` / `nve`。词库用 `v` 表示 ü。
旧词库里写成 `lue` / `nue` 的词也照常能打。

导入后列在随包词库之下，显示名称、条数、许可证。可单独开关；「移除」只将文件移到一旁，不删除。

Windows 导入时会转换成 `.qj` 并自动启用，设置页显示导入条数或失败原因。没有可用词条的文件不能导入。
文件选择窗口支持按 Ctrl 或 Shift 多选，批量导入 YAML、TSV 或 `.qj`；单个文件失败不影响其余文件，完成后显示成功、失败数量及各文件结果。
输入法运行时通常在约一秒内自动加载；同名重新导入和移除也会自动更新，无需重启。
若手动编辑配置时出现格式错误，词库仍按上次有效的开关设置加载；修正配置后自动恢复应用新设置。
Rime 文件要经「导入词库…」转换，直接放进词库目录不会加载。

### 导入雾凇拼音中文词库

下载并解压雾凇拼音，在「导入词库…」中选择解压目录里的 `rime_ice.dict.yaml`，同时保留它旁边的 `cn_dicts/` 目录。
无需逐个导入分表；只有主词库 `import_tables` 中启用的分表会被合并，注释掉的分表不会导入。
分表名相对所选主词库目录，引用的文件须在该目录或其子目录内；缺失分表会使本次导入失败，同名的已导入词库保持原样。

雾凇的腾讯分表没有拼音列。导入时利用一并读取的字表补充读音；多音字只用字频占比至少 5% 的读音，显式注音不受此限制。
缺少字表读音的词，或读音组合超过 256 种的词会被跳过，最终导入条数以词库列表为准。
重复的「词、拼音」保留首次出现的权重；显式注音优先于自动补充的注音。

导入后可在青简已有的全拼或双拼方案下使用。这里只导入中文词库，不加载 `.schema.yaml`、Lua 扩展、英文词库或雾凇的双拼键位配置。
雾凇词库由用户自行下载，使用与再分发须遵守原词库许可。

### 使用雾凇全拼扩展

若还需要英文、符号、拆字和日期输入，在青简配置文件里启用雾凇全拼，路径指向完整解压目录：

```toml
[rime_ice]
enabled = true
data_dir = 'D:\InputData\rime-ice'
```

macOS 或 Linux 使用对应的绝对路径，例如 `/home/me/InputData/rime-ice`。同时保留目录里的 `cn_dicts/`、`en_dicts/`、`opencc/`、`lua/` 等文件；不要只复制中文词库。

全拼时会使用雾凇中文词库、英文词库、混输词条、固定短语与 Emoji；切换双拼、注音或五笔后仍使用青简原有方案。选词、翻页和中英切换按键保持青简的设置。设 `enabled = false` 可恢复青简词库。

首次启用需要等待词库转换。修改雾凇源文件后重启青简。目录缺失或文件损坏时，青简保留当前可用词库，并在日志中记录原因。

| 输入 | 候选内容 |
|---|---|
| `rq`、`sj`、`xq` | 日期、时间、星期 |
| `dt`、`ts`、`rqzh`、`rqen` | 日期时间、时间戳、中文日期、英文日期 |
| `nl`、`N20260217` | 今日农历、指定公历日期的农历 |
| `uuid` | UUID |
| `cC1+2`、`cCsin(pi/2)` | 算式结果与完整算式 |
| `R1234.5678` | 数字大小写、金额大小写 |
| `U4e2d` | 中 |
| `vhelp`、`va`、`v1` | 符号列表、拼音声调、数字符号 |
| `uUrenmu` | 拆字反查，例如休 |
| 全拼后输入反引号与部件拼音 | 按部件缩小汉字候选，例如 ``xiu`ren`` |

算式支持四则、幂、括号、百分数、阶乘、三角函数、对数、平均值、方差与随机数等。数字、运算符会留在特殊输入码中，空格确认候选。符号列表的数字键仍用于选词，例如 `vhelp` 后按 `1` 选择第一项。

`rq`、`nl` 等输入先显示快捷候选，后面仍保留同码中文词，可以翻页选择。

普通词序和学习按青简规则处理，候选顺序可能与 Rime 不同。雾凇的自定义 Lua 和任意配置补丁不会自动生效。
