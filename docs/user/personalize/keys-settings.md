可以改的键都在「设置 → 快捷键」，改完立即生效。页底「恢复默认」把本页的键恢复为缺省值，下方列出打拼音时固定、不能改的键；缺省按键全表见 [按键速查](../getting-started/keys.md)。

## 翻页键

「翻页键」可选 `[` `]`（缺省）、`,` `.` 或 `-` `=`，前一个上一页、后一个下一页。`PageUp` / `PageDown` 始终可用。

- 选 `,` `.` 后，打拼音时逗号、句号用于翻页，不再上屏候选加标点。
- 选 `-` `=` 后，**翻不动时这两个键照常输入**：打拼音时没有上一页，`-` 就是 `-`（进英文直输）；没有下一页，`=` 就是 `=`。英文候选里 `-` 也是这样：第一页上按 `-` 就是单词里的连字符（`well-known`）。
- `-` `=` 指这两个键本身，不包括按住 Shift 打出的 `_` 和 `+`。
- 选 `[` `]` 或 `,` `.` 时，翻不动也照样当作翻页键，不会往文字里插标点。

macOS 与 Windows 另有「额外翻页键」，三组可多选，与上面的翻页键一起用。这些键打拼音时优先翻页；算式里的运算符、英文直输和辅码的触发键保持原来的作用。

## 回车优先上屏译词（macOS）

在「候选」一组打开「回车优先上屏译词」后，打拼音时按回车（含小键盘回车）上屏**当前高亮候选的第一条非中文译词**。空格照常选择中文。

- 没有候选、没有非中文译词或译词还没准备好时，回退到原来的回车逻辑，不等待联网翻译，也不自动选择别的候选。
- 默认关闭；关闭后回车仍原样上屏拼音。没有正在输入的拼音时，回车照常换行或发送，带修饰键的回车也不改变。
- 配置文件对应 `[shortcut] enter_translation = true`；支持英语、日语、德语等学习语言；候选已有非中文译词时才会上屏，中文释义仍走原回车逻辑。

## 上屏键（Windows、Linux）

打拼音时「上屏高亮候选」缺省是空格，「上屏敲的字母」（把敲的字母原样上屏）缺省是回车，两项都能在「候选」一组里点按钮重录：

- 可以是空格、回车（都可加 `Shift`），或一个符号键，如 `;` `/`；不能用 `Ctrl`、`Alt`、`Win` 组合，也不能用字母、数字、单引号。
- 两项不能是同一个键，也不能和翻页键、辅码触发键重复，录的时候会说明撞了哪一项。例如想让回车上屏候选，先把「上屏敲的字母」录成 `Shift + 回车`，再把「上屏高亮候选」录成回车。
- 空格或回车改走以后没录给另一项，打拼音时按它什么也不做（不会把空格或换行插进应用）。没在打拼音时它们照常交给应用。
- 大千注音的空格是一声，回车与 `Shift + 回车` 有自己的规则，不受这两项影响。

## 高亮移动键（macOS、Windows）

缺省 `↑` / `↓` 移动高亮、`←` / `→` 移动拼音光标。改选 `←` / `→` 后，`←` / `→` 在候选之间移动：

- **横排**：按 `↑` 移到拼音里（这时候选不显示高亮），`←` / `→` 移动拼音光标；按 `↓` 回到候选，勾了「横排时 ↑ / ↓ 展开成多行」时在候选上再按 `↓` 展开，展开后 `↑` / `↓` 上下换行、第一行再按 `↑` 回到拼音里。在拼音里再按 `↑` 打开符号面板。
- **竖排**：高亮与拼音光标连成一条，拼音光标到末尾再按 `→` 才移到下一个候选，候选在第一个时再按 `←` 才退回拼音；`↑` / `↓` 在打拼音时不起作用。

没在打字时方向键照常交给应用。中英文模式都适用。

## Emacs 风格候选键（macOS）

在「设置 → 快捷键 → 翻页与模式」勾选「Emacs 风格候选键」的 `Ctrl + F/B/N/P/A/E` 后，可在候选中使用这组键，与已有按键并用。默认关闭。Windows 与 Linux 暂不支持。

- **竖排**：`⌃ + P` / `⌃ + N` 移动到上一个 / 下一个候选，`⌃ + B` / `⌃ + F` 上一页 / 下一页。
- **横排**：`⌃ + B` / `⌃ + F` 移动到上一个 / 下一个候选，`⌃ + P` / `⌃ + N` 上一页 / 下一页。
- **横竖排均适用**：`⌃ + A` / `⌃ + E` 跳到当前页首个 / 最后一个真实候选，跳过空位。

这组键仅在候选中使用；未启用时不影响应用原有快捷键。开启后，候选中这些键不再交给应用；如果与按需 AI 联想或标点切换的自定义快捷键相同，这两项优先。横排开启「翻页键展开成多行」时，这组翻页键也会先展开；展开后按屏翻动。

## 全半角标点快捷键（macOS、Windows）

打开「Ctrl + . 切换全半角标点」后，按 `Ctrl + .`（macOS 为 `⌃ + .`）切换当前中英模式的标点全角 / 半角，不改字母与数字，也不切中英。
缺省关闭，以免占用应用自己的快捷键。macOS 英文模式的标点一律半角，这时按它不切换，键照常交给应用。
想换成别的组合键，见 [直接编辑配置文件](../advanced/config-file.md)。

## 简繁切换快捷键（Windows）

打开「Ctrl + Shift + F 切换简繁输出」后，按 `Ctrl + Shift + F` 在简体与繁体之间切换，候选立即换成新的字形，正在打的拼音保留，已经上屏的字不改。
切到繁体时用上次切走前的那一档；从来没用过繁体时是台湾字形。切换的结果同样记在「候选 → 输出字形」里，档位的差别见 [繁体输出](../input/traditional.md)。
缺省关闭：开着时这个组合在所有应用里都会被青简拿走，VS Code 等编辑器的「在文件中查找」用的也是它。想换成别的组合键，见 [直接编辑配置文件](../advanced/config-file.md)。

## 算式与问字的前缀

「表达式」「问字」两项是进入算式与问字的前缀字母，只能是 v、u、i；选了另一个正在用的字母，两者对调。见 [日期、算式与特殊字符](../input/shortcuts.md#换前缀字母)。

「? 也进问字」打开后，没在打拼音时敲 `?` 再接拼音同样进入问字，见 [问字](../cloud/question-and-translate.md#问字)。

## 译词

「上屏第一个译词」「上屏第二个译词」两项各是一个修饰键，与数字键一起用。点一下再按住修饰键按任一数字即录下。

缺省：

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 上屏第一个译词 | `⌥` | `Ctrl` | `Alt` |
| 上屏第二个译词 | `⇧⌥` | `Ctrl + Shift` | `Alt + Shift` |

macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页）；Windows 上 `Alt + 数字` 会被应用当作菜单快捷键截走，所以缺省用 `Ctrl`。两项不能相同，录到不可用的键时该行下方说明原因。删除候选改在候选的右键菜单里，见 [输入习惯](habits.md#候选右键菜单)。

## 翻译与 AI 联想

- **翻译选中文字**：点一下再按下组合键即录下。Windows 上改完要切到其他输入法再切回青简（或重开应用）才生效。
- **按需 AI 联想**（macOS、Windows）：打拼音时手动要 AI 候选的组合键，见 [云联想与整句补全](../cloud/predict.md#手动联想)。

录制时按 `Esc` 或点击别处取消。
