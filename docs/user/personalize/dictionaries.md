## 随包词库

随包的是基础词库、通用词库与成语词库，都列在「设置 → 词库 → 随包词库」里，缺省都开着，三本都能开关。

- **基础词库**：约 34 万条（13 万常用词加 21 万补充词）。关掉后它的词不再出，单字照常能打，词和整句里的词全靠你导入或下载的词库，适合想整套换用自己词库的时候。
- **通用词库**：127 万条，2 到 30 字，从公开语料里整理出来，还在边用边清理。
  读音一样时，基础词库的词排在它前面；它里面的长词也不会在没敲完时提前出现，比如敲 `anzhao` 不出「按照相关」，敲全了才出。

**领域词库**在下面的「下载」里装：法律、医学、地名、诗词名句、IT、财经、饮食、动物、汽车、历史人物。
领域词库只决定「有没有这个词」，不改变整句的排法。

基础词库收了 3.6 万个生僻字（规范字表以外的扩充汉字与台湾罕用字），用拼音能打出，排在同音字最后，不参与整句：
`fiao` 出 覅，`biangbiangmian` 出 𰻝𰻝面。系统字体没有的字会显示成方框。

## 下载词库

「设置 → 词库 → 下载」列出青简词库仓库里能下载的词库与释义表，上方的「词库 ｜ 释义表」切换看哪一类；词库有不止一种语言时按语言分组。每本写明简介、作者、大小和许可，作者名能点的点了打开作者主页；别人整理的名称旁标「第三方」。
列表在打开设置时取一次，没联网时显示上次取到的那份，列表上方写着是什么时候取的，点「刷新」重新取。点「下载」后装进你的数据文件夹，和导入的词库一起列在「我的词库」里，缺省开着，前面的勾选框可以开关，也能移除；
词库仓库里有新版本时按钮变成「更新」。同时点了好几本时依次下载，还没轮到的显示「排队中」，可以取消。

从旧版本升级上来时，以前随包、你开着的领域词库，以及学习语言用到的释义表，会在打开设置时自动依次下载回来，下完和升级前一样。

「释义表」那一栏是候选旁译词用的表：日语、西班牙语、越南语、德语要下载，英语和英文候选旁的中文随包就有。下载后输入法自动换上，不用重启；它不出现在「我的词库」里，比随包的同一张表新时用下载的。
## 自动组词

「设置 → 输入 → 五笔自动组词」可开启「自动学习五笔新词」，并选择「最大词长」：2～10 个汉字，默认 4 字。这两个设置只控制五笔连续组词，包括混输中连续选中的五笔词，不改变拼音和双拼的学习规则。

- 同一段拼音分次选完一次即学习，整段记忆最多 20 字；由多字词组成、6 字以内的整句一次选中也会记住。分开输入的连续词仍需重复 3 次后学习，不受五笔组词开关和最大词长限制。
- 五笔连续上屏的字词首次组合后即记住，按单字全码取词码，不受简码输入影响。最长 10 字的词仍使用 4 码；只组合完整上屏词，不截取词内的字。
- 标点、英文、原样上屏、焦点变化或编辑操作打断五笔组词。混输时，拼音与五笔分别学习，不把拼音输入串作为五笔编码。
- 关闭不删除已学词，也不关闭词频排序学习。关闭「学习输入习惯」或进入私密输入时，不学习新词。

自定义形码需明确提供兼容的五笔组词规则。macOS 与 Windows 提供这组设置；Linux 尚未接入形码，暂不显示。Android 使用相同的学习规则，应用设置暂未提供独立的自动组词控件。

## 导入自己的词库

「设置 → 词库 → 导入词库」，可一次选多个文件，接受五种：

- **文本词库**（`.tsv` / `.txt`）：每行「词、拼音、词频」，以 Tab 分隔，拼音音节间以空格分隔：`青简	qing jian	100`。拼音可以带数字声调（`ni3 hao3`，轻声写 5 或 0），也可以不带，打字时一样。ü 写作 `v`，写成 `lue` / `nue` 的也认。
- **Rime 词库**（`.dict.yaml`）：读取名称和词条（每行「词、拼音、可选的权重」）。不支持它引用的其他词库、自定义列顺序或方案配置。只有词、没写拼音的行按下面一条补读音。
- **只有词的词表**（`.txt`，或没写拼音的 Rime 词库）：每行一个词，也可以写「词、词频」；读音按随包的基础词库与领域词库自动补：
  词表里写明的读音优先，其次是词库里的整词读音，再次按词库切分（`中华人民共和国` 用「中华」「人民」「共和国」的读音），剩下的单字取最常用的读音。
  字不在随包词库里的词跳过不导入，结果里会列出跳过了几条、前几个是哪些词。
- **搜狗细胞词库**（`.scel`）：从搜狗词库网站下载的词库，读取词条与拼音，不带词频（统一按 100 算），名称取文件名。
- **青简词库**（`.qj`，或压缩过的 `.qjz`）：别人做好的词库文件，自带名称与许可证；`.qjz` 导入时自动解开，不用先解压。

- 导入后列在随包词库之下，显示名称、条数、许可证，并自动启用；输入法通常在约一秒内用上，不用重启。
- 单个文件失败不影响其余文件，完成后显示每个文件的结果；没有可用词条的文件不能导入。
- 可单独开关；「移除」只把文件挪到一旁，不删除，彻底删除见 [卸载](../help/uninstall.md#只清除一部分)。
- 「导出…」把一本存成 TSV（`词、拼音、词频`，知道声调的带数字调，开头几行注释写名称与许可），可以拿去改了再导入，下载的词库也能导出。
- 同名的词库重新导入会替换旧的。Rime 词库要经「导入词库」转换，直接放进青简的数据文件夹不会生效。

Android 的词库在青简应用里导入，见 [Android：生词本与设置](../platforms/android-settings.md#词库)。

## 屏蔽词

导入的词库里有时会带进一堆用不上的词——某些第三方词库把「搜狗」这类品牌词的词频填得很高，
打 `sougo` 这种错拼都能顶到第一页。在配置文件的 `[dictionaries]` 下加一行就能挡掉：

```toml
[dictionaries]
blocked = ["搜狗"]
```

按**含有**算：配了「搜狗」，「搜狗拼音」「搜狗输入法」「搜狗标准大词库」一起消失。
自定义短语不受影响——那是你自己写下的原文。

改完保存就行，输入法约一秒内重新读配置，不用重启。设置界面里暂时还没有这一项，先改配置文件。macOS、Windows 与 Linux 支持；Android 还不支持。

## 导入五笔词库

五笔词库也从「导入词库」进。导入时看第二列：多字词的第二列是连着写的字母（`gant`）就当五笔词库，带空格的（`kai fa`）是拼音词库。
认不出格式的文件直接报错，不会显示导入成功却打不出来。只有单字的文件分不出是拼音还是五笔，按拼音词库导入。

五笔词库每行「词、编码、词频」，以 Tab 分隔，词频可省略，`#` 开头的是注释；Rime 的五笔词库也行：

```text
青简	getu	100
```

- 导入的词与随包五笔码表合在一起用，不用整份替换码表。同一个编码下按词频排，想让自己的词排在前面就把词频写大一些。
- 词库记给导入时「设置 → 输入 → 形码」选着的方案（形码是「关」时记给五笔）。换成别的形码方案后它不生效，换回来照常用。
- 列表里名字后面带着方案名，例如「我的五笔词（五笔（86））」，和拼音词库一样可以开关、移除。
- macOS 与 Windows 支持；Linux 和 Android 还不能导入五笔词库。
