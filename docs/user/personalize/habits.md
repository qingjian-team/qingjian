青简会记住你的输入习惯，让常用的词排得更靠前。全部记在本机，不上传。

## 记住什么

- 你选过的词，以及同一段拼音下你选的是哪个。
- 连续输入的词与词之间的搭配，整句据此调整。
- 自己造的词：连续选出的两个词合起来不在词库里、又选过几次时，自动记为一个词；分几次选完的一段拼音，第二次同样输入时合起来记为一个词。
- 选过的 AI 候选（按你敲的读音记）。
- 原样上屏过的英文词。
- 被接受的拼写纠正，见 [整句、简拼与纠错](../input/sentence.md#记住习惯性错误)。

选错后删掉重打，那次选择不会被记住，见 [选错了词](../getting-started/first-input.md#选错了词)。

## 慢慢淡忘

选择次数会随时间自然冷却：一个词 90 天不打，次数约减半，排序时旧词让位给新词，候选始终跟着你现在的习惯走。
冷却只影响排序，记录本身一直在。

## 候选右键菜单

输入拼音时在候选上点右键（macOS 也可按住 `⌃` 点按），菜单里按情况有这几项，只对当前这段输入生效：

- **修改译文…**：在系统输入框里修改候选旁的学习语言译文。保存到个人释义表后立即生效，并优先于随包释义显示。
- **模型重新生成译文**：云服务按当前学习语言重新翻译这个候选，并把结果保存到个人释义表。只有云服务和学习语言都启用时才显示；私密输入不会发出请求。
- **置顶**：以后打同样的字母，这个词排第一。做法是在「自定义短语」里加一条权重最高的短语，可以在那里看到、改权重或删掉，见 [自定义短语](phrases.md)。只认完全相同的字母，简拼、全拼各算各的。
- **取消置顶**：删掉这条自定义短语。
- **降权**：这个词往后挪一位，可以连点几次。词库里的词也能降。
- **取消降权**：回到原来的位置。
- **删除**：自己造的词、选过的 AI 候选整个删除；词库里的词不删除，但清除对它的全部记录，恢复原来的排序。

做完拼音行旁短暂显示结果（如「已删除用户词「…」」），输入下一个键即消失。菜单开着时按 `Esc` 只关菜单。
Windows 与 macOS 支持；Linux 暂不支持。

## 关闭学习与从头开始

- 「设置 → 候选」关闭「学习输入习惯」后不再记新的，已记住的照样参与排序。
- 在密码框与应用标为私密的输入框里打字，一律不记。
- 想从头开始，删掉数据文件夹里的输入习惯文件，见 [数据文件与日志](../advanced/data-files.md#数据文件)；Android 在青简应用里可一键清空，见 [Android：生词本与设置](../platforms/android-settings.md#导出与清空)。
