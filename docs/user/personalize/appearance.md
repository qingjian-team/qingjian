候选窗口的样子在「设置 → 外观」里改，页首是按当前设置画的预览。macOS 与 Windows 上同一个主题显示效果一致。
Linux 使用 Fcitx 自己的候选面板，外观由 Fcitx 的设置决定；Android 见 [Android：生词本与设置](../platforms/android-settings.md#外观)。

## 主题

| 主题 | 高亮的候选 |
|---|---|
| 青简绿（缺省） | 浅绿色底，文字颜色不变 |
| 系统蓝 | 系统蓝色底，白字 |
| 微信绿 | 微信绿色底，白字；AI 候选为蓝色 |
| 玻璃 | 蓝色胶囊，白字；横排是一整条胶囊。macOS 上窗口是透明的玻璃，透出后面的内容，字跟着背景自动变深变浅；Windows 上是近白的不透明底 |
| 樱花 | 粉紫玻璃底、粉色高亮块，宋体候选，词性与释义分两行；左上角趴着的人物、樱花挂件与缎带 |
| 大肥鱼 | 蓝边玻璃底与水波、浅蓝高亮块，译文在词下面另起一行；鲸鱼女仆趴在窗口上沿、竖排时扒在右边 |
| 初音未来 | 青色切角边框与音柱、青色高亮块，译文在词下面另起一行；初音未来趴在窗口上沿、竖排时扒在右边 |
| 波奇酱 | 粉色双层边框、奶油底，窗口外绕一圈音频线，粉色高亮块；波奇酱抱着吉他趴在窗口上沿、竖排时躲在左边 |

点主题卡片即换。青简绿、系统蓝、微信绿、玻璃都有浅色与深色两套，按同一页的「外观」选跟随系统、浅色或深色；樱花、大肥鱼、初音未来、波奇酱只有浅色。
主题只在「渲染引擎」选「青简渲染器」（缺省）时生效。

想自己做一个主题，见 [自制主题](../advanced/custom-themes.md)；做好的主题放进去后，重新打开设置即出现在主题卡片中。

## 排布

- **竖排或横排**：竖排一行一个候选；横排时候选排成一行，只有高亮候选在下方单独一行显示译词，页码在行尾。
- **每页候选数**：在「设置 → 候选」里选 1 至 9。
- **拼音显示位置**：行内与窗口、只在行内、只在窗口。「行内」是在应用的输入框里显示正在打的拼音；终端与部分应用对行内拼音显示得不好，可选「只在窗口」。

### 横排时展开成多行

macOS 与 Windows 横排时，可以勾选「横排时 ↑ / ↓ 展开成多行」（缺省不勾）。勾选后：

- 按 `↑` / `↓` 把这一行展开成 6 行的矩阵（一行对应一页候选），同时换到上一行或下一行；第一排再按 `↑` 回到第一个候选。
- `←` / `→` 在候选之间移动（没展开时也是）；`←` 顶到第一个候选后接着按可移动拼音光标，`→` 移回末尾后恢复移动候选。
- 数字键选的是高亮所在那一行的第几个，高亮移出矩阵上下边缘时按行滚动，翻页键一次翻一屏。
- 展开后窗口大小在这一轮输入里保持不变；超过四个字的候选在格子里截断显示为「…」。继续输入拼音或按 `Esc` 收回单行。

不勾时横排下的按键与竖排相同：`↑` / `↓` 逐个移动高亮，`←` / `→` 移动拼音光标。

## 拼音行显示声调

macOS 与 Windows 可在「设置 → 候选」打开「拼音行显示声调」：候选窗口顶部的拼音按高亮候选的读音标声调（`ganga` 高亮「尴尬」时是 `gān'gà`），简拼也换成完整读音。
读音与输入对不上的候选（模糊音、纠错、AI 推荐）仍显示输入的拼音；拿不准读音的字不标调。应用输入框里的拼音不变。

## 文字

- **渲染引擎**：青简渲染器（缺省）或系统绘制。主题、字体、键位提示等只在青简渲染器下生效。
- **字体**：缺省为系统字体。
- **Windows 生僻字**：系统装有宋体扩展字体时，候选窗口会自动用它补显示生僻字，不必更换主题或字体。系统没有覆盖对应汉字的字体时，仍可能显示缺字。
- **候选字号、译文字号**：缺省为主题的字号；「恢复主题字号」回到主题的字号，换主题后跟随新主题。

## 动效

「过渡动画」关闭后高亮直接跳到位，主题里一直在动的装饰也停下。系统开了「减少动态效果」时同样不播动画。
