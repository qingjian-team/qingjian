在 Windows 与 Android 之间互传复制的文字和图片：一边复制，另一边直接粘贴。内容只在你的设备之间加密传输，不经过任何服务器。这是实验功能，默认关闭，macOS 与 Linux 还不支持。

## 打开与配对

1. 两台设备都打开同步：
   - Windows：「设置 → 实验功能」打开青简剪贴板和「局域网同步」。
   - Android：「键盘设置 → 剪贴板 → 局域网同步」。
2. 打开设备页：Windows 按快捷键呼出剪贴板面板，点「设备」；Android 就在刚才那一页。
3. 一台点「显示配对码」，另一台在「附近的设备」里点对方，输入这 6 位数字。

配对码 2 分钟内有效，输错一次就作废，重新生成一个就好。「附近的设备」里没有对方时，用「手动输入地址」，写对方的 IP 地址和端口，比如 `192.168.1.5:53319`。

只需配对一次。设备名可以改；没起名时会有一个随机的名字，配对后在别的设备上显示的就是它。设备名和电脑名（或手机型号）在同步打开时局域网里的设备都看得到，不要写隐私内容。

## 同步什么

- 文字和图片会同步，文件不同步。
- 收到的内容进历史。Windows 上最新的一条还会放上系统剪贴板，直接就能粘贴；Android 上只有文字会这样，图片要从剪贴板面板里取。
- 手动删掉一条，其他设备也会删掉。超出最多保留条数被清掉、或者清空本机历史，只影响本机。
- 对方不在线时不算失败，上线后自动补传。

## 连接状态

| 显示 | 含义 |
|---|---|
| 已连接 | 最近真的连上过 |
| 正在连接… | 还没有结果，正在试 |
| 连不上 | 最近一次连接失败；对方可能关了同步、关机或换了网络。显示的时间是上次同步的时间 |

## 霓虹灯

收到内容时，屏幕边缘（Android 上是键盘边缘）亮一圈光。传得快时颜色从蓝变青再变紫，成功转绿、失败转红，然后收起。发送方只在发送失败时才亮红色。Windows 上结束时顶边还有 ✓ 或 ✕。可以在同步的设置里关掉，全屏游戏时 Windows 不显示。

## 常见问题

- **剪贴板面板收起后还同步吗？** 同步。Windows 上只要剪贴板程序在运行就行。
- **手机上没及时收到？** Android 只在输入法或青简 App 运行时同步，系统把它们清掉后，下次弹出键盘时会补上。
- **配不上、连不上？** 确认两台在同一个网络；Windows 第一次打开同步时如果弹出防火墙提示，要允许专用网络；访客网络或开了「AP 隔离」的路由器可能禁止设备互连。
