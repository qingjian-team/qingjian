## 中英切换

- **macOS**：`Caps Lock`（键盘上的中 / 英键），熄灭为中文，亮起为英文。
- **Windows**：单击 `Shift`（按下即松开，不与其他键组合），任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」；点击该图标同样可以切换。
  Windows 上的 `Caps Lock` 只控制大小写。
- **Linux**：单击 `Shift`。

切换键可以改，英文模式也可以整个关掉，见 [中英文](../input/english-mode.md)。

## 候选窗口

输入拼音时，候选窗口显示在光标下方：顶部一行是已输入的拼音（自动按音节分隔），其下是候选，右下角是页码。缺省竖排，每页 9 个，均可在设置中修改，见 [外观与主题](../personalize/appearance.md)。
一串拼音有几种分法时按高亮候选的读音分隔：`ganga` 高亮「尴尬」时显示 `gan'ga`，高亮「刚啊」时显示 `gang'a`。
候选右侧字号较小、颜色较浅的一列是译词，见 [候选旁的译词](../learning/translation.md)。

## 选词与翻页

| 操作 | 按键 |
|---|---|
| 上屏高亮候选 | `Space` |
| 上屏第 N 个候选 | 数字 `1` 至 `9` |
| 将拼音字母原样上屏 | `Enter` |
| 翻页 | `[` `]`，或 `PageUp` / `PageDown` |
| 移动高亮 | `↑` / `↓` |
| 删除一个字母（前面有选好的词时先撤回选择） | `Backspace` |
| 清空 | `Esc` |

也可以用鼠标点候选上屏。完整按键表见 [按键速查](keys.md)。

## 整句输入

无需切换模式，连续输入整句后再上屏：`jintiantianqihenhao` 的首选即为「今天天气很好」。简拼同样可用：`jttqhh`。
整句、简拼和输错字母时的处理见 [整句、简拼与纠错](../input/sentence.md)。

## 中文标点

中文模式下直接敲标点键得到全角标点：`,` 出「，」，`.` 出「。」，`{` `}` 出「」。数字之后的 `.` 保持半角（`3.14`）。
全角与半角的切换、打拼音时敲标点的效果，见 [标点、符号与表情](../input/punctuation.md)。

## 选错了词

上屏后用 `Backspace` 删除，再输入同一段拼音改选其他候选，上一次的选择不会被记住；误按 `Space` 选中错词也不会被输入法记住。
连续删除后面几个词再从头重输同样有效：删除「沃德书」后重输为「我的书」，「沃德」那次选择视为未发生。

一段拼音分几次选完时，先选的词留在输入框里、显示在剩下的拼音前面，整段选完才一起上屏；按 `Enter` 时它们连同剩下的拼音原样一起上屏，`Esc` 全部取消。
发现前面选错了，按 `Backspace` 撤回最后一次选择、那段又变回拼音，可以重选；选择都撤回之后再按才删字母。
想要选了就上屏，在「设置 → 输入」关掉「分次选词先不上屏」。

一段拼音分几次选完（先选一个字，剩余部分整句上屏），第二次以同样方式输入时，合起来的词会被记为用户词，此后整段输入直接排在第一位。
青简还会从哪些方面记住你的习惯，见 [输入习惯](../personalize/habits.md)。
