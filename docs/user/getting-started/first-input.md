## 中英切换

**中英切换是 `Caps Lock`**（键盘上的中 / 英键）。灭着是中文，亮着是英文。英文模式的行为见 [英文模式](../input/english-mode.md)。

## 候选窗口

敲拼音时候选窗口跟在光标下方：顶部一行是切分好的拼音，下面是候选，右下角是页码。缺省竖排，每页 9 个，都能在偏好设置里改。
候选右侧较小较浅的一列是译词，见 [译词与生词](../learning/translation.md)。

## 整句输入

不用切模式，一口气敲完一句再上屏：`jintiantianqihenhao` 首选就是「今天天气很好」。简拼也行：`jttqhh`。
两三个字母的简拼多半还是词（`sj` 时间），要句子就多敲几个音节。

## 按键

| 按键 | 行为 |
|---|---|
| 字母、`'` | 在光标处插入 |
| `空格` | 上屏高亮候选；没有候选时上屏拼音 |
| `1` 到 `9` | 上屏当前页第 N 个 |
| `回车` | 把拼音原样上屏 |
| `退格` / `Delete` | 删光标前 / 后一个字母 |
| `⌥ + 退格` | 删光标前一个音节（`kai'fa'xian` → `kai'fa`） |
| `⌘ + 退格` | 删光标前的全部拼音 |
| `Esc` | 清空 |
| `上` / `下` | 移动高亮，到页边自动翻页 |
| `左` / `右` | 移动拼音光标；光标停在中间时候选只按光标前的拼音算 |
| `⌥ + 左` / `⌥ + 右` | 按音节跳光标；`⌘ + 左` / `⌘ + 右` 到开头 / 末尾。前面某个音节敲错了：⌥← 跳到它后面，⌥⌫ 删掉重敲，⌘→ 回末尾 |
| `[` `]` | 翻页（可改成 `,` `.`）；`PageUp` / `PageDown`、`Shift + Tab` 也翻 |
| `Tab` | 有云端整句补全时接受它，没有则翻页 |
| 半角标点（`,` `.` `?` `-` 等，翻页键除外） | 进入英文直输段：`hello,` `no-way` 整段原样显示，之后的字符原样追加，空格 / 回车原样上屏（空格本身也打出）。中文模式下也能打 `hello, world?` 这样带标点的英文 |
| `Shift + 字母` | 先把拼音原样上屏，再把大写字母交给应用 |

不在组句时，中文标点：`, . ? ! : ; ( ) [ ] < > \ ^ _ $ ~` 转全角，`"` `'` 成对切换；数字后面的 `.` 保持半角。
要在拼音后面接全角标点，先按空格把词上屏再打标点。

## 选错了词

上屏后把它退格删掉、重打同一段拼音换选别的词，上一次记的学习会退回去，不用担心一次误按空格把错词教给输入法。
连着删掉后面几个词再从头重打也算数：「沃德书」删掉重打成「我的书」，「沃德」那次就当没选过。

一段拼音分几次选完（先选一个字，剩下的整句上屏），第二次这么打时合起来的词就会记成你的词，下次整段打出来直接排第一。
