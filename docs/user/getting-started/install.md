## 系统要求

macOS 13 或更新。Apple Silicon 与 Intel 各有一个安装包，不确定自己是哪种就点左上角  → 「关于本机」看「芯片」一行。

## 安装

1. 下载 `Qingjian-<版本>-arm64.pkg`（Apple Silicon）或 `Qingjian-<版本>-x86_64.pkg`（Intel），双击安装，需要管理员密码。
2. 测试版还没有 Apple 开发者签名，首次打开系统会拦一下：到「系统设置 → 隐私与安全性」，拉到底部点「仍要打开」，再装一次。
3. 装完输入法菜单里就有「青简」。

没有出现的话，到「系统设置 → 键盘 → 输入法 → 编辑 → +」，在「简体中文」下添加「青简」；还没有就注销再登录一次。

## 装完之后

- 菜单栏右上会多一个「中 / 英」状态项，点它能打开输入法菜单和偏好设置。
- 偏好设置在输入法菜单里，改完立即生效，没有「保存」按钮。
- 第一次用先到「偏好设置 → 通用」选学习语言（英语或日语），候选旁边的译词就是这门语言。

## 升级与卸载

升级直接装新的 pkg，学习数据与设置都保留。卸载见 [卸载](../help/uninstall.md)。
