macOS 与 Windows 版是测试版，从[下载页](https://qingjian.app/download)取得安装包。
Linux 版需在终端中安装，见 [Linux](../platforms/linux.md)；Android 版下载 APK 安装，见 [Android](../platforms/android.md)。

官方发布渠道目前只有官网下载页、[GitHub Releases](https://github.com/qingjian-team/qingjian/releases)，以及每版更新日志里给出的夸克网盘链接，其他地方的「青简」都不是官方发布的；青简目前没有上架任何包管理器。

## macOS

**系统要求**：macOS 13 或更新。Apple Silicon 与 Intel 各有一个安装包；不确定机型时，点左上角  → 「关于本机」，查看「芯片」一行。

1. 下载名字带 `arm64` 的安装包（Apple Silicon）或带 `x86_64` 的安装包（Intel），双击安装，需要输入管理员密码。
2. 测试版尚无 Apple 开发者签名，首次打开会被系统拦截：到「系统设置 → 隐私与安全性」，在底部点「仍要打开」，再安装一次。
3. 安装完成后，输入法菜单中出现「青简」。

若未出现，先注销后重新登录（系统在登录时才刷新输入法列表）；仍未出现，再到「系统设置 → 键盘 → 输入法 → 编辑 → +」，在「简体中文」下添加「青简」。

安装后：

- 菜单栏右上出现「中 / 英」状态项，点击可打开输入法菜单与设置。
- 首次使用先到「设置 → 候选」的「译文」选择学习语言，候选旁的译词即为该语言，见 [候选旁的译词](../learning/translation.md)。

### 直接替换 app 后行为不对：重新添加一次

不用安装包、直接替换青简的 app 之后，系统可能还在用旧的登记：青简能选中，行为却跟新版对不上。这时：

1. 「系统设置 → 键盘 → 输入法 → 编辑」里移除青简；
2. 注销并重新登录；
3. 重新添加青简。

用安装包安装不用这样做，每次安装都会重新登记。

## Windows

**系统要求**：64 位 Windows 10（1809 或更新）或 Windows 11。安装包已带齐所需组件，不必另装。

1. 下载名字以 `setup.exe` 结尾的安装包，双击安装，需要管理员权限。
   安装位置保持默认（`C:\Program Files\Qingjian`），不要改到其他目录或其他盘：装在别处时，候选窗口在开始菜单、任务栏搜索框这类系统界面中会被压在下面。
2. 测试版尚无正式的代码签名，SmartScreen 会拦截：点「更多信息 → 仍要运行」。
3. 安装完成后，青简出现在输入法列表中（任务栏右下的「中 / 英」或「拼」处，或按 `Win + Space` 切换），位于「中文(简体)」之下。

安装后：

- 任务栏右下显示当前为「中」或「英」；桌面上可另开一条悬浮状态条，见 [中英文](../input/english-mode.md#悬浮状态条（Windows）)。
- 设置在开始菜单的「青简设置」，或悬浮状态条上的 ⚙。
- 首次使用先到「设置 → 候选」的「译文」选择学习语言。

若某个程序中无法切换到青简，注销后重新登录，或重启该程序。

**已知问题**：测试版没有正式的代码签名，在开始菜单、任务栏搜索框、「设置」等系统界面中，候选窗口可能被遮挡而看不见；输入与上屏不受影响。此问题将在签名版中解决。

## 升级

直接安装新版安装包，学习数据与设置均保留。

Windows 上，**升级前已经打开的程序要重新打开才会用上新版**：在其中切走输入法再切回没有用；资源管理器重启后，任务栏搜索框才用上新版。
只改设置不受此影响，改完一秒内生效。

卸载见 [卸载](../help/uninstall.md)。
