两个平台功能相同，按键按各自系统的习惯设计。表中 `⌥` 为 Option，`⌘` 为 Command，`⌃` 为 Control，`⇧` 为 Shift；
「—」表示该平台没有此键。

## 切换模式

| 操作 | macOS | Windows |
|---|---|---|
| 中 / 英切换 | `Caps Lock` | 单击 `Shift`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 直接输入大写英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） |
| 输入拼音时临时输入一个大写字母 | `⇧ + 字母`：拼音原样上屏，再输入该大写字母 | 同左 |
| 切换全角 / 半角标点 | 中文全角、英文半角，不可更改 | 点击悬浮状态条上的「，。」格，中英各记一份 |
| 切换到其他输入法 | `⌃ + Space`（系统） | `Win + Space`（系统） |

## 输入拼音时

| 操作 | macOS | Windows |
|---|---|---|
| 上屏高亮候选（无候选时上屏拼音） | `Space` | `Space` |
| 上屏当前页第 N 个 | `1` 至 `9` | `1` 至 `9` |
| 将拼音字母原样上屏 | `Enter` | `Enter` |
| 删除光标前一个字母 | `Backspace` | `Backspace` |
| 删除光标后一个字母 | `Delete` | — |
| 删除光标前一个音节 | `⌥ + Backspace` | — |
| 删除光标前全部拼音 | `⌘ + Backspace` | — |
| 清空 | `Esc` | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` | `↑` / `↓` |
| 翻页 | `[` `]`、`PageUp` / `PageDown`、`⇧ + Tab`（上一页） | `[` `]`、`PageUp` / `PageDown` |
| 接受云端整句补全 | `Tab`；无补全时翻页 | `Tab`；无补全时交给应用 |
| 移动拼音光标 | `←` / `→` | `←` / `→` |
| 按音节移动光标 | `⌥ + ←` / `⌥ + →` | — |
| 光标移到开头 / 末尾 | `⌘ + ←` / `⌘ + →`，或 `Home` / `End` | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；上屏后其余拼音保留，光标移到末尾。
若前面某个音节输入有误，macOS 上可按 `⌥ + ←` 移到其后、`⌥ + Backspace` 删除后重输、`⌘ + →` 回到末尾。

翻页键对可改为 `,` `.`：「偏好设置 → 快捷键」。

## 英文模式下

| 操作 | macOS | Windows |
|---|---|---|
| 选择高亮候选 | `Tab` | `Tab` |
| 移动高亮 | `↑` / `↓` | `↑` / `↓` |
| 选择已移动到的高亮候选 | `Space` | `Space` |
| 原样输出所敲字母 | `Space`（未移动过高亮时）、`Enter`、标点 | 同左 |

英文模式下数字键即为数字，不选词。

## 译词与删除候选

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 数字` | `Ctrl + 数字` |
| 上屏第二条译词（候选右侧有两条时） | `⇧⌥ + 数字` | `Ctrl + Shift + 数字` |
| 删除第 N 个候选 | `⇧ + 数字` | `Shift + 数字` |

仅在输入拼音时有效。三组修饰键在「偏好设置 → 快捷键」（Windows：「设置 → 快捷键」）录制修改；
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页），Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获。
删除候选的说明见 [译词与生词](../learning/translation.md#删除不需要的候选)。

## 云联想

| 操作 | macOS | Windows |
|---|---|---|
| 翻译应用中选中的文字 | `⌃⌥T` | `Ctrl + Alt + T` |
| 翻译结果：替换选区 | `Enter` / `Space` / `1` | 同左 |
| 翻译结果：保留原文 | `Esc` | `Esc` |
| 问字 | 未输入拼音时输入 `?`，再输入拼音 | 同左 |

均需先打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。翻译快捷键可修改；Windows 上修改后需切换到其他输入法再切回青简才生效。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字 |
| `u` + 十六进制 | 该码点对应的字符 |
| `?` + 拼音 | 问字（需打开云联想） |

两个平台相同，详见 [快捷输入](../input/shortcuts.md)。`v` 与 `u` 可在「快捷键」页改为 v、u、i 三者之一。
