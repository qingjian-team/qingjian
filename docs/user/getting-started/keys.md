以下表格列出 macOS 与 Windows 的按键；Linux 按键见本页后面的「Linux（Fcitx4 / Fcitx5）」小节。表中 `⌥` 为 Option，`⌘` 为 Command，`⌃` 为 Control，`⇧` 为 Shift；
「—」表示该平台没有此键。

## 切换模式

| 操作 | macOS | Windows |
|---|---|---|
| 中 / 英切换 | `Caps Lock` | 单击 `Shift`（设置里还可勾单击 `Ctrl`、`Ctrl + Alt + Space`，可多选）；系统的 `Ctrl + Space`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 直接输入大写英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） |
| 输入拼音时临时输入一个大写字母 | `⇧ + 字母`：拼音原样上屏，再输入该大写字母；设置里可改成「进组句」：大写按小写参与匹配，`Cpan` 与 `cpan` 一样能出「C盘」 | 同左 |
| 切换全角 / 半角标点 | 中文全角、英文半角，不可更改 | 点击悬浮状态条上的「，。」格，中英各记一份；可在「设置 → 快捷键」启用 `Ctrl + .` |
| 切换到其他输入法 | `⌃ + Space`（系统） | `Win + Space`（系统） |

Windows 的「中 / 英切换」键在设置里勾选，可以多选：单击 `Shift`、单击 `Ctrl`（打字时容易误触 `Shift` 的话）、`Ctrl + Alt + Space`；这三项都不勾时，仍可使用已启用的系统 `Ctrl + Space` 和中 / 英按钮。中英模式缺省由所有应用共用。关掉「内置英文模式」后，切换键与任务栏、悬浮状态条上的「中」「英」都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法。

Windows 的主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

Windows 上中 / 英的切换键可以勾选（设置 → 中英文 → 切换键，配置 `[shortcut] switch_mode`，可多选）：**单击 Shift**（缺省，与微软拼音一致）、
**单击 Ctrl**（Shift 老是误触时用）、**Ctrl + Alt + Space**（组合键，最不易误触）；这三项都不勾时，仍可使用已启用的系统 Ctrl + Space 和任务栏 / 悬浮状态条上的「中」「英」按钮。
改完**立刻生效**；没在打字时 Shift 在其他组合键里的作用不受影响。系统自带的 `Ctrl + Space`（输入法/非输入法切换）也能切中英。在「设置 → 中英文 → 切换键」勾选 **Ctrl + Space（系统）** 即可启用，取消即可关闭；它读取并修改 Windows 当前用户的系统设置，也会影响微软拼音等简体中文输入法。其余切换键仅对青简生效。

还可以整个关掉**内置英文模式**（设置 → 中英文 → 英文模式，配置 `[general] english_mode`）：关掉后青简固定中文模式，
切换键与任务栏、悬浮状态条上的按钮都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法。
详见 [英文模式](../input/english-mode.md)。

## 输入组句时（拼音 / 注音 / 五笔）

微软 / 搜狗双拼用 `y` 输入 ü：`ny` / `ly` 对应女 / 绿，`jy` / `qy` / `xy` / `yy` 对应 ju / qu / xu / yu；原来的 `ju` / `qu` / `xu` / `yu` 也可继续使用。各方案说明见 [模糊音与输入方案](../input/fuzzy-and-shuangpin.md)。

| 操作 | macOS | Windows |
|---|---|---|
| 上屏高亮候选（无候选时上屏所敲的拼音 / 注音 / 编码） | `Space` | `Space` |
| 上屏当前页第 N 个 | `1` 至 `9` | `1` 至 `9` |
| 用鼠标上屏（青简渲染器） | 点候选上屏它；点候选右侧的译词上屏那一条译词 | 同左 |
| 将敲的字母 / 注音符号原样上屏 | `Enter` | `Enter` |
| 上屏高亮候选并接全角标点 | 组句中的 `,` `.` `?` `!` 等会转全角的标点（翻页键除外；需勾选「组句中标点先上屏候选」，`[general] punct_commits`，缺省关）；`'` 是隔音符，`-` `/` `@` 等不转的符号进英文直输 | 同左 |
| 删除光标前一个字母 / 注音 / 编码 | `Backspace` | `Backspace` |
| 删除光标后一个字母 | `Delete` | — |
| 删除光标前一个音节（五笔下是整段编码，同左的「全部」） | `⌥ + Backspace` | — |
| 删除光标前全部拼音 | `⌘ + Backspace` | — |
| 清空 | `Esc`（打开「横排时 ↑ / ↓ 展开成多行」且矩阵展开着时，第一下先收回单行） | `Esc`（同左） |
| 清除辅码（保留拼音与候选） | `Esc` | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` | `↑` / `↓`（可改成 `←` / `→`，见下） |
| 打开符号面板 | 打字后高亮还在第一个、没动过时按 `↑`（长按连发不算）；横排矩阵开关打开时也是这一下开面板，`↓` 照旧展开矩阵；也可以点菜单栏输入法菜单里的「符号面板…」 | 打字后高亮还在第一个、没动过时按 `↑`；也可以点悬浮状态条上的「符」，或右键任务栏「中 / 英」图标选「符号面板…」 |
| 符号面板里 | `↑` `↓` `←` `→` 移动，`Tab` / `⇧ + Tab` 换「搜索 / 符号 / 表情」组，`[` `]` 换分类，`PageUp` / `PageDown` 翻屏，`Space` / `Enter` / 数字键 / 双击上屏，单击格子移动高亮、单击标签换组换类，鼠标滚轮或触控板逐行滚动，`Esc` / `Backspace` / 右上角 ✕ 回到候选，敲字母收起面板接着打字 | 同 macOS（`Shift + Tab` 换上一组，配置的翻页键也能换分类） |
| 横排展开成 6 行矩阵并换行（macOS 需先在「设置 → 外观」勾选「横排时 ↑ / ↓ 展开成多行」，Windows 在「设置 → 候选窗口」勾「多行展开」，缺省关） | `↑` / `↓`；`←` / `→` 在候选之间移动（单行、展开后都是），`←` 顶在第一个候选上退回拼音行（光标移回末尾后 `→` 恢复移动候选），第一排再按 `↑` 回到第一个候选，移出矩阵上下边缘时按行滚动 | 同左 |
| 翻页 | `[` `]`、`PageUp` / `PageDown`、`⇧ + Tab`（上一页） | `[` `]`、`PageUp` / `PageDown`、`Shift + Tab`（上一页） |
| 进入辅码状态并输入码 | `;`（可改为其他单个可见字符），之后直接输入码字母 | 同左 |
| 接受云端整句补全 | `Tab`；无补全时翻页 | `Tab`；无补全时下一页 |
| 移动拼音光标 | `←` / `→`（可改成高亮键，见下；打开横排展开开关后，横排下这两个键先移动候选高亮；`←` 顶到第一个候选后接着按可移动拼音光标，`→` 移回末尾后恢复移动候选） | `←` / `→`（可改成高亮键，见下；打开横排展开开关后同 macOS） |
| 按音节移动光标 | `⌥ + ←` / `⌥ + →` | — |
| 光标移到开头 / 末尾 | `⌘ + ←` / `⌘ + →`，或 `Home` / `End` | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；上屏后其余拼音保留，光标移到末尾。
若前面某个音节输入有误，macOS 上可按 `⌥ + ←` 移到其后、`⌥ + Backspace` 删除后重输、`⌘ + →` 回到末尾；打开横排展开开关后，`←` 顶到第一个候选后也轮到拼音光标，改完按 `→` 移回末尾即回到候选。

「设置 → 快捷键 → 高亮移动键」（配置 `[shortcut] highlight_keys`）可以换高亮归哪对键管：
选 `←` / `→` 时这两键连着拼音行一起走——拼音光标到末尾再按 `→` 才移到下一个候选，候选在首位再按 `←` 才退回拼音行，
两键都在头时那一下没有去处；此时 `↑` / `↓` 在组句中不做事（不组句时照常交给应用）。
缺省是 `↑` / `↓` 移高亮、`←` / `→` 移拼音光标，与以前一致；中英文组句都适用。

### 注音模式（Windows）

「设置 → 输入」的「拼音」选「大千注音」后，组句中的按键改为：

| 操作 | Windows |
|---|---|
| 上屏高亮候选 | `Enter` |
| 将注音符号原样上屏 | `Shift + Enter` |
| 一声 / 轻声 | `Space` |
| 声调与符号（进入组句，不选词） | 数字键，`-` `;` `,` `.` `/` |

大千键盘布局把数字键与 `- ; , . /` 都分给了注音符号和声调，所以注音模式下这些键不再选词，选词用 `Enter`；`Space` 是一声。macOS 暂无注音模式。

> **五笔（形码）**：组句时敲的是字根编码，没有音节的概念，所以「删到音节边界」「拼音行分段」这些不适用，
> 左右键按单个字母移动光标。整句输入、简拼、模糊音、拼写纠错在五笔下都不生效，
> `v` / `u` / `i` 也不再是模式键（它们是字根键）。选词、翻页、上屏、删除候选与拼音一致。
> 拼音方案与五笔**同时开着**是混输：两边都出候选、编码打全的五笔词在前，见 [模糊音与输入方案](../input/fuzzy-and-shuangpin.md)。

翻页键对可改为 `,` `.` 或 `-` `=`：「设置 → 快捷键」。选 `-` `=` 时**翻不动就落回原语义**：
组句中没有上一页时 `-` 就是 `-`（进英文直输段），没有下一页时 `=` 就是 `=`，不会白吃键；`[` `]` `,` `.` 作翻页键时翻不动也照旧吃键（落字会往文档里插标点）。
Windows 的英文候选里 `-` 也是这样：有上一页时翻页，第一页上按 `-` 就是单词里的连字符（`well-known`）；`=` 翻不动照旧吃键。

Windows 还可在「设置 → 快捷键 → 额外翻页键」同时勾选多组，与主翻页键并用。
这些符号在拼音候选中优先翻页；表达式的运算符、英文直输段和辅码触发键保持原有规则。
配置写在 `[shortcut] extra_page_keys`，例如 `["[]", ",.", "-="]`；缺省为空。

Windows 的标点切换快捷键由 `[shortcut] toggle_punctuation` 控制：空串关闭，`"ctrl+."` 为 Ctrl + 句号。
也可改成修饰键加字母、数字或句号，例如 `"ctrl+shift+."`。更改后立即生效；快捷键切换的是当前中英模式的标点，
不改变字母、数字的宽度，也不改变中英状态。缺省关闭，不占用应用自己的快捷键。

升级后，已经打开的应用仍可能使用旧版输入模块；请保存内容并重新打开该应用，再使用新增的标点快捷键。

## 英文模式下

| 操作 | macOS | Windows |
|---|---|---|
| 选择高亮候选 | `Space`、`Tab` | `Space`、`Tab` |
| 选择第 N 个候选（当前页没有第 N 个时，数字作为内容接在所敲字母后，如 `gpt6`） | 数字键 | 数字键 |
| 移动高亮 / 翻页 | `↑` / `↓`、翻页键 | `↑` / `↓`、翻页键 |
| 原样输出所敲字母 | `Enter`、标点 | 同左 |

没有候选时数字直接接在字母后（`xq1`）；带数字的标识符先按 `Enter` 输出字母再敲数字。

## 译词与删除候选

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 数字` | `Ctrl + 数字` | `Alt + 数字` |
| 上屏第二条译词（词条有第二条时） | `⇧⌥ + 数字` | `Ctrl + Shift + 数字` | `Alt + Shift + 数字` |
| 删除第 N 个候选 | `⇧ + 数字` | `Shift + 数字` | `Shift + 数字` |

仅在组句时有效。三组修饰键在「设置 → 快捷键」录制修改；Linux 也可在配置文件的 `[shortcut]` 中修改。
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页），Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获。
删除候选的说明见 [译词与生词](../learning/translation.md#删除不需要的候选)。

## 云联想

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 翻译应用中选中的文字 | `⌃⌥T` | `Ctrl + Alt + T` | `Alt + Shift + T` |
| 翻译结果：替换选区 | `Enter` / `Space` / `1` | 同左 | 同左 |
| 翻译结果：保留原文 | `Esc` | `Esc` | `Esc` |
| 问字 | 输入 `u`（双拼下 `Shift`+`U`）再输入拼音；勾选「敲 ? 也进入问字」后未输入拼音时输入 `?` 再接拼音同样可用 | 同左 | 同左 |

均需先打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。翻译快捷键可修改；Windows 上修改后需切换到其他输入法再切回青简才生效。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字与金额（`v123.5` → 壹佰贰拾叁元伍角）；双拼下以 `Shift`+`V` 开头 |
| `u` + 十六进制 | 该码点对应的字符；双拼下以 `Shift`+`U` 开头 |
| `u` + 拼音 | 问字（需打开云联想）；`?` + 拼音需在「快捷键」页勾选后可用 |

两个平台相同，详见 [快捷输入](../input/shortcuts.md)。`v` 与 `u` 可在「快捷键」页改为 v、u、i 三者之一。

## Linux（Fcitx4 / Fcitx5）

单击 `Shift` 切换中英；按住 `Shift` 输入字母不会切换。`Space`、`1` 至 `9` 以及候选点击选词，
全拼 / 双拼下 `Enter` 原样输出，`Backspace` / `Delete` 编辑，`Esc` 取消，方向键移动高亮或光标。
`[` / `]` 和 `PageUp` / `PageDown` 翻页。配置文件的 `[general] page_keys` 可选 `"[]"`、`",."`、`"-="`，
前一个字符上一页、后一个下一页，保存后约一秒内生效；示例见 [Linux 翻页键](linux.md#翻页键)。
Fcitx5 的全局候选翻页热键不会替代青简的这项配置。`"-="` 指 `-` / `=` 字符，不包含按住 Shift 输入的 `_` / `+`。
选 `",."` 后，中文组句中逗号句号用于翻页而不是上屏加标点；选 `"-="` 后，中文组句中的 `-` 用于翻页，不再进入英文直输段。

Linux 的 `Tab` 规则：没有组句时 `Tab` / `Shift + Tab` 交给应用；中文组句中 `Tab` 接受整句补全，
无补全时下一页；英文组句中 `Tab` 选择高亮候选；组句中的 `Shift + Tab` 始终上一页。
云联想开启后，云端整句补全显示在候选面板的辅助行。裸问号的既有还原规则优先。

数字选择当前页对应候选；当前页没有这一格时数字接入缓冲区，`hao6` 回车可原样输出。
组句中会转全角的标点（`,` `.` `?` `!` 等）上屏高亮候选并接全角标点，不可转的符号（`-` `/` `@`）进入英文直输段，
进入英文直输段后数字和标点继续追加，`gpt-6` 后按空格得到 `gpt-6 `。
英文候选开启时，数字、翻页键和空格同样可选词，空格选词后保留一个空格。
小键盘运算符保持半角；关闭 NumLock 时按导航键处理。

`[general] shift_letter = "compose"` 可让大写字母参与中文组句，默认原样输入大写英文。
双拼下 `Shift + V` 进入表达式模式，`Shift + U` 可输入码点或问字；入口字母可在 `[shortcut]` 修改，问字需开启云联想。
大千注音（`[general] scheme = "zhuyin"`）下，数字及 `- ; , . /` 输入符号和声调，空格补一声，再按空格可选词；
`Enter` 选高亮，`Shift + Enter` 原样输出注音。

Linux 的直接输出译词、删除候选快捷键见上表；安装与配置位置见 [Linux](linux.md)。
选中应用文字后按 `Alt + Shift + T` 可调用云翻译；Fcitx5 需要应用提供选区，Fcitx4 在 X11 下还可读取当前应用的系统选区。快捷键可用 `[shortcut] translate_selection` 修改。

## Windows 默认模式与按应用记忆

在「设置 → 中英文」可启用默认英文和[按应用记忆](../input/english-mode.md#默认模式与按应用记忆（Windows）)。
启用后，新应用使用选定的默认模式，切回应用时恢复它上次的中英状态；同一应用的窗口共用记录，重启青简后重置。

Windows 开启云联想后，在组句中按 **Ctrl+Alt+J** 手动请求 AI 候选，结果放在首页前面的空位；自动联想补在首页末尾，空格仍选本地首项。开始移动高亮或翻页后，晚到结果保持当前候选顺序。快捷键可在设置中改修饰键，配置文件 `[shortcut] predict` 可修改完整组合。
