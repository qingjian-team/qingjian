本页只列按键。表中 `⌥` 为 Option，`⌘` 为 Command，`⌃` 为 Control，`⇧` 为 Shift；「—」表示该平台没有此键。
可以改的键见 [改按键](../personalize/keys-settings.md)；Android 是屏幕键盘，见 [Android](../platforms/android.md)。

## 切换

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 中 / 英切换 | `Caps Lock` | 单击 `Shift`；系统的 `Ctrl + Space`；点任务栏或悬浮状态条上的「中 / 英」 | 单击 `Shift` |
| 直接输入大写英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） | `Caps Lock` 亮起 |
| 输入拼音时临时打一个大写字母 | `⇧ + 字母` | `Shift + 字母` | `Shift + 字母` |
| 切换全角 / 半角标点 | 可启用 `⌃ + .`（缺省关） | 点悬浮状态条上的「，。」格；可启用 `Ctrl + .`（缺省关） | — |
| 切换到其他输入法 | `⌃ + Space`（系统） | `Win + Space`（系统） | Fcitx 的切换热键 |

Windows 与 Linux 的中 / 英切换键还可以选单击 `Ctrl` 或 `Ctrl + Alt + Space`，见 [中英文](../input/english-mode.md#改掉或关掉中-英切换)。

## 打拼音时

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 上屏高亮候选 | `Space` | `Space` | `Space` |
| 上屏当前页第 N 个 | `1` 至 `9` | `1` 至 `9` | `1` 至 `9` |
| 用鼠标上屏 | 点候选；点候选右侧的译词则上屏那条译词 | 同左 | 点候选 |
| 将敲的字母原样上屏 | `Enter` | `Enter` | `Enter` |
| 删除光标前一个字母（分几次选词时先撤回最后一次选择） | `Backspace` | `Backspace` | `Backspace` |
| 删除光标后一个字母 | `Delete` | — | `Delete` |
| 删除光标前一个音节 | `⌥ + Backspace` | — | — |
| 删除光标前全部拼音 | `⌘ + Backspace` | — | — |
| 清空 | `Esc` | `Esc` | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` | `↑` / `↓` | `↑` / `↓` |
| 翻页 | `[` `]`、`PageUp` / `PageDown`、`⇧ + Tab`（上一页） | `[` `]`、`PageUp` / `PageDown`、`Shift + Tab`（上一页） | 同 Windows |
| 接受 AI 整句补全（无补全时下一页） | `Tab` | `Tab` | `Tab` |
| 移动拼音光标 | `←` / `→` | `←` / `→` | `←` / `→` |
| 按音节移动光标 | `⌥ + ←` / `⌥ + →` | — | — |
| 光标移到开头 / 末尾 | `⌘ + ←` / `⌘ + →`，或 `Home` / `End` | `Home` / `End` | `Home` / `End` |
| 打开符号面板 | 高亮还在第一个时按 `↑`（横排且高亮移动键选了 `←` / `→` 时，先按 `↑` 移到拼音里再按一次） | 同左 | — |
| 进入辅码 | `;` | `;` | — |
| 横排时展开成多行（需在设置中打开） | `↑` / `↓` | `↑` / `↓` | — |

光标停在拼音中间时，候选只按光标之前的拼音计算（`ni|hao` 出「你」）；上屏后其余拼音保留，光标移到末尾。
大千注音与五笔下有几个键不同，见 [拼音方案与模糊音](../input/fuzzy-and-shuangpin.md#大千注音) 与 [五笔与混输](../input/wubi.md)。

## 符号面板里

| 操作 | 按键 |
|---|---|
| 移动 | `↑` `↓` `←` `→` |
| 换「搜索 / 符号 / 表情」组 | `Tab` / `⇧ + Tab` |
| 换分类 | `[` `]` |
| 翻屏 | `PageUp` / `PageDown` |
| 上屏 | `Space`、`Enter`、数字键或双击 |
| 回到候选 | `Esc`、`Backspace` 或右上角 ✕ |

敲字母则收起面板接着打字。详见 [标点、符号与表情](../input/punctuation.md#符号面板)。

## 英文模式下

| 操作 | macOS / Windows / Linux |
|---|---|
| 选择高亮候选 | `Space`、`Tab` |
| 选择第 N 个候选（当前页没有第 N 个时，数字接在所敲字母后，如 `gpt6`） | 数字键 |
| 移动高亮 / 翻页 | `↑` / `↓`、翻页键 |
| 原样输出所敲字母 | `Enter`、标点 |

## 译词与右键菜单

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 数字` | `Ctrl + 数字` | `Alt + 数字` |
| 上屏第二条译词（词条有第二条时） | `⇧⌥ + 数字` | `Ctrl + Shift + 数字` | `Alt + Shift + 数字` |
| 置顶 / 降权 / 删除候选 | 右键候选，或 `⌃` 点按 | 右键候选 | 暂不支持 |

只在打拼音时有效。见 [候选旁的译词](../learning/translation.md#直接上屏译词) 与 [输入习惯](../personalize/habits.md#候选右键菜单)。

## AI 服务

以下都要先开启 AI 服务，见 [AI 服务](../cloud/index.md)。

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 翻译应用中选中的文字 | `⌃⌥T` | `Ctrl + Alt + T` | `Alt + Shift + T` |
| 翻译结果：替换选区 | `Enter` / `Space` / `1` | 同左；兼容模式按这些键复制译文，再自行 `Ctrl+V` 粘贴 | 同左 |
| 翻译结果：保留原文 | `Esc` | `Esc` | `Esc` |
| 打拼音时手动要 AI 候选 | `⌃⌥J` | `Ctrl + Alt + J` | — |
| 问字 | `u` 再输入拼音 | 同左 | 同左 |

Windows 配套版本等待译文时，提前按 `Enter`、`Space` 或 `1` 会继续等待；译文出现后再按一次确认。

## 前缀

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式、数字或日期 | 算式结果、中文数字与金额、中文日期 |
| `u` + 十六进制 | 该编号对应的字符 |
| `u` + 拼音 | 问字（需开启 AI 服务） |

三个平台相同，详见 [日期、算式与特殊字符](../input/shortcuts.md)。双拼与混输下 `v`、`u` 改为 `Shift + V`、`Shift + U`。
