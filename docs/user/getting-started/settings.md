## 打开设置

- **macOS**：输入法菜单（菜单栏「中 / 英」状态项，或系统输入源菜单中青简的几项）中的「设置…」。
- **Windows**：开始菜单的「青简设置」，或悬浮状态条上的 ⚙。
- **Linux**：应用菜单中的「青简设置」。

改动即时生效，没有「保存」按钮，也不用重新切换输入法。

左上角的搜索框可按设置项名称、选项文字或说明中的词查找，例如搜「英语」可找到「译文」。点击结果（或按 `Enter` 选第一条）跳到对应页并标出该项，`Esc` 清空搜索。
标题旁的 ⓘ：鼠标悬停显示简短说明，点击打开本文档中对应的段落。

只在某个平台有的设置项，在别的平台不显示；依赖别的设置的项（例如字体只对青简渲染器生效）显示为灰色。

## 输入法菜单（macOS）

点菜单栏的「中 / 英」状态项打开：云联想开关、模糊音子菜单、符号面板（在光标处打开）、设置、旧版设置、打开日志目录、版本号。有新版本时也在这里提示。

## 任务栏图标（Windows）

右键任务栏的「中 / 英」图标：切中文 / 英文、全角标点、显示或隐藏悬浮状态条、打开符号面板、打开设置或旧版设置。有新版本时也在这里提示。

## 旧版设置

本版本保留旧的设置窗口作为备用，新设置窗口打不开或某项不生效时可改用它：macOS 输入法菜单中的「旧版设置…」；Windows 任务栏图标右键菜单中的「旧版设置…」，或开始菜单中的「青简旧版设置」。
两者修改同一份设置。旧版设置将在之后的版本移除；遇到需要改用旧版的情况，请[反馈](../help/feedback.md)。
