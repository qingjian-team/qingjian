「偏好设置 → 统计」有两块：

## 输入量

今天 / 最近 7 天 / 累计打了多少汉字、多少中文词、多少英文词、上屏多少次；累计字数再折成「约等于 n 本《某书》」，书目从《道德经》到《平凡的世界》。
这些只是几个数字，按天记在本机，与输入日志无关：日志关掉或清空，统计还在。

## 词汇

见过 / 看熟 / 上屏过 / 打出过 / 本周新见的译词数，再按等级分行列出词表总数与你的进度：

- 英语：CEFR A1 到 C2（CEFR-J 词表 1.5 加 Octanove C1/C2，8,845 词）。
- 日语：JLPT N5 到 N1（7,757 词）。

等级只在统计页出现，不进候选窗口。词汇记录里只有译词本身和次数，不含你打的中文。
