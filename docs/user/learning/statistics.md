「设置 → 统计」顶上分「输入」和「云服务」两层；云服务只在 macOS 与 Windows 上有。

## 输入量

- 四张数字卡：今天、本周（从周日算）、本月、累计输入的汉字数、中文词数、英文词数。
- 近一年：一格一天、一列一周（周日在上），颜色越深那天打的字越多；指针停在格子上显示日期与字数。
- 过去 24 小时：每小时一根柱，最右边是现在这个钟点；指针停在柱上显示那个小时的字数。
- 输入详情：
  - 最多的一天、有输入的日子平均打多少字。
  - 速度（字 / 分钟）：今天、平均、最快的一天。只算在打字的时间，键与键之间停顿超过 5 秒的那段不算。
  - 首选率：从候选里选词时，选的就是第一个的比例。
  - 一次打对：选词上屏前没按过退格、没删过的比例。
  - 平均码长：每个汉字平均敲几键。
  - 累计字数折算为「约等于 n 本《某书》」，书目从《道德经》到《平凡的世界》。

速度、首选率、一次打对和码长从 0.2.2 起才记，更早的记录只有字数。

这些只是若干数字，按小时记录在本机，与输入日志无关：关闭或清空日志后统计仍在。每次上屏当场写进文件，输入法被强制退出或电脑突然关机也不会丢之前的记录。

## 词汇

见过 / 已熟悉 / 上屏过 / 输出过 / 本周新见的译词数，再按等级列出词表总数与当前进度：

- 英语：CEFR A1 至 C2（CEFR-J 词表 1.5 加 Octanove C1/C2，8,845 词）。
- 日语：JLPT N5 至 N1（7,757 词）。

等级只在统计页显示，不进入候选窗口。词汇记录中只有译词本身与次数，不含输入的中文。

## 云服务用量

「云服务」层与输入层一样：今天、本周、本月、累计四张数字卡（Token 数与请求次数），近一年每天的 Token、过去 24 小时每小时的 Token；
详情里是最多的一天、累计请求、收到响应、失败、还没有结果的次数，以及输入、输出、合计 Token 和其中的缓存输入。每次进入统计页读取最新记录，重启后累计值保留。
按天、按小时的图从 0.2.2 起才有，更早的用量只在累计里。macOS 从 0.2.2 起记用量，Linux 的输入法还没接云服务。

统计包含组句云联想、译词自动补充、选中文字翻译和测试连接。每次实际发送分别计数，兼容重试计两次；未发送的取消及缓存复用不记请求，已发送的请求按实际计数。缓存输入已包含在输入 Token 中；接口未返回用量时记为未知。启用统计前的历史用量可在服务商平台查看。
