「设置 → 统计」顶上分「输入」和「云服务」两层；云服务一层只在 macOS 与 Windows 上有。Android 的统计在青简应用首页，见 [Android：生词本与设置](../platforms/android-settings.md#生词本与统计)。

## 输入量

- 四张数字卡：今天、近 7 天、本月、累计输入的汉字数、中文词数、英文词数。近 7 天含今天，按天滚动，不在周一或周日归零。
- 近一年：一格一天、一列一周（周日在上），颜色越深那天打的字越多；指针停在格子上显示日期与字数。
- 过去 24 小时：每小时一根柱，最右边是现在这个钟点；指针停在柱上显示那个小时的字数。
- 输入详情：
  - 最多的一天、有输入的日子平均打多少字。
  - 速度（字 / 分钟）：今天、平均、最快的一天。只算在打字的时间，键与键之间停顿超过 5 秒的那段不算。
  - 首选率：从候选里选词时，选的就是第一个的比例。
  - 一次打对：选词上屏前没按过退格的比例。
  - 平均码长：每个汉字平均敲几键。
  - 累计字数折算为「约等于 n 本《某书》」，书目从《道德经》到《平凡的世界》。

速度、首选率、一次打对和码长从 0.2.2 起才记，更早的记录只有字数。

统计只是若干数字，按小时记录在本机，与输入日志无关：关闭或清空输入日志后统计仍在。每次上屏当场记下，输入法被强制退出或电脑突然关机也不会丢之前的记录。

## 词汇

见过 / 已熟悉 / 上屏过 / 输出过 / 近 7 天新见的译词数，再按等级列出词表总数与当前进度：

- 英语：CEFR A1 至 C2（共 8,845 词）。
- 日语：JLPT N5 至 N1（共 7,757 词）。

等级只在统计页显示，不进入候选窗口。词汇记录中只有译词本身与次数，不含输入的中文。

## AI 服务用量

「云服务」一层和输入层一样：今天、近 7 天、本月、累计四张数字卡（Token 数与请求次数），近一年每天、过去 24 小时每小时的 Token 数。
Token 是 AI 服务商计费的单位，大致与发送和收到的字数成正比。
详情里是最多的一天、累计请求、收到响应、失败、还没有结果的次数，以及输入、输出、合计 Token 和其中命中缓存的输入。每次进入统计页读取最新记录，重启后累计值保留。

- 计入的有：云联想、自动补充译词、生词本整句翻译、翻译选中的文字和「测试连接」。每次实际发出的请求都算，自动重试的那一次单独算；取消了没发出的、用了缓存结果的不算。
- 服务商没有返回用量时记为「未知」。
- 按天、按小时的图从 0.2.2 起才有，更早的用量只在累计里。开始记录之前的用量可在服务商的网站上查看。
