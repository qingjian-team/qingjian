「偏好设置 → 统计」显示输入量与词汇；Windows 还提供 Token 使用统计。

## Token 使用统计（Windows）

显示本机累计 API 请求次数、成功与失败次数，以及输入、输出、总 Token 和缓存输入。打开页面或点击「刷新统计」可查看最新数据，重启输入法或电脑后仍保留。

用量取自服务商返回的数据，包含 AI 联想与「测试连接」。缓存输入属于输入 Token，已包含在总量中。失败或接口未提供用量的请求单独标为用量未知；尚未取得结果的请求另列。统计从安装支持此功能的版本后开始，之前的用量可在服务商平台查看。

只在本机保存计数，与输入日志无关；统计文件不含输入文字或 API 密钥。

## 输入量

今天 / 最近 7 天 / 累计输入的汉字数、中文词数、英文词数、上屏次数；累计字数另折算为「约等于 n 本《某书》」，书目从《道德经》到《平凡的世界》。
这些只是若干数字，按天记录在本机，与输入日志无关：关闭或清空日志后统计仍在。
