## 译词

每个候选右侧最多一条译词，带词性。语言由「偏好设置 → 通用」的学习语言决定，英语或日语，一次只有一种。

- 英语：`开发` → v. develop · v. exploit。
- 日语按汉字段注平假名：`开发` → v. 開発(かいはつ)する。

没有译词的行留空，不显示占位符。随包释义表覆盖整个词库；开了 [云联想](../cloud/index.md) 后，表里没有的词在你打出它之后会自动补一条。

## 生词

**橙色的译词是生词**：它在你上屏时出现在候选窗口里的轮次还不到三次。看熟了自动变回灰色，不加图标、不弹提示。
只按上屏那一刻屏幕上那一页算，逐键刷新时一闪而过的不算。

## 快捷键

| 快捷键 | 行为 |
|---|---|
| `⌥ + 1` 到 `9` | 上屏第 N 个候选的第一条译词，而不是候选本身 |
| `⇧⌥ + 1` 到 `9` | 上屏第二条译词（候选右侧有两条时）；日文不带注音 |
| `⇧ + 1` 到 `9` | 删掉第 N 个候选：自己造的词、云端选过的词整个删；词库里的词清掉对它的全部学习，回到原来的排序 |
| `⌃⌥T` | 翻译应用里选中的文字，需要开云服务，见 [问字与翻译](../cloud/question-and-translate.md) |

删候选后，拼音行下方会闪一句结果（「已删除用户词「…」」，或词库词没学习记录时的「没什么可删」），敲下一个键就消失。

三组修饰键都在「偏好设置 → 快捷键」录制修改，避开 `⌃ + 数字`（系统切桌面）和 `⌘ + 数字`（应用切标签页）。
Windows 上 `⌥` 就是 `Alt`（`Alt + 数字` 上屏译词、`Shift + Alt + 数字` 第二条、`Shift + 数字` 删候选），在配置文件的 `[shortcut]` 一节里改；翻译选中文字还没接。

## 它怎么学你

- 选过的词、同一段拼音下选过哪个词、连着打的词序列，都在本机记下来，整句转换与排序据此调整。
- 连着选出的两个词合起来词库里没有、选够次数，就自动记成一个词。
- 全部在本机，不上传。文件在哪、怎么清见 [数据与日志](../help/data-and-logs.md)。
