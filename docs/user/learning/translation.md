## 译词

每个候选右侧最多一条译词，附词性。语言由「偏好设置 → 通用」的学习语言决定，英语、日语或西班牙语，一次只有一种；
选「不显示译文」则候选旁不出译词，生词标记与释义兜底也停，翻译选中的文字仍可用（译成英语）。

- 英语：`开发` → v. develop · v. exploit。
- 日语按汉字段标注平假名：`开发` → v. 開発(かいはつ)する。
- 西班牙语：`开发` → v. desarrollar。

没有译词的候选留空，不显示占位符。随包释义表覆盖整个词库；打开 [云联想](../cloud/index.md) 后，表中没有的词在输出后会自动补充一条。

## 译词难度与随机频率

macOS 在「偏好设置 → 通用」可以设置「英语译词难度」与「译词随机频率」。
难度有全部、基础（A1–A2）、进阶（B1–B2）、高级（C1–C2）四档。例如「高兴」可显示 `happy`、`delighted` 或 `elated`。
只在该中文词的已有译词中选择，不会把不相关的英文词塞进候选。没有目标等级的译词、或没有等级资料时，保留原有译词；未分级的词不自动算作高级。
难度筛选目前只用于英语，日语和西班牙语仍可随机选择已有译词。

随机频率是每个候选在新一段输入中随机抽取译词的概率：0% 保持固定顺序，50% 约一半输入轮次随机选，100% 每轮都抽样。
同一段拼音输入中，继续打字、移动高亮、翻页或刷新候选都保持同一词的译词稳定；下一次输入再重新抽样。随机抽样可能再次选到同一个词。
候选旁仍最多显示两条，直接输出译词的快捷键输出当前显示的那一条，生词记录也按实际显示的译词计算。
默认「全部难度 + 0%」，升级后沿用原来的显示方式；想经常接触高级词汇，可选「高级 + 100%」。

Windows 与 Linux 目前通过配置文件设置这两项，图形设置入口尚未提供。在「高级」页打开配置文件，在 `[general]` 下写入：

```toml
translation_difficulty = "advanced" # all / beginner / intermediate / advanced
translation_random_percent = 100   # 0–100
```

macOS 与 Windows 保存后自动生效；Linux 需重启青简后台服务。只有一条可用译词时，随机频率不会凭空增加新词。

## 生词

**橙色的译词为生词**：它在上屏时出现在候选窗口中的次数不足三次。达到三次后自动恢复灰色，不加图标、不弹出提示。
只按上屏那一刻屏幕上的那一页计算，逐键刷新时短暂出现的不计。

## 直接输出译词

输入拼音时，不选候选本身，而是输出其旁边的译词：

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 1` 至 `9` | `Ctrl + 1` 至 `9` |
| 上屏第二条译词（候选右侧有两条时；日文不带注音） | `⇧⌥ + 1` 至 `9` | `Ctrl + Shift + 1` 至 `9` |

学习记录与选中该候选相同。候选没有对应译词时按键无效。

## 删除不需要的候选

输入拼音时按 `⇧ + 数字`（Windows：`Shift + 数字`）删除当前页第 N 个候选：
用户自造的词、云端选过的词整个删除；词库中的词不删除，但清除对它的全部学习记录，恢复原始排序。
删除后拼音行下方短暂显示结果（「已删除用户词「…」」，或词库词无学习记录时的「没什么可删」），输入下一个键即消失。

## 翻译选中的文字

按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）将应用中选中的文字翻译为学习语言，需打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。

## 修改快捷键

上述三组修饰键与翻译快捷键均在「偏好设置 → 快捷键」（Windows：「设置 → 快捷键」）录制修改。
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页）；Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获，因此缺省使用 `Ctrl`。
全部按键见 [按键与快捷键](../getting-started/keys.md)。

## 学习方式

- 选过的词、同一段拼音下选过的词、连续输入的词序列，均在本机记录，整句转换与排序据此调整。
- 连续选出的两个词合起来不在词库中且选择次数达到阈值时，自动记为一个词。
- 全部在本机，不上传。文件位置与清除方式见 [数据与日志](../help/data-and-logs.md)。
