## 译词

每个候选右侧最多一条译词，附词性。语言由「设置 → 候选」的「译文」决定，英语、日语、西班牙语、越南语或德语，一次只有一种；
选「不显示译文」则候选旁不出译词，生词标记与释义兜底也停，翻译选中的文字仍可用（译成英语）。
Windows 上可在同一页关掉「译词显示词性」：候选旁只留译词，不再显示 v. / n. / adj. 等标注（`develop` 而非 `v. develop`）。

- 英语：`开发` → v. develop · v. exploit。
- 日语按汉字段标注平假名：`开发` → v. 開発(かいはつ)する。
- 西班牙语：`开发` → v. desarrollar。
- 越南语：`开发` → v. phát triển。
- 德语：`房子` → n. das Haus。

没有译词的候选留空，不显示占位符。随包释义表覆盖整个词库；打开 [云联想](../cloud/index.md) 后，表中没有的词在输出后会自动补充一条。

## 生词

**橙色的译词为生词**：它在上屏时出现在候选窗口中的次数不足三次。达到三次后自动恢复灰色，不加图标、不弹出提示。
只按上屏那一刻屏幕上的那一页计算，逐键刷新时短暂出现的不计。

## 生词本

设置的「生词本」页记着你打过的中文和它们在学习语言里的说法，分「时间线」和「词表」两个视图。私密输入（密码框等）中的内容不记。

**时间线**：按天排列，每次上屏一条，说法大字在上，中文在下，右侧是时刻。
- 上屏带译词的中文（两个字以上）时，记下它的第一条译词；用快捷键直接打出译词时记打出的那条。日语另显示假名读音。
- 整句没有现成译词。macOS 与 Windows 开着 [云联想](../cloud/index.md) 时，会在后台翻译后再记进时间线，通常几秒内出现；没开云联想，或在「云服务」页关了「生词本整句翻译」时，整句不记。
  一次上屏的整句，与分几次上屏、写完时（句末标点、切换应用或写满 80 字）有四个汉字以上的一句话，都按整句翻译。
- 顶部显示这天遇到了多少个词、其中几个是第一次见到的生词、已连续输入几天，以及按小时排列的「记忆色带」。点日期两旁的箭头翻到前后有记录的日子。
- 单个词的条目下面附有例句：它所在的那句话，从上一个句号、问号、感叹号或换行算起，到下一个为止；一直不打句号时到切换应用或写满 80 字为止。

**词表**：一个译词一行，显示中文、例句与看到、上屏的次数。
- **筛选与排序**：全部、生词、本周新见、认识了；按最近见到、次数或字母排；搜索框可搜译词、中文与例句。每页 50 个词。
- **认识了**：标了之后这个译词在候选里不再显示为生词，可随时取消。
- **删除**：从词表删掉这个词，之后再见到时重新记起。
- 生词本出现之前记下的英语词没有中文，词表里用随包的英→中释义补上显示。

**两个视图共用**：
- **语言**：按学习语言分开记，打开时显示当前的学习语言；记过几门语言时，顶上可以切换查看以前学过的语言。
- **导出**：把词表当前筛选与搜索出的词导出为 CSV（表格软件打开）、Anki 导入文件（正面译词，背面中文与例句）或网页（浏览器打开、打印）。
- **清空**：删掉正在查看的这门语言的全部记录，连同时间线，需点两次确认。

生词本只保存在本机的 `user-vocab.tsv` 与 `vocab-log.tsv`，见 [数据与日志](../help/data-and-logs.md)。

## 直接输出译词

输入拼音时，不选候选本身，而是输出其旁边的译词：

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 1` 至 `9` | `Ctrl + 1` 至 `9` | `Alt + 1` 至 `9` |
| 上屏第二条译词（词条有第二条时；日文不带注音） | `⇧⌥ + 1` 至 `9` | `Ctrl + Shift + 1` 至 `9` | `Alt + Shift + 1` 至 `9` |

也可以直接用鼠标点候选右侧的译词，点哪条上屏哪条（青简渲染器）。学习记录与选中该候选相同。候选没有对应译词时按键无效。 Linux 的 Fcitx 候选面板只显示第一条译词；词条有第二条时仍可用快捷键直接输出。此功能不需要开启云联想。

## 删除不需要的候选

输入拼音时按 `⇧ + 数字`（Windows / Linux：`Shift + 数字`）删除当前页第 N 个候选：
用户自造的词、云端选过的词整个删除；词库中的词不删除，但清除对它的全部学习记录，恢复原始排序。
删除后拼音行下方短暂显示结果（「已删除用户词「…」」，或词库词无学习记录时的「没什么可删」），输入下一个键即消失。

## 翻译选中的文字

按 `⌃⌥T`（Windows：`Ctrl + Alt + T`；Linux：`Alt + Shift + T`）将应用中选中的文字翻译为学习语言，需打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。

## 修改快捷键

上述三组修饰键与翻译快捷键在「设置 → 快捷键」修改；Linux 也可在配置文件的 `[shortcut]` 中修改。
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页）；Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获，因此缺省使用 `Ctrl`。
全部按键见 [按键与快捷键](../getting-started/keys.md)。

## 学习方式

- 选过的词、同一段拼音下选过的词、连续输入的词序列，均在本机记录，整句转换与排序据此调整。
- 连续选出的两个词合起来不在词库中且选择次数达到阈值时，自动记为一个词。
- 全部在本机，不上传。文件位置与清除方式见 [数据与日志](../help/data-and-logs.md)。
