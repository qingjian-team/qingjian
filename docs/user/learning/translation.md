## 译词

每个候选右侧最多一条译词，附词性。语言在「设置 → 候选」的「译文」里选：英语、日语、西班牙语、越南语或德语，一次只学一种。

- 英语：`开发` → v. develop · v. exploit。
- 日语按汉字段标注平假名：`开发` → v. 開発(かいはつ)する。
- 西班牙语：`开发` → v. desarrollar。
- 越南语：`开发` → v. phát triển。
- 德语：`房子` → n. das Haus。

- 同一页关掉「译词显示词性」后，候选旁只留译词，不显示 v. / n. / adj. 等标注（`develop` 而非 `v. develop`）。
- 选「不显示」则候选旁不出译词，生词标记与生词本也停；翻译选中的文字仍可用（译成英语）。
- 没有译词的候选留空，不显示占位符。随包的释义表覆盖整个词库；开启 AI 服务后，表里没有的词还可以[自动补一条](../cloud/sentence-translation.md#自动补充译词)。
- Linux 的候选面板只显示第一条译词。

## 生词

**橙色的译词是生词**：它在你上屏时出现在候选窗口中的次数还不到三次。到了三次自动变回灰色，不加图标、不弹提示。
只按上屏那一刻屏幕上的那一页计算，打字过程中一闪而过的不算。在生词本里标「认识了」的词不再显示为生词，见 [生词本](vocabulary.md)。

## 直接上屏译词

输入拼音时，可以不上屏中文，而是上屏它旁边的译词：

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 1` 至 `9` | `Ctrl + 1` 至 `9` | `Alt + 1` 至 `9` |
| 上屏第二条译词（词条有第二条时） | `⇧⌥ + 1` 至 `9` | `Ctrl + Shift + 1` 至 `9` | `Alt + Shift + 1` 至 `9` |

例如输入 `nihao`，候选「你好」旁显示 `hello` 时按 `⌥ + 1`，输出的就是 `hello`。

- macOS 与 Windows 也可以直接用鼠标点候选右侧的译词，点哪条上屏哪条。
- 上屏的只有译词本身，不带词性、日语的假名注音或生词标记：`v. 開発(かいはつ)する` 只输出 `開発する`。接着上一个英文、西班牙文这类用空格分词的词上屏译词时，前面自动隔一个空格（`hello` 后上屏 `world` 得 `hello world`）；日语译词不加。这条不受「中文与英文、数字之间自动加空格」开关影响。
- 候选没有译词时按键无效。不需要开启 AI 服务。
- 修饰键可在「设置 → 快捷键」改，见 [改按键](../personalize/keys-settings.md#译词与删除候选)。
