设置的「生词本」页记着你打过的中文和它们在学习语言里的说法，分「时间线」和「词表」两个视图。只保存在本机；密码框和应用标为私密的输入框里打的字不记。

## 时间线

按天排列，每次上屏一条，学习语言的说法大字在上，中文在下，右侧是时刻。

- 上屏带译词的中文（两个字以上）时，记下它的第一条译词；直接上屏译词时记上屏的那条。日语另显示假名读音。
- 整句没有现成的译词。macOS 与 Windows 开着 AI 服务时，会在后台把整句翻译后记进时间线，通常几秒内出现，见 [AI 补译](../cloud/sentence-translation.md#生词本整句翻译)；没开 AI 服务或关了这一项时，整句不记。
  一次上屏的整句，与分几次上屏、写完时（句末标点、切换应用或写满 80 字）有四个汉字以上的一句话，都按整句翻译。
- 顶部显示这天遇到了多少个词、其中几个是第一次见到的生词、已连续输入几天，以及按小时排列的「记忆色带」。点日期两旁的箭头翻到前后有记录的日子。
- 单个词的条目下面附有例句：它所在的那句话，从上一个句号、问号、感叹号或换行算起，到下一个为止；一直不打句号时到切换应用或写满 80 字为止。

## 词表

一个译词一行，显示中文、例句与看到、上屏的次数。

- **筛选与排序**：全部、生词、近 7 天新见、认识了；按最近见到、次数或字母排；搜索框可搜译词、中文与例句。每页 50 个词。
- **认识了**：标了之后这个译词在候选里不再显示为生词，可随时取消。
- **删除**：从词表删掉这个词，之后再见到时重新记起。
- 生词本出现之前记下的英语词没有中文，词表里用随包的英汉释义补上显示。

## 两个视图共用

- **语言**：按学习语言分开记，打开时显示当前的学习语言；记过几门语言时，顶上可以切换查看以前学过的语言。
- **导出**：把词表当前筛选与搜索出的词导出为 CSV（用表格软件打开）、Anki 导入文件（正面译词，背面中文与例句）或网页（用浏览器打开、打印）。
- **清空**：删掉正在查看的这门语言的全部记录，连同时间线，需点两次确认。

Android 的生词本在青简应用里，见 [Android：生词本与设置](../platforms/android-settings.md#生词本与统计)。
