Qingjian is a pinyin input method. As you type, each candidate carries a gloss in the language you are learning, so you pick up a word while you write.
It is a complete input method first: sentence input, abbreviated pinyin, spelling correction, fuzzy pinyin, double pinyin, Wubi and English mode all run on your device, and no data is uploaded.

| Platform | Status |
|---|---|
| macOS, Windows | Beta. The two platforms have nearly the same features; keys follow each system's conventions |
| Linux | Uses the Fcitx5 / Fcitx4 candidate panel; installed from a terminal and started by hand |
| Android | Preview; install the APK |

For which features each platform has, see [Platform differences](platforms/differences.md).

## Three principles

- **Typing comes first.** Any delay, pop-up or distraction added for the sake of learning counts as a design bug.
- **One language at a time.** Each candidate has a single gloss; English, Japanese and Korean are never shown at once.
- **Everything on your device.** Pinyin conversion, dictionaries, learning and glosses all work offline. AI services are an optional extra: data goes to the provider you enter, never through Qingjian.
