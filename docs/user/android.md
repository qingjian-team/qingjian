「简词键盘」基于青简输入引擎开发，是非官方实验版。支持 Android 8.0 及以上的 64 位 ARM 手机；中文候选旁显示英语译词。当前功能与桌面版不同，尚无云联想、神经模型、统计页和多语言学习设置。

## 安装与启用

把 APK 传到手机后打开安装。打开「简词键盘」，点击「启用简词键盘」，在系统键盘列表中启用，再点击「切换输入法」选择它。

更新时可使用同一签名的 APK 覆盖安装。请先在普通文本输入框中试用。

## 输入与按键

输入 `nihao`，等待候选出现后点「你好」或按空格。选择短词后可继续选择剩余拼音。输入 `kaifa` 可查看「开发」旁的英语译词。

中文候选先显示，英语译词随后补齐；译词补充时保留候选条的滑动位置。

| 操作 | 触屏按键 |
|---|---|
| 中英文切换 | 「中/英」 |
| 英文大小写 | 上箭头键；中文输入仍使用小写拼音 |
| 数字与符号 | 「符号」进入，「ABC」返回字母页 |
| 选择首个候选 | 空格 |
| 浏览其他候选 | 在候选条横向拖动；松手后可惯性滚动 |
| 删除 | 点删除键删除一次；长按连续删除，松手或移出按键即停止 |
| 发送、搜索或换行 | 回车键，按当前应用的要求执行 |
| 使用其他输入法 | 顶部「切换输入法」，从系统列表中选择 |

键盘采用深色外观，三排字母大小相同；底部为系统导航栏留出空间。

## 数据与隐私

输入法离线运行，不申请网络权限。个人选词习惯仅保存在手机上；密码框及应用标记为不允许个性化学习的输入框不会记录选词学习。

首次启动需准备本地词库。若出现数据加载失败提示，可关闭键盘后重新打开。

## 已验证范围

荣耀 500、MagicOS 10.0.0.175(C00E170R103P6H1) 的 QQ 输入框中，试用者确认 0.1.3 实验 APK 的候选滑动、长按删除及底部导航栏遮挡问题均已修复。其他手机、应用、横屏和导航模式仍需分别验证。
