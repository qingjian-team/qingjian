青简是一个拼音输入法。输入时，候选词旁边附带一条所学语言的译词，在输入的同时记住一个词。
它首先是一个完整的输入法：整句输入、简拼、拼写纠错、模糊音、双拼、五笔、英文模式，全部在本机完成，不上传数据。

| 平台 | 现状 |
|---|---|
| macOS、Windows | 测试版，两个平台功能基本相同，按键按各自系统的习惯设计 |
| Linux | 使用 Fcitx5 / Fcitx4 的候选面板，需在终端中安装、手动启动 |
| Android | 预览版，下载 APK 安装 |

各平台有哪些功能见 [平台差异](platforms/differences.md)。

## 三条原则

- **输入优先。** 任何为学习功能增加的延迟、弹窗与干扰都视为设计错误。
- **一次只学一种语言。** 一个候选旁只有一条译词，不同时显示英语、日语、韩语。
- **全部在本机。** 拼音转换、词库、学习、译词均不联网；AI 服务是可选的补充，数据发送给你自行填写的服务商，不经过青简。
