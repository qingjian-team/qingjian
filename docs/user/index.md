青简是一个用 Rust 写的拼音输入法。打字时，候选词旁边多一条你正在学的那门语言的译词，输入的时候顺便多认识一个词。
它首先是一个好用的输入法：整句输入、简拼、拼写纠错、模糊音、双拼、英文模式，全部在本机完成，不上传数据。

现在只有 macOS 版，测试阶段。Windows 与 Linux 版在计划中。

## 从哪里开始

- 还没装：[安装](getting-started/install.md)。
- 装好了：[第一次输入](getting-started/first-input.md) 讲中英切换、选词、翻页、选错了怎么退回。
- 想知道候选旁边那条译词是什么、橙色是什么意思：[译词与生词](learning/translation.md)。
- 想让它联网帮忙补全整句、答字、翻译选中的文字：[云联想](cloud/index.md)，缺省关闭，要自己填 AI 服务商。
- 关心它在你电脑上留下了什么：[数据与日志](help/data-and-logs.md)。

## 三句话原则

- **输入优先。** 任何为学习功能增加的延迟、弹窗、干扰都算设计错误。
- **一次只学一种语言。** 一个候选旁边只有一条译词，不会同时塞进英语、日语、韩语。
- **全在本机。** 拼音转换、词库、学习、释义都不联网；云联想是可选的补充，数据发给你自己填的服务商，不经过青简。
