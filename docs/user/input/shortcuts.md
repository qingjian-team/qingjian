## 日期、时间、星期

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 当天日期、当前时间、星期，前三种写法紧跟首选，其余排在候选末尾 |
| `riqi` / `shijian` / `xingqi` | 候选里出现「日期」「时间」「星期」时，同样的写法紧跟在这个词后面 |

写法有多种，前三条跟在首选后面，其余垫到候选末尾——第一页留给词本身，打 `sj` 想要「时间」不用翻页：

| 输入 | 前三条 | 其余（举例） |
|---|---|---|
| `rq` | `2026年11月9日`、`2026-11-09`、`2026/11/09` | `2026.11.09`、`11月9日`、`20261109`、`26-11-09`、`09/11/2026`（欧式）、`11/09/2026`（美式）、`2026-W45-1`、`二〇二六年十一月九日` |
| `sj` | `19:06`、`19:06:23`、`19点06分` | 带毫秒、带日期、12 小时制（`下午7:06`、`7:06 PM`）、纯数字（`190623`、`20261109190623`）、文件名友好（`20261109_190623`） |
| `xq` | `星期一`、`周一`、`礼拜一` | — |

## 算式、中文数字与日期

以 `v` 开头：

| 输入 | 结果 |
|---|---|
| `v1+2` | 算式：出 `3` 与 `1+2=3`，支持 `+ - * / ^`、括号、小数 |
| `v123` | 中文数字：一百二十三 与 壹佰贰拾叁；金额：一百二十三元整 与 壹佰贰拾叁元整 |
| `v123.5` | 小数读法：一百二十三点五 与 壹佰贰拾叁点伍；金额：一百二十三元五角 与 壹佰贰拾叁元伍角（小数最多两位，到分） |
| `v1998-3-8` | 中文日期：一九九八年三月八日；另有 1998年3月8日 与 1998-03-08，分隔符 `-` / `/` / `.` 都可以 |
| `vnow` | 今天的日期，写法与 `v2026.11.5` 完全一样 |
| `vnow+4` / `vnow-4` | 四天后 / 四天前。也可以写 `vnow;4`（分号，或冒号 `vnow:4`；不带符号按往后算） |
| `v1234.9.9-7` / `v1234.9.9+30` | 指定日期往前 7 天 / 往后 30 天。只认完整年月日，且偏移的符号要和日期分隔符不同 |

- 日期按**四位年份 + 月 + 日**认；年份不是四位（`v98-3-8`）或月日不合法（`v1998-2-30`）时按算式算。单年份与年月也要四位（`v1632` 查崇祯五年，`v123` 仍按算式），三段完整日期放宽到三位（`v755.4.1` 是天宝十四年）。
- `-` 与 `/` 既可以是日期分隔符也可以是减号：`v1998-3-8` 同时给日期写法与算式结果，日期在前、算式在后，由用户挑。认不出来的写法（`v1-2-3`）按算式算。
- 以 `v` 开头后，数字与运算符都进算式，不再用于选词或翻页；选第二项用 `↑` / `↓` 加 `Space`，`Enter` 将所敲内容原样输出。
- 以 `v` 开头的英文词（`very`）不受影响，仍给出英文候选。

## 时间戳

`vts` 出四个候选：Unix 秒、UTC（RFC 3339，`2026-09-03T11:06:23Z`）、Unix 毫秒、带时区的 ISO 8601（`2026-09-03T19:06:23+08:00`）。数字键照常选词；值取自敲下 `vts` 那一刻，选词前不会变。

## UUID

`vuuid` 出四个候选：随机的 UUID v4、按时间排序的 v7，以及同一个 v4 的全大写与去掉连字符两种写法。数字键照常选词。
全拼下直接敲 `uuid` 也行，UUID 跟在英文词 uuid 之后。每次重新输入都是一组新的值。

## 按部件拆字

不会读的字，`u` 后依次打各部件的拼音：`umumu` 出「林」，`uniuniuniu` 出「犇」，`uyanshe` 出「话」「谢」。候选旁标出这个字的读音（林 lín），数字键选中上屏。

- 部件按从左到右、从上到下的顺序打；偏旁按它本来的字读，讠 读 yan、氵 读 shui、扌 读 shou。
  个别部件按日常叫法认：`囗` 形同口，按 kou 打（`ukoumu` 出「困」），按它本来的 wéi 读也认。
- 打到一半就出候选，整串对上的排在前面，同样对上的按常用程度排。
- 不需要 AI 服务。开着 AI 服务时，同一串拼音还会照常发去问字（见下一节）。
- 拆法来自[開放詞典網](http://kaifangcidian.com/)的漢語拆字字典（CC BY 3.0）。

## 按笔顺找字

知道怎么写、不知道读什么、也拆不成部件时，`u` 后直接打笔顺。五个键代替五种笔画：

| 键 | 笔画 |
|---|---|
| `h` | 横 |
| `s` | 竖 |
| `p` | 撇 |
| `n` | 点、捺 |
| `z` | 折 |

`uhspn` 出「木」（横竖撇捺），`uhspnhspn` 出「林」。打几笔就出几笔的候选，打得越全越准，第一个是笔顺刚好对上的那个。

**倒着打也行**：从最后一笔往前，`unpsh` 同样出「木」。

## 部件与笔画混着打

一半拆得出、一半只记得笔顺时，两种连着打，不用加分隔：

| 输入 | 拆法 |
|---|---|
| `umuhspn` | 木(mu) + 木的笔顺 |
| `uheszh` | 禾(he) + 口(szh) |
| `uphspnkou` | 禾的笔顺 + 口(kou) |

不用记规则：同一串会按「全读音」「混合」「全笔画」排成三档，对得越全的越靠前。

## 按编号输入字符

`u` 后接十六进制的字符编号（Unicode 码点），得到对应的字符：`u4e00` 出「一」，`u+1f600` 出 😀。

`u` 后接拼音是问字，答案需开启 AI 服务，见 [问字与翻译](../cloud/question-and-translate.md#问字)。

## 换前缀字母

`v` 与 `u` 可在「设置 → 快捷键」的「表达式」「问字」里改，只能是 v、u、i 三个字母（它们不作为任何拼音的开头）；选了另一个正在用的字母，两者对调。

双拼与五笔拼音混输下 v / u / i 都是编码键，改为按住 `Shift` 输入：`Shift + V` 后接算式（`V1+2`），`Shift + U` 后接拼音或编号（`U4e00`），与搜狗、微软双拼一致。只在还没打拼音时生效；改过前缀字母的，按改后的字母加 `Shift`。
单用五笔时没有这些前缀。
