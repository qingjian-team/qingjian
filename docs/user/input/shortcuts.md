## 日期、时间、算式

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 当天日期（`2026年9月3日`、`2026-09-03`）、当前时间（`19:06`、`19点06分`）、星期，插在首选之后 |
| `v1+2` | 算式：出 `3` 与 `1+2=3`，支持 `+ - * / ^`、括号、小数 |
| `v123` | 中文数字：一百二十三 与 壹佰贰拾叁；金额：一百二十三元整 与 壹佰贰拾叁元整 |
| `v123.5` | 小数读法：一百二十三点五 与 壹佰贰拾叁点伍；金额：一百二十三元五角 与 壹佰贰拾叁元伍角（小数最多两位，到分） |
| `u4e00` | 按十六进制码点输入字符：一；`u+1f600` 出 😀 |

以 `v` 开头后，数字与运算符均进入算式，不再用于选词或翻页；选第二项用 `↑` / `↓` 加 `Space`，`Enter` 将所敲内容原样输出。
以 `v` 开头的英文词（`very`）不受影响，仍给出英文候选。

`v` 与 `u` 两个前缀键可在「设置 → 快捷键」修改，只能是 v、u、i 三个字母（它们不作为任何拼音的开头）。
双拼下 `v` / `u` 是音节键，改用 `Shift`+`V` / `Shift`+`U` 开头（`V1+2`、`U4e00`）。

`u` 之后接拼音为 [问字](../cloud/question-and-translate.md)，需打开云联想；`?` 缺省只是问号，可在「快捷键」页勾选让它也进入问字。

## 中英混输

中文模式下无需切换：

- 整段输入为英文词时直接给出英文候选。拼音不成立时（`hello` 只能切成 `he l l o`）英文排第一，拼音成立时（`china`）英文排第二。
  打开「设置 → 候选」的「中文排在英文词前面」后英文固定排第二（`hello` 先 荷兰咯 再 hello，`key` 先 可以 再 key），
  `Space` 上屏的仍是中文，按 `2` 选英文；没有中文候选时（`github`）英文仍排第一。
  专名按正确大小写上屏：`windows` → **Windows**，`github` → **GitHub**，`python` → **Python**。
- 拼音不成立且不少于 3 个字母时补全前缀：`compa` → company / companies / compared。
- 不想在中文模式里看到英文词与补全，关闭「设置 → 候选」的「打拼音时也给英文词」（配置文件里是 `[general] english_in_chinese = false`），英文模式不受影响。
- 一句拼音末尾接一个英文词时，整句直接包含该词：`woxiangxuehaorust` → 我想学好rust，`wodeid` → 我的ID，`woyongvim` → 我用vim，`yongwindows` → 用Windows。
  拼音行显示 `wo'xiang'xue'hao'rust`，`Space` 上屏整句。该英文词需在词表中（用户自己输入过的也算，见 [英文模式](english-mode.md)）。
  `database` 这类同时可读作拼音的输入，按两种读法的通顺程度排序：我的database 排第一、我的大塔巴瑟 排第二；
  `womenqubeijing` 只给出 我们去北京。`fan`、`to` 这类短词按拼音处理；可纠正为通顺拼音的输入错误（`shiide` → 是的）不视为英文。
  英文词只识别句末，`wozaidebugzhege` 这类位于句中的暂不支持（可先上屏前面的中文，再打英文词）。
- **中英混杂词**（字母 + 汉字）直接按「字母 + 拼音」打：`cpan` → C盘，`bzhan` → B站，`dpan` → D盘，`txu` → T恤，`agu` → A股，`xguang` → X光。
  U盘 因 `u` 是问字前缀，打 `youpan`（与 优盘 同读音，U盘 排前）。它们也能进整句：`wozaibzhan` → 我在B站。
- 输入拼音时输入不会转全角的符号（`-` `/` `@`，翻页键除外）即进入**英文直输**：`no-way` 整段原样显示，之后的字符原样追加，
  `Space` / `Enter` 原样上屏（空格字符也一并输出），因此中文模式下可直接输入 `no-way` 这类带符号的串。
- 会转全角的标点（`,` `.` `?` `!` `:` 等）缺省也进直输段。打开「设置 → 中英文」的「标点先上屏候选」（配置 `[general] punct_commits = true`）后，
  它们不再进直输段，而是先把高亮候选上屏、再接该标点（`nihao,` 一气打完「你好，」）。
  要在候选后面接半角标点，先切英文模式（Windows 也可关闭「中文模式标点转全角」）。

## 符号面板

打字后按 `↑`（高亮还在第一个、没动过时）打开符号面板。没在打字时：macOS 点菜单栏输入法菜单里的「符号面板…」，
Windows 点悬浮状态条上的「符」格，或右键任务栏的「中 / 英」图标选「符号面板…」，面板出现在鼠标旁（这时没有搜索组）。顶上是三组：

- **搜索**：把刚敲的字当搜索词，`ku` 出 😢 😭 (T_T)，`jiantou` 出所有箭头，`alpha` 出 α；没搜到时没有这一组。
- **符号**：常用、中英文标点、数学、箭头、希腊字母、序号、货币单位、分数、上下标、装饰、几何制表、汉语拼音（带声调）、注音、平假名、片假名、国际音标、拉丁字母、竖排标点、全角字母、数学字母。
- **表情**：常用 emoji、颜文字，以及按 Unicode 分组的全部 emoji（笑脸、人物、动物自然、食物、旅行地点、活动、物品、标志、旗帜）。

`Tab` 换组、`[` `]` 换分类、方向键移动，鼠标滚轮或触控板逐行滚动，`Space` / `Enter` 或双击上屏，上屏后敲的字一并清掉；`Esc` 或右上角 ✕ 回到候选。
面板目前一律按系统样式画，不随主题变。
底下一行显示高亮条目的中文名（😂 笑哭了、€ 欧元符号）。太新的 emoji 旧系统显示不出来，面板里只收到 Emoji 15.1。

## emoji、颜文字与符号

前几个候选中有对应 emoji、颜文字或符号的词，它们紧随该词之后，右侧标注对应的词：

| 输入 | 候选 |
|---|---|
| `ku` | 哭 😢 😭 (T_T) |
| `xiaosi` | 笑死 🤣 |
| `yuedengyu` | 约等于 ≈ |
| `sheshidu` / `erfenzhiyi` / `meiyuan` | 摄氏度 ℃、二分之一 ½、美元 $ |
| `alpha`（英文候选） | alpha α |
| 英文模式 `smile` | smile 🙂 😊 |

同一个词后面按 emoji、颜文字、符号的顺序排；emoji 和符号每个词最多两个，颜文字一个。上屏不记录学习。
三样各有各的名额，在「设置 → 候选」的「候选后面的 emoji」「候选后面的颜文字」「候选后面的符号」里选（不显示 / 最多 1–3 个），
配置文件里是 `[general] emoji`（缺省 3）、`kaomoji`（缺省 1）、`symbols`（缺省 1），都是 `0`–`3`；以前 `emoji` 写的 `true` / `false` 照旧认，相当于 3 / 0。
