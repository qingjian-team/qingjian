## 日期、时间、星期

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 当天日期（`2026年9月3日`、`2026-09-03`）、当前时间（`19:06`、`19点06分`）、星期，插在首选之后 |
| `riqi` / `shijian` / `xingqi` | 候选里出现「日期」「时间」「星期」时，同样的写法紧跟在这个词后面 |

## 算式、中文数字与日期

以 `v` 开头：

| 输入 | 结果 |
|---|---|
| `v1+2` | 算式：出 `3` 与 `1+2=3`，支持 `+ - * / ^`、括号、小数 |
| `v123` | 中文数字：一百二十三 与 壹佰贰拾叁；金额：一百二十三元整 与 壹佰贰拾叁元整 |
| `v123.5` | 小数读法：一百二十三点五 与 壹佰贰拾叁点伍；金额：一百二十三元五角 与 壹佰贰拾叁元伍角（小数最多两位，到分） |
| `v1998-3-8` | 中文日期：一九九八年三月八日；另有 1998年3月8日 与 1998-03-08，分隔符 `-` / `/` / `.` 都可以 |

- 日期按**四位年份 + 月 + 日**认；年份不是四位（`v98-3-8`）或月日不合法（`v1998-2-30`）时按算式算。
- 以 `v` 开头后，数字与运算符都进算式，不再用于选词或翻页；选第二项用 `↑` / `↓` 加 `Space`，`Enter` 将所敲内容原样输出。
- 以 `v` 开头的英文词（`very`）不受影响，仍给出英文候选。

## 按编号输入字符

`u` 后接十六进制的字符编号（Unicode 码点），得到对应的字符：`u4e00` 出「一」，`u+1f600` 出 😀。

`u` 后接拼音是问字，需开启 AI 服务，见 [问字与翻译](../cloud/question-and-translate.md#问字)。

## 换前缀字母

`v` 与 `u` 可在「设置 → 快捷键」的「表达式」「问字」里改，只能是 v、u、i 三个字母（它们不作为任何拼音的开头）；选了另一个正在用的字母，两者对调。

双拼与五笔拼音混输下 v / u / i 都是编码键，改为按住 `Shift` 输入：`Shift + V` 后接算式（`V1+2`），`Shift + U` 后接拼音或编号（`U4e00`），与搜狗、微软双拼一致。只在还没打拼音时生效；改过前缀字母的，按改后的字母加 `Shift`。
单用五笔时没有这些前缀。
