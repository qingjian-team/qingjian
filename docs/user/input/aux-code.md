翻页找词很费事。辅码是在拼音之后补几个字母，把候选直接缩小到想要的词。macOS 与 Windows 支持。

## 开启

在「设置 → 输入 → 辅码」打开「启用」，在「辅码方案」里选一套码表。没选过时用随包的笔画码。同一时间只用一套：几套混用时同一个字母意思不同，反而筛不干净。
打开但没有可用码表时，触发键不生效，`;` 仍按原来的方式工作。

## 用法

先按平常的方式输入拼音，再按触发键（缺省 `;`）进入辅码：此时候选不变，拼音行末尾多一个 `;`。
接着输入码，候选随每多一个字母即时收窄，剩下的词就是码以所输字母开头的词。

例如码表里「开发」的码是 `kf`，输入 `kaifa` 后按 `;` 再输入 `kf`，候选只剩「开发」。

- 码只筛词，不改变拼音的输入方式，也不影响整句。
- 码表没收的词在辅码状态下不显示。
- 码不需要敲满：敲到候选合适即可按空格或数字上屏。
- `Backspace` 删除码的最后一个字母；码删空后仍停在辅码状态、候选全部回来，再按一次才退出（关掉「码删空后留在辅码」则删空即退出）。`Esc` 直接清掉码。
- 「Shift + 字母」设为「进组句」时，在辅码状态里敲大写字母等于先按 `Esc`：清掉码回到拼音，字母照常参与拼音。
- 辅码状态下选过的词同样会被记住，下次纯拼音输入它会更靠前。

## 触发键

缺省为 `;`，在「设置 → 输入 → 辅码」中修改，可改为 `/` 或反引号等单个可见字符。

微软、搜狗、紫光双拼用 `;` 表示韵母 ing：拼音末尾有落单的声母时，`;` 当拼音用（`x;` 得到 xing），其他情况下才是触发键。

## 码表

随包的笔画码：横 `h`、竖 `s`、撇 `p`、点与捺 `n`、折 `z`。单字取前四笔加最后一笔；词取每个字的第一笔，四字及更长的词取前三个字与最后一个字。自己造的词、导入词库里的词也按这条规则算码。

其他码表需自行取得后导入：「设置 → 输入 → 码表 → 导入码表」，接受 Rime 的码表文件（`.dict.yaml`）与青简的 `.qj` 文件。
导入完成后显示读入、有码、无码与跳过的条数，并自动改用刚导入的那张；想换回来在「辅码方案」里选。导入的码表列在「码表」组中，可以移除。

码表文件的写法，以及让只收单字的码表也能筛词，见 [自制方案与码表](../advanced/custom-schemes.md#辅码码表)。

## 候选上显示码

打开「设置 → 输入 → 辅码 → 候选上显示码」后，码用方括号紧跟在候选词后面显示，例如 `鹤[rbm] crane`。
不进辅码也能看：纯拼音打字时候选就带着每个词的码，方便边打边记；进了辅码显示的则是对上当前输入的那条码。
