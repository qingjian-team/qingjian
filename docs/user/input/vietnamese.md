# 越南语 Telex

在“设置 → 输入法切换”把“连按两次 Shift 切换第三输入法”选成“越南语”。原来配置的单击切换键仍在中文和上次使用的外文之间切换；400 ms 内连按两次 Shift 在英文和越南语之间切换。在中文状态双击时直接进入另一个外文，不会先闪过中间状态。

越南语使用 Simple Telex：`aw` → `ă`、`aa` → `â`、`dd` → `đ`、`ee` → `ê`、`oo` → `ô`、`ow` → `ơ`、`uw` → `ư`；`s`、`f`、`r`、`x`、`j` 分别输入五种声调，`z` 删除声调。声调按现代规则放置，例如 `hoas` → `hoá`。

整段文字在输入框里保持为组合文字：空格确认当前词后可以继续输入下一词，标点也留在当前整段中；按 Enter 才一次性上屏并结束本轮输入。退格先按实际敲下的 Telex 键回退，当前词为空时继续删除前面已确认但尚未上屏的内容；按 Esc 可把当前词恢复成原始按键。

候选窗口第一项是当前 Telex 转换结果，后面优先按尚未上屏的完整连续文字匹配词组和短语；连续匹配不足时，再按当前词补全。选择完整短语会替换当前整段，不会把相同前缀重复追加。每个越南语候选右侧显示一至两个常见中文译词。转换结果与原始按键不同时，原文排在最后。空格选择第一项，也可按数字或点击选择其他词。

右键点击候选可提权、降权、取消降权，或让候选模型重新生成中文译词。越南语候选权重与中文拼音候选分开记录。

候选支持鼠标点击、数字键、Tab 和方向键操作；↑ / ↓（以及 ← / →）移动高亮，Tab 选择当前高亮候选。
候选右侧的中文译词也支持青简通用快捷键：Command + 数字上屏第一条译词，Shift + Option + 数字上屏第二条译词；鼠标点击译词效果相同。

输入引擎按越南语音节结构判断越英混输，`linux`、`changes`、`windows` 等明显不是越南语音节的单词保持英文。少数英文恰好也是合法的越南语 Telex 序列，例如 `this` → `thí`、`mix` → `mĩ`；这时可按 Esc 恢复原文。
