## 整句

无需切换模式，连续输入整句后再上屏：`jintiantianqihenhao` 的首选即为「今天天气很好」。
整句打到最后一个字时只敲声母也能提前出整句：`youdiandongx` 的首选就是「有点东西」，与补全成 `youdiandongxi` 一致。

一段拼音分几次选完时，先选的词留在输入框里，整段选完才一起上屏，见 [选错了词](../getting-started/first-input.md#选错了词)。

### 词库里没有的词

想打的词不在词库里（新词、网络用语、人名）时，可以从第一个字开始逐字选：

- 拼音能完整拆成几个音节时（`shishan`），对得上的整词之后只跟少数几个猜出来的长词（时尚潮流），接着就是首个音节的单字（是、时、十、屎……）。
- 一长串拼音时（`shiyanshiqing…`）也一样：整句和开头几个音节的词再多，第一页最晚第九个也是首个音节的单字，多出来的词排到单字后面。
- 把一个完整的音节拆开才读得出的词（`shishan` 读成 `shi s h an` 的「事实」）排在最后。

## 简拼

只敲每个字的声母同样可用：`jttqhh` 出「今天天气很好」。
两三个字母的简拼通常仍按词处理（`sj` 出「时间」），需要整句时多输入几个音节。

## 拼写纠错

- **拼音拼不通时**（多敲、少敲、两键颠倒、敲错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行把要改动的字母以删除线标出并保留原位，候选全部按纠正后的拼音给出。
  相邻两键颠倒时不必等整个词输完：`mignt`、`migntia` 就已给出「明天」，继续输入即可；
  两种纠正都说得通时优先按颠倒解释（`mignti` → 命题，而不是改一个字母的 面体）。
- **每个音节都对时**：照原样读得出由常用词组成的句子，就按原样排第一，纠正只当备选：`shabi` 首选「傻逼」，不会被纠成「杀不」。
  照原样只拼得出一个个单字或生僻的碎片时，纠正仍可排第一：`meiganxi` → 没关系（`gan` 视为 `guan`），`zanen` → 咱们。

只有纠正后的句子明显比原样通顺时才纠正；合法的简拼（`nhao`、`womend`）不会被误纠，整段为英文词的输入（`hello`）也不纠正。

### 关闭拼写纠错

在「设置 → 输入 → 纠错」关掉「拼写纠错」（配置 `[general] spelling_correction = false`），之后拼音只按敲的原样读（模糊音照常），不再给纠正后的候选，记住的习惯性错误也不再用（记录保留，重新打开后照常起作用）。

### 不需要纠正时

`Enter` 仍将所敲字母原样上屏。原样上屏过一次的字母串，此后不再纠正。

### 记住习惯性错误

被接受的纠正会被记住：习惯将 `shuo` 敲成 `shou` 的话，几次之后「我说」会自然排到前面。记住的错误同样遵守上面的规则：敲的拼音照原样读得通时，它只让纠正那一条更靠前，不会顶掉原样的首选。用 `Backspace` 删除后改选会一并撤销这次记录。

双拼与五笔下不纠错：双拼敲错一个键改变的是整个声母或韵母，五笔敲的是字根编码，都不是拼错一个字母的情形。

## 本地整句模型

本地整句模型缺省关闭，整句只按词库算，最快也最省电。想用时在下面的「实验功能」里下载两个模型之一：含章·通变按你敲的拼音直接造出整句，让长句的首选更通顺；知意读光标前的字，从候选里挑最合适的首选。模型都在本机运行，不联网、不发送任何内容。Linux 版随包带通变，在「设置 → 候选」打开「本地整句模型」就能用。

- 敲完一段拼音停一下（长句约十分之二秒），整句候选就换成模型认为更通顺的那句；没停就先显示按词库算出的句子。
- 通变造出的句子在长句（六个字左右起）里排第一；短的输入、最后一个字的拼音还没打完、或拼音敲错被纠正时，按词库算出的句子排第一，通变造的排在后面。中英混打、词库拼不出完整句子时也由它补出整句。
- 模型只调整整句候选。词候选、你选过的词都不受它影响，你的习惯仍然优先。
- 已经翻到后面的页或用方向键移过高亮时，模型的结果不再换掉正在看的这页。
- 输入法刚启动的几秒钟模型还在加载，这段时间按词库出句。
- 较旧的 Mac（如 macOS 14 上缺少所需图形功能时）改用处理器运行模型，排序可能慢一些。
- 含章·通变只看这段拼音；知意还会参考光标前面的几十个字。应用不让读上下文时（部分终端、Electron 应用），改看你刚才在这个输入框里打的字，换了应用或输入框就从头算，一分钟没打字也不再算；这个时长是配置文件 `[model]` 分节的 `context_memory_seconds`，填 0 表示一直算。

不想用时，在「设置 → 实验功能」把开着的模型关掉，或在「设置 → 候选」关掉「本地整句模型」，回到只按词库排序；与 AI 服务互不影响。
换用自己的模型见 [数据文件与日志](../advanced/data-files.md#换用自己的本地整句模型)。

### 实验功能

macOS 与 Windows 上「设置 → 实验功能」可以下载两个本地整句模型，都要手动下载：

- **知意**（推荐）：读光标前的字与敲的拼音，从候选窗前几条里挑首选；整句候选也按它对每个字的判断来拼，长句还会先拼出十几种说法再由它挑，更通顺（光标前有字时效果最明显）。由[知意输入法](https://github.com/dd1000001000/zhiyi_ime)的作者训练并授权，macOS 约 154 MB、Windows 约 70 MB。开着时可以选档位：省电、均衡、准确，越往后比的候选越多、看的前文越长，也越费电；电脑较旧、觉得卡或发热时选省电。
- **含章·通变**：青简自己训练的模型，按敲的拼音直接造出整句、也能造出词库里没有的词，长句的首选更通顺；不看光标前的字，约 43 MB。

点「下载」后显示进度条，可以取消；下完自动启用。同一时间只用一个模型，开了一个就关掉另一个，两个都关着就不用模型、只按词库排序。模型同时连 Gitee 与 GitHub，哪边先响应从哪边下，断了换另一边，每一块都核对校验值。Linux 还没接这两个模型。
