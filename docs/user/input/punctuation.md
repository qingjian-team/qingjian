## 中文标点

没在打拼音时，中文模式下输入 `, . ? ! : ; ( ) [ ] { } < > \ ^ _ $ ~` 得到全角标点，`{` `}` 出直角引号「」，`"` `'` 成对切换；数字之后的 `.` 保持半角（`3.14`）。

### 全角与半角

- 「设置 → 中英文」的「中文标点」可选半角，字母和数字不受影响。
- Windows 与 Linux 的英文模式另有一份「英文标点」，缺省半角；macOS 英文模式一律半角。
- Windows 上点击悬浮状态条的「，。」格可随时切换当前模式的全角 / 半角。
- macOS 与 Windows 可在「设置 → 快捷键」启用 `Ctrl + .`（macOS 为 `⌃ + .`）切换当前模式的全角 / 半角，缺省关闭，以免占用应用自己的快捷键。

## 打拼音时敲标点

打了一半拼音时敲标点，有两种效果，由「设置 → 中英文」的「标点先上屏候选」决定：

- **关闭（缺省）**：进入**英文直输**，拼音和后面敲的字符整段原样显示，`Space` / `Enter` 原样上屏。中文模式下可以直接打出 `no-way`、`gpt-6` 这类带符号的串。
- **打开**：会转全角的标点（`,` `.` `?` `!` 等，翻页键除外）先把高亮候选上屏、再接全角标点：`nihao,` 一气打完「你好，」。

不论开关如何：

- `'` 是隔音符（`xi'an`）。
- 不会转全角的符号（`-` `/` `@`）总是进入英文直输。
- 打邮箱：`qingjian@` 后面列出 qq.com、163.com、gmail.com 等常见邮箱的完整地址，接着敲 `g` 只剩 gmail.com。用方向键移到地址上按 `Space`，或直接点它，上屏这个地址，后面不带空格；`Enter` 照旧上屏敲的原文。
- 要在候选后面接半角标点，先切到英文模式，或把中文标点改为半角。
- 选了某组标点作翻页键时（如 `,` `.`），这两个键在打拼音时用于翻页，见 [改按键](../personalize/keys-settings.md#翻页键)。

## 符号面板

macOS 与 Windows 有符号面板。打字后按 `↑`（高亮还在第一个、没动过时）打开。没在打字时：macOS 点菜单栏输入法菜单里的「符号面板…」，
Windows 点悬浮状态条上的「符」格，或右键任务栏的「中 / 英」图标选「符号面板…」，面板出现在鼠标旁（这时没有搜索组）。面板分三组：

- **搜索**：把刚敲的拼音当搜索词，`ku` 出 😢 😭 (T_T)，`jiantou` 出所有箭头，`alpha` 出 α；没搜到时没有这一组。
- **符号**：常用、中英文标点、数学、箭头、希腊字母、序号、货币单位、分数、上下标、装饰、几何制表、汉语拼音（带声调）、注音、平假名、片假名、国际音标、拉丁字母、竖排标点、全角字母、数学字母。
- **表情**：常用 emoji、颜文字，以及按类别分组的全部 emoji（笑脸、人物、动物自然、食物、旅行地点、活动、物品、标志、旗帜）。

`Tab` 换组、`[` `]` 换分类、方向键移动，鼠标滚轮或触控板逐行滚动，`Space` / `Enter` 或双击上屏，上屏后刚敲的拼音一并清掉；`Esc` 或右上角 ✕ 回到候选。
底下一行显示高亮条目的中文名（😂 笑哭了、€ 欧元符号）。面板目前按系统样式显示，不随主题变。太新的 emoji 旧系统显示不出来，面板里只收到 Emoji 15.1。

## 候选后面的 emoji、颜文字与符号

前几个候选中有对应 emoji、颜文字或符号的词，它们紧随该词之后，右侧标注对应的词：

| 输入 | 候选 |
|---|---|
| `ku` | 哭 😢 😭 (T_T) |
| `xiaosi` | 笑死 🤣 |
| `yuedengyu` | 约等于 ≈ |
| `sheshidu` / `erfenzhiyi` / `meiyuan` | 摄氏度 ℃、二分之一 ½、美元 $ |
| `alpha`（英文候选） | alpha α |
| 英文模式 `smile` | smile 🙂 😊 |

同一个词后面按 emoji、颜文字、符号的顺序排。三样各有各的数量，在「设置 → 候选」的「emoji」「颜文字」「符号」里选不显示或最多 1–3 个（缺省 emoji 3 个、颜文字与符号各 1 个）。
选这些候选上屏不会被记作输入习惯。
