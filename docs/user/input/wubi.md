macOS 与 Windows 支持形码（Android 另有五笔键盘）；Linux 暂不支持。

## 开启

「设置 → 输入 → 形码」选「五笔（86）」。随包只有 86 版五笔，也可以放入自己的形码方案，见 [自制方案与码表](../advanced/custom-schemes.md#自制形码方案)。

- **单用五笔**：把同一页的「拼音」设为「关」。
- **五笔拼音混输**：拼音方案保持开着，见下文[混输](#混输)。

## 打字

敲的是编码而不是读音：`ggll` 出 一，`khlg` 出 中国，`gant` 出 开发。候选窗口顶部原样显示敲的编码。

- 编码打到哪儿算哪儿，按已敲的部分查词。86 五笔 A–Y 的一级简码字始终排第一；其他编码打全的词排在更长编码的词前面，这就是二级 / 三级简码。
- 空格上屏高亮候选，数字键选词，翻页、删除、上屏与拼音一致；左右键按单个字母移动光标。候选旁的译词、输入习惯与生词本也照常。
- 拼音才有的功能在五笔下没有：整句输入、简拼、模糊音、拼写纠错，以及 `v` / `u` 开头的[算式与特殊字符](shortcuts.md)。

单用五笔时另有几条规则：

- **满码唯一自动上屏**：编码敲满 4 码，而且只对应一个词时，不用按空格，直接上屏。例如 `trwu` 直接上屏 我们；`khlg` 对应 中国、跑车、跨国 三个词，停下等待选择。
- **顶字**：编码已经敲满时再敲一个字母，先把高亮的候选上屏，这个字母作为下一个词的第一码。例如 `khlg` 之后接着敲 `trwu`，依次上屏 中国、我们。
- **标点上屏**：敲逗号、句号这类标点，先上屏高亮候选，再接全角标点。
- **空码清除**：编码查不到任何词时，按空格或标点只清掉编码，不把字母打进正文；需要字母时按 `Enter`。

前两条可以关：拼音为「关」时，「设置 → 输入」的「形码」下面有「满码唯一自动上屏」与「顶字」两个开关，每个形码方案分别记住。

### 字根图

形码选了五笔（86）时，「设置 → 输入」里同样有「键位提示」：候选窗口旁边显示 86 版字根图，每个键上是它的全部字根，底下一行是键名与区位号。
弹出时机、大小与透明度和双拼的键位提示是同一组设置，见 [键位提示](fuzzy-and-shuangpin.md#键位提示)。自己放入的形码方案没有字根图。

## 混输

拼音方案与形码同时开着时，敲编码与敲拼音都认，五笔打不出的字直接打拼音：

```text
gant     → 开发          （编码）
nihao    → 你好          （编码查不到，用拼音）
ggll     → 一            （拼不成音节，只剩编码）
woxiangxuehao → 我想学好  （第 5 个字母起五笔已经查不到，只剩拼音）
```

- **编码打全的五笔词排在最前，其次是拼音候选，只敲了编码前一部分的五笔词排在拼音之后**：`g` 第一个是一级简码 一，`ga` 第一个是 开，`kai` 第一个仍是拼音的 开。
- 五笔编码最长 4 码，所以**敲到第 5 个字母时自动只剩拼音**，不用手动切。
- 同一个词两边都命中时只出现一次。
- 句末夹英文词只在拼音那边有效；超过 4 码的输入只可能是拼音，拼写纠错照常。
- 算式与问字改用 `Shift + V`、`Shift + U` 开头，见 [日期、算式与特殊字符](shortcuts.md#换前缀字母)。
- 满码自动上屏、顶字、空码清除在混输时都不生效：满码之后的字母可能是在接着打拼音。

反过来主要用拼音、偶尔用五笔也行，只是一级 / 二级简码（五笔里 `wo` 是 伙）会排在拼音首选前面；不想要就把形码关掉。

## 加自己的五笔词

不用换整份码表：把词写成文件，从「设置 → 词库 → 导入词库」导入即可，见 [词库](../personalize/dictionaries.md#导入五笔词库)。
