## 两种纠错

- **拼音切不干净时**（多敲、少敲、敲反、敲错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行把改掉的字母画成删除线插在原位，候选全部按纠正后的拼音出。
- **每个音节都合法、整句却说不通时**：`meiganxi` 也能出「没关系」（`gan` 读成 `guan`）。这一路只影响整句，不影响单个词的候选。

只有纠正后的句子明显比原样更通顺才纠；合法的简拼（`nhao`、`womend`）不会被误纠，整段是英文词的（`hello`）也不纠。

## 不想要纠正

`回车` 仍然把敲的字母原样上屏。原样上屏过一次的串，以后不再纠它。

## 它会越来越懂你的手

接受过的纠正会记下来：习惯性把 `shuo` 敲成 `shou` 的人，几次之后「我说」就自然排上来。退格重选会把这条记录一并退回。

双拼下拼写纠错不启用：敲错一键换掉的是整个声母或韵母，一处编辑的模型不适用。
