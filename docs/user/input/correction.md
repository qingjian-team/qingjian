## 两种纠错

- **拼音无法完整切分时**（多输、少输、颠倒、输错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行将被改动的字母以删除线标出并保留原位，候选全部按纠正后的拼音给出。
- **每个音节合法、整句不通顺时**：`meiganxi` 同样可出「没关系」（`gan` 视为 `guan`）。此类纠错只影响整句，不影响单个词的候选。

只有纠正后的句子明显比原样通顺时才纠正；合法的简拼（`nhao`、`womend`）不会被误纠，整段为英文词的输入（`hello`）也不纠正。

## 不需要纠正时

`Enter` 仍将所敲字母原样上屏。原样上屏过一次的字母串，此后不再纠正。

## 记忆习惯性错误

被接受的纠正会被记录：习惯将 `shuo` 输成 `shou` 的用户，几次之后「我说」会自然排到前面。用 `Backspace` 删除后改选会一并撤销该记录。

双拼下不启用拼写纠错：输错一个键改变的是整个声母或韵母，单处编辑的模型不适用。
