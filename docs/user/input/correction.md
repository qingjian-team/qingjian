## 两种纠错

- **拼音无法完整切分时**（多输、少输、颠倒、输错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行将被改动的字母以删除线标出并保留原位，候选全部按纠正后的拼音给出。
  相邻两键颠倒时不必等整个词输完：`mignt`、`migntia` 就已按 `ming't`、`ming'tia` 给出 明天，继续输入即可；
  两种纠正都说得通时优先按颠倒解释（`mignti` → 命题，而不是改一个字母的 面体）。
- **每个音节合法、词库仍无法完整读出时**：尝试相近拼音补齐缺失的读法。此类纠错只影响整句，不影响单个词的候选。

原拼音能完整读出时保留原读音：`henjianduandejishu` 按 `hen jian duan de ji shu` 出「很简短的技术」，常用词「简单」的频次再高也不会把 `duan` 改成 `dan`。
这条规则同时适用于整句、中英混输和本地模型重排；已启用的模糊音规则继续生效。

原样读不通时，只有纠正后的句子明显更通顺才纠正；合法的简拼（`nhao`、`womend`）和整段英文词（`hello`）保留原输入方式。

## 不需要纠正时

`Enter` 仍将所敲字母原样上屏。原样上屏过一次的字母串，此后不再纠正。

## 记忆习惯性错误

被接受的纠正会被记录，帮助原拼音读不通时选择更合适的相近读法。个人学习也遵循原拼音优先的规则。用 `Backspace` 删除后改选会一并撤销该记录。

双拼下不启用拼写纠错：输错一个键改变的是整个声母或韵母，单处编辑的模型不适用。五笔（形码）下同样不启用——敲的是字根编码，不是拼音。
