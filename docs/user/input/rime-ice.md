青简可启用雾凇方案作为输入后端。全拼、七种双拼、中文与英文词库、中英混输、部件反查、辅码、Emoji、简繁转换及 Lua 功能由雾凇方案处理。青简负责显示候选窗口和向应用输入框提交文本。候选顺序、注释、选字键和分页遵循雾凇方案设置。

## 启用

需准备与青简进程架构一致、包含 Lua 的 Rime 运行库，以及完整的[雾凇文件](https://github.com/iDvel/rime-ice)。青简安装包不包含这些文件。简繁转换还需准备与运行库兼容的 OpenCC 数据。运行库及其依赖需一起安装。

按[数据与日志中的雾凇设置](../help/data-and-logs.md#雾凇拼音)指定运行库、共享数据和独立用户目录，然后重启输入法服务。首次启用需部署词库，可能需要等待。更改路径、方案或插件模块后需重启服务；方案和用户补丁的修改也会在重启时重新部署。

## 方案与按键

可通过雾凇菜单切换方案，默认按 `F4` 或 `` Ctrl + ` `` 打开。按键以原始方案及个人补丁为准，青简的全拼、双拼、翻页、标点、辅码和中英切换设置不参与原生按键处理。macOS 使用修饰键对应的原生键位；系统保留的快捷键可能先被系统处理。

日期、农历、UUID、Unicode、数字及金额大写、计算器、以词定字和置顶候选等功能由方案中的 Lua 实现。个人补丁与自定义短语保存在原生用户目录，修改方式遵循雾凇文档。额外插件需由所选运行库提供。移动端九宫格依赖专用处理器，需使用相应运行库；桌面运行库不提供该处理器。

## 与青简功能配合

候选仍可显示青简已有的译词，原生注释与译词分别显示。词频学习和造词由 Rime 处理，青简本地模型、云端候选和自定义短语不参与排序。这些行为需通过雾凇的短语文件和补丁设置。

原生输入不使用青简的「修饰键 + 数字上屏译词」快捷键，也不触发青简的前缀问字与快捷计算；这些按键由雾凇处理。输入日志可记录雾凇上屏的文本；统计保留汉字、英文词和上屏次数，不估计中文词数。关闭青简的学习开关不会关闭 Rime 的用户词库；Rime 学习需在原生方案中设置。

私密输入会清除原生组句并将后续按键交给应用。青简不会在私密输入中调用用户 Lua 处理按键。个人 Lua 的其他行为取决于脚本本身。

若只需中文词库，可通过[词库导入](../settings/dictionaries.md)使用青简原有输入功能。
