## 进入英文模式

- **macOS**：`Caps Lock` 亮起为英文模式，熄灭回到中文。
  想让 `Caps Lock` 像系统拼音那样在青简与「ABC」之间切换输入法，在「系统设置 → 键盘 → 文本输入 → 编辑」里打开用 Caps Lock 切换「ABC」的选项：
  轻按 `Caps Lock` 切换输入法，按住仍是大写锁定；这时青简自己的英文模式就用不到了。
- **Windows**：单击 `Shift`（按下即松开，不与其他键组合）在中 / 英之间切换，任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」。
  点击任务栏的「中 / 英」图标同样可以切换。
  `Caps Lock` 在 Windows 上只控制大小写：亮起时无论中英模式均直接输出大写字母（与微软拼音一致）。
- **Linux**：单击 `Shift` 在中 / 英之间切换，按住 `Shift` 打字母不会切换。`Caps Lock` 亮着时直接输出大写字母。

中英模式在 Windows 上缺省**所有应用共用一份**：在一个应用里切到英文，切到别的应用、新打开的应用也是英文。Linux 上**每个窗口各记一份**，新打开的窗口从中文开始。

## 改掉或关掉中 / 英切换

打字时误触 `Shift` 会切到英文、打断输入。Windows 与 Linux 可以在「设置 → 中英文」的「切换键」里调整，勾上哪个就能用哪个，可以多选：

| 选项 | 说明 |
|---|---|
| 单击 Shift | 缺省勾上，与微软拼音一致 |
| 单击 Ctrl | 不容易误触；Ctrl 在其他组合键里的作用不受影响 |
| Ctrl + Alt + Space | 组合键，最不容易误触 |
| Ctrl + Space（系统，仅 Windows） | Windows 自带的「输入法 / 非输入法切换」，缺省开启；改的是 Windows 的系统设置，也会影响微软拼音等简体中文输入法 |

改完立刻生效。一个都不勾时键盘不再切中英：Windows 上只能用任务栏或悬浮状态条上的「中」「英」按钮；Linux 上单击 `Shift` 原样交给应用。

Windows 上装了英文键盘或别的输入法时，系统可能改用 `Ctrl + Space` 切到别的输入法，这由系统决定；不想要这条系统热键，到 Windows「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」把它改成「未分配」。

Linux 上 Fcitx5 缺省把**左** `Shift` 设为「临时在当前和第一个输入法之间切换」，它比青简先拿到按键：单击左 `Shift` 会直接切到英文键盘，不受青简的切换键设置影响。
想让左 `Shift` 只归青简管，到 Fcitx5 配置的「全局选项 → 快捷键」把这一项清空。

习惯中英文用两个不同的输入法时，可以关掉「设置 → 中英文」第一行的**英文模式**：青简固定为中文，切换键与状态栏按钮都不再切到英文，
需要英文时 Windows 用 `Win + Space`、Linux 用 Fcitx 的切换热键切到别的输入法。

## 默认模式与按应用记忆

「设置 → 中英文」的「英文」一组里有两项：

- **默认英文模式**（Windows、Linux）：Windows 上青简启动时从英文开始；Linux 上新打开的应用和窗口从英文开始。关掉时从中文开始。
- **按应用记住中英模式**（Windows）：切回应用时恢复它上次的状态。没有记录的应用使用上面的默认模式，同一应用的多个窗口共用状态。

例如两项都打开，新应用从英文开始，在记事本切到中文不会影响浏览器的英文状态。
记住的状态在本次青简运行期间保留，关闭再打开应用仍能恢复；重启青简后重新使用默认模式。
更改这两项或开关「英文模式」会清掉已记住的状态。关掉「英文模式」时始终是中文，默认英文不生效。

## 英文模式下打字

英文模式下输入字母时，候选窗口给出英文词的补全与拼写纠正：`recieve` → receive，`seperate` → separate。
字母缺省小写，按住 `Shift` 输出大写。

- 选词与中文模式一致：`Space` 选高亮候选（词上屏后空格照常输入），数字键选当前页第 N 个（没有第 N 个时数字接进单词，如 `foo1`），翻页键翻页，`↑` / `↓` 移动高亮，`Tab` 同样选高亮项。
- **`Enter` 与标点将所敲字母原样上屏**：`kubectl` 这类词表中没有的词按 `Enter` 即可原样输出；没有候选时 `Space` 也原样上屏。
- 带数字的词（`mp3`、`utf8`）先按 `Enter` 输出字母再敲数字；没有候选时数字直接接在字母后。
- 标点在 macOS 上一律半角；Windows 与 Linux 缺省半角，可改为全角，见 [标点、符号与表情](punctuation.md)。

按 `Enter` 原样上屏过的英文词（如 `gist`、`python`）会记住，下次输入时排在首位。选过的英文候选同样记住。

[自定义短语](../personalize/phrases.md)在英文模式里同样生效：敲全输入码时短语排在英文词候选前面，例如给 `dont` 配上 `don't`，英文模式下按空格上屏的就是 `don't`。

### 哪些应用里给候选

- 缺省只在浏览器、聊天和文档类应用中给英文候选，例如 Safari、Chrome、Edge、Firefox、微信、QQ、企业微信、钉钉、飞书、Word、WPS、记事本、备忘录、Obsidian。
  其他应用中英文模式不出候选，字母原样交给应用：终端与代码编辑器里不会遮挡应用自身的补全或占用 `Tab` 键，
  Photoshop、Illustrator、Blender 这类软件的单键快捷键（如 Photoshop 的 `W` `H` `V`）也能直接使用。
- 「设置 → 中英文」的「只在写字的应用里给」控制这份名单，取消勾选即处处都给。增减具体应用见 [直接编辑配置文件](../advanced/config-file.md)。
- 关闭「英文模式也给候选」后英文模式完全不出候选，与没有使用输入法时一样。

## 在中文模式里打英文

中文模式下无需切换：

- 整段输入为英文词时直接给出英文候选。拼音不成立时（`hello`）英文排第一，拼音成立时（`china`）英文排第二。
  打开「设置 → 候选」的「中文排在英文词前面」后英文固定排第二（`hello` 先 荷兰咯 再 hello），`Space` 上屏的仍是中文，按 `2` 选英文；没有中文候选时（`github`）英文仍排第一。
  专有名词按正确大小写上屏：`windows` → **Windows**，`github` → **GitHub**，`python` → **Python**。
- 拼音不成立且不少于 3 个字母时补全英文：`compa` → company / companies / compared。
  英文候选最多几条、最高排到第几位可在「设置 → 候选」调：数量 1–4（缺省 4，1 只留最靠前的一条）；有中文候选时英文最高排到第几位（缺省第 1 位，即不限）。
- `key`、`id` 这类既像英文词又可读成拼音的输入，若常选中文词，中文词排在前面，英文词退后。
- 一句拼音末尾接一个英文词时，整句直接包含该词：`woxiangxuehaorust` → 我想学好rust，`wodeid` → 我的ID，`yongwindows` → 用Windows。
  该英文词需在词表中（自己在英文模式输入过的也算）。`database` 这类也可读作拼音的输入，按两种读法的通顺程度排序；`fan`、`to` 这类短词按拼音处理。
  英文词只认句末，`wozaidebugzhege` 这类位于句中的暂不支持（可先上屏前面的中文，再打英文词）。
- **字母加汉字的词**直接按「字母 + 拼音」打：`cpan` → C盘，`bzhan` → B站，`txu` → T恤，`agu` → A股，`xguang` → X光。
  U盘 因 `u` 是问字的前缀，打 `youpan`（与 优盘 同音，U盘 排前）。它们也能进整句：`wozaibzhan` → 我在B站。
- 不想在中文模式里看到英文词，关闭「设置 → 候选」的「打拼音时也给英文词」，英文模式不受影响。
  关闭后英文词也不再作为句末的尾巴参与整句（`nanine` 不再出「那nine」）。

打拼音时按 `Shift + 字母` 缺省是临时打英文：拼音先上屏，这个大写字母原样输出。
「设置 → 中英文」的「Shift + 字母」改成「进组句」后，大写字母按小写参与拼音，`Cpan` 与 `cpan` 一样能出「C盘」。

敲 `-` `/` `@` 这类符号会进入英文直输，可以直接打出 `no-way` 这类带符号的串，见 [标点、符号与表情](punctuation.md#打拼音时敲标点)。

## 中西文自动空格

macOS 与 Windows 可打开「设置 → 中英文 → 中文与英文、数字之间自动加空格」（缺省关）。打开后，汉字与半角字母、数字相邻处自动补一个空格：
「用Go写了30行」上屏为「用 Go 写了 30 行」。标点与已有空格两侧不补，自定义短语与日期、算式这类候选按原文上屏；
光标移到了别处，或应用不提供光标前的文字时，无法判断上文，不补空格。Linux 暂不支持。

## 悬浮状态条（Windows）

任务栏的「中 / 英」不易察觉时，可另开一条桌面上的悬浮状态条：「设置 → 中英文」打开「悬浮状态条」。它有四格：

| 格 | 显示 | 点击 |
| --- | --- | --- |
| `中` / `注` / `英` | 当前模式（大千注音显示「注」；双拼、五笔显示为「中 · 小鹤双拼」这样） | 切换中 / 英；关掉「英文模式」后固定「中」 |
| `，。` / `,.` | 当前模式下标点是全角还是半角，中英各记一份 | 切换当前模式的全角 / 半角 |
| `符` | | 打开[符号面板](punctuation.md#符号面板) |
| ⚙ | | 打开设置 |

按住拖动可移到屏幕任意位置，位置会被记住；外观随系统的深浅色。大小在「状态条大小」里调（60%–150%），不跟候选字号走。
它只在当前输入法为青简时显示：切到其他输入法或系统的英语键盘时收起，切回后再次出现。
前台是全屏应用（游戏、全屏视频、演示）时自动收起，退出全屏后回来。也可以在任务栏「中 / 英」图标的右键菜单里随时显示或隐藏它。
它每次显示时都会被移回屏幕可见范围内。状态条也可以随主题换样子，见 [自制主题](../advanced/custom-themes.md#悬浮状态条（Windows）)。
