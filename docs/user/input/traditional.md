打字方式不变，仍然按普通话拼音输入；变的只是候选窗口里显示的字与上屏的字。

## 开启

「设置 → 候选 → 输出字形」，或在配置文件里写 `[general]` 的 `traditional_variant`：

| 选项 | 配置写法 | 效果 |
|---|---|---|
| 简体 | `off` | 不转换（默认） |
| 繁体（台湾） | `taiwan` | 台湾字形：软件 → 軟件、这里 → 這裡 |
| 繁体（香港） | `hongkong` | 香港字形 |
| 繁体（通用字形） | `standard` | OpenCC 的标准繁体字形：这里 → 這裏 |

三档都只换字形、不换用语：软件仍是「軟件」，不会换成「軟體」。台湾与香港的字形取舍不同（裡 / 裏、著 / 着），所以分开两档。改动立即生效，不必重新切换输入法。

0.2.1 及以前的配置里写的是 `traditional = true`，升级后按「繁体（台湾）」读，输出与原来相同。

### Linux

Linux 上也可以直接改配置文件里的这一行，保存后约一秒内生效，不用重启。以台湾字形为例：

```bash
sed -i 's/^traditional_variant = .*/traditional_variant = "taiwan"/' ~/.config/qingjian/config.toml
```

把 `taiwan` 换成 `hongkong` / `standard` 就是另外两档，改回 `off` 是简体。从 0.2.1 及以前升级上来的配置里没有这一行，在 `[general]` 下面加一行 `traditional_variant = "taiwan"` 即可。

## 学习数据始终是简体

词库、词频、用户词、个人常用搭配记录的都是简体。所以：

- 开着繁体输出时学到的词，改回简体输出后照样优先。
- 反过来也一样：之前用简体攒下的习惯，开繁体后立刻生效。
- 删除候选（修饰键 + 数字）删的也是那条简体记录。

## 自定义短语不转换

自定义短语按你写下的原文上屏，开着繁体输出也不改字。想要繁体的短语，直接把短语写成繁体。

## 仍按简体的拼音与用词输入

转换发生在候选与上屏这一步，词库本身没有变，因此：

- **读音按普通话**：垃圾要打 `laji`（不是台湾读音 `lese`）、企划要打 `qihua`。
- **用语按大陆习惯**：转换只换字形，打 `ruanjian` 得到「軟件」，不会变成台湾用语「軟體」；词库里也没有以台湾用语为词条的词。
- **一字多形的地方偶尔会错**：简体的一个字对应多个繁体字时（后 → 後 / 后、发 → 發 / 髮），转换按词判断，生僻搭配可能选错。遇到错字可以只打那一个字再选，或改用通用字形。

需要完整的台湾读音与在地词库（注音、`lese` 这类读音）时，要换一套繁体词库，那不是这个开关能解决的。
