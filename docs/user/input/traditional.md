打字方式不变，仍然按普通话拼音输入；变的只是候选窗口里显示的字与上屏的字。

## 开启

「设置 → 候选 → 输出字形」：

| 选项 | 效果 |
|---|---|
| 简体 | 不转换（缺省） |
| 繁体（台湾） | 台湾字形：软件 → 軟件、这里 → 這裡 |
| 繁体（香港） | 香港字形 |
| 繁体（通用字形） | 标准繁体字形：这里 → 這裏 |

三档都只换字形、不换用语：软件仍是「軟件」，不会换成「軟體」。台湾与香港的字形取舍不同（裡 / 裏、著 / 着），所以分开两档。改动立即生效。
AI 给出的候选与整句补全同样转换。Android 在键盘设置里选，见 [Android：生词本与设置](../platforms/android-settings.md)。

## 输入习惯始终按简体记

词库、你选过的词、自己造的词、输入统计记的都是简体。所以：

- 开着繁体输出时学到的词，改回简体输出后照样优先；反过来也一样。
- 删除候选删的也是那条简体记录。
- 候选旁的译词照常显示。

自定义短语按你写下的原文上屏，开着繁体输出也不改字。想要繁体的短语，直接把短语写成繁体。

## 仍按普通话拼音与大陆用词输入

转换发生在候选与上屏这一步，词库本身没有变，因此：

- **读音按普通话**：垃圾要打 `laji`（不是台湾读音 `lese`）、企划要打 `qihua`。
- **用语按大陆习惯**：打 `ruanjian` 得到「軟件」，不会变成台湾用语「軟體」。
- **一字多形的地方偶尔会错**：简体的一个字对应多个繁体字时（后 → 後 / 后、发 → 發 / 髮），转换按词判断，少见的搭配可能选错。遇到错字可以只打那一个字再选，或改用通用字形。

需要完整的台湾读音与在地用词时，要另换一套繁体词库，不是这个开关能解决的。
