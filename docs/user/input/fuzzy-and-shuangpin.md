## 模糊音

九条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。缺省全关。

打开：输入法菜单「模糊音」子菜单勾选，或「偏好设置 → 模糊音」。开了 z/zh 之后敲 `zi` 也出 知 / 之，开了 f/h 敲 `kaiha` 也出 开发。
敲对的词仍然优先，模糊命中的排在后面。韵母那三条只对完整音节生效。

## 双拼

四套方案：小鹤、自然码、微软、搜狗。「偏好设置 → 通用」选，空为全拼。

- 拼音行显示解出来的全拼（`nihc` → `ni'hao`），学习按全拼记，切回全拼也受益。
- 零声母：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）。
- 微软 / 搜狗的 `;` 是 ing：组句中末尾有落单声母时敲 `;` 进拼音，其他时候仍是标点。
- 双拼下 v / u / i 都是音节键，[快捷输入](shortcuts.md) 里的表达式与问字只能用 `?` 开头进。
- 已知：`lue` / `nue` 与 `lve` / `nve` 同键，词库里少量 `lue` 读音的词双拼下打不出；`lo` 与 `luo` 同键，解成 luo。
