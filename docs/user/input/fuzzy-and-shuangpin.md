## 模糊音

九条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。缺省全部关闭。

开启：输入法菜单「模糊音」子菜单勾选，或「偏好设置 → 模糊音」。开启 z/zh 后输入 `zi` 也出 知 / 之，开启 f/h 后输入 `kaiha` 也出 开发。
输入正确的词仍然优先，模糊匹配的词排在其后。韵母三条只对完整音节生效。

## 输入方案

「偏好设置 → 通用」里是**两个独立的设置**：

| 设置 | 可选 |
| --- | --- |
| 拼音方案 | 全拼（缺省）、小鹤双拼、自然码、微软双拼、搜狗双拼、智能ABC、小浪双拼、首道双拼、大千注音、关 |
| 五笔（86 版） | 开 / 关（缺省关） |

两边可以各自单开，也可以同时开——同时开着就是**混输**，见下一节。

中英切换始终是 `Shift`，与选哪套方案无关。全拼、双拼与注音都是「拼音」的读法，共用同一份词库、整句转换与学习数据；五笔是形码，走的是另一条路。
两个都关着时按全拼算，不会一个字都打不出。

## 双拼

七套方案：小鹤、自然码、微软、搜狗、智能ABC、小浪、首道。

- 拼音行与输入框显示：缺省均显示解出的全拼（`nihc` → `ni'hao`，小浪 `nihs` → `ni'hao`）；可在偏好设置勾选「双拼在输入框显示原始按键」（配置 `[general] shuangpin_raw_preedit = true`），勾选后输入框（光标处）保留原始输入按键字母（如 `kdfa`），方便输入英文词或核对按键，回车可直接原样上屏；候选窗口顶部的拼音行照旧显示解码后的全拼（如 `kai'fa`），敲击按键与音节解析两不耽误。学习按全拼记录，切回全拼后同样受益。
- 零声母：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）；智能ABC 也写 `o` + 韵母键，但韵母键按它自己的表（ei 是 `oq` 不是 `oz`），且不认双写元音（`aa` 是 zha、`ee` 是 che）；小浪写 `aa` `ai` `ah` `ao`、`uu`（e）、`ui`（ei）、`un`（en/eng）、`ur`（er）、`oo`（o）、`ou`（ou）。
- 微软 / 搜狗的 `;` 为 ing：输入拼音时末尾有落单的声母，`;` 作为拼音（`x;` → xing）；其他情况下仍为标点。
- 智能ABC 翘舌声母以 `a` 为 zh、`e` 为 ch、`v` 为 sh（`ai` → zhi、`ei` → chi、`vi` → shi）。
- 小浪双拼翘舌声母以 `e` 为 zh、`i` 为 ch、`v` 为 sh；`x` 为 ü（`lx` → lv，`nx` → nv，`jx` → ju）；`v` 兼作韵母 uai 与 ing；未在键位表列出的韵母按原拼键输入（如 a/e/i/u 及 o 对 uo/o）。
- 首道双拼翘舌声母以 `v` 为 zh、`i` 为 ch、`e` 为 sh；零声母双写首字母或照全拼输入（`aa` `ai` `an` `ao` `oo` `ou` `en` `er`），ang 为 `ay`，e / ei / eng 以 `u` 引导（`ue` `ui` `uf`）；ue 在 `l`（`jl` → jue），üe 单独在 `b`（`lb` → lve）。
- 双拼下 v / u / i 均为音节键，[快捷输入](shortcuts.md) 中的算式与问字改为按住 `Shift` 输入：`Shift`+`V` 后接算式（`V1+2`），`Shift`+`U` 后接拼音或码点（`U4e00`），与搜狗、微软双拼一致。未输入拼音时才生效；模式键改过的，按改后的字母加 `Shift`。
- 全拼输入 `lue` / `nue` 与词库形式 `lve` / `nve` 等价。双拼统一解为 `lve` / `nve`。
- 已知限制：`lo` 与 `luo` 同键，解为 luo。小浪方案中 `en` 与 `eng` 同码（`un`），统一解为 `en`；`dia`/`dai` 同码解为 `dai`，`lia`/`lai` 同码解为 `lai`，`nen`/`niang` 同码解为 `niang`。首道方案中 `den`/`dia` 同码（`dk`），解为 `den`。

## 五笔（形码）

86 版五笔。敲的是字根编码而不是读音：`ggll` 出 一，`khlg` 出 中国，`gant` 出 开发。
候选框顶部原样显示敲的编码，不打乱成音节。

- 编码打到哪儿算哪儿，按该前缀查表。编码正好打全的词排在同前缀的更长编码词前面（这就是一级 / 二级 / 三级简码）。
- 空格上屏高亮候选，数字键选词，与拼音一致；候选旁的译文、词频学习与生词记录也照常。
- 这条路上没有拼音的那些能力：整句输入、简拼、模糊音、拼写纠错，以及 `v` / `u` / `i` 开头的[快捷输入](shortcuts.md)。
  这三个键在五笔里是字根键，不再当模式键。
- 单用五笔时把拼音方案设为「关」；那样连中英混输也没有，敲多长都是编码。

## 混输（五笔 + 拼音）

**拼音方案与五笔同时开着**就是这样。敲字根编码与敲拼音都认，五笔打不出的字直接打拼音：

```text
gant     → 开发          （编码）
nihao    → 你好          （编码查不到，落到拼音）
ggll     → 一            （编码切不成音节，拼音那半条自动让位）
woxiangxuehao → 我想学好  （第 5 个字母起五笔已经查不到东西，只剩拼音）
```

- **编码打全的五笔词排在最前，其次是拼音候选，只敲了编码前缀的五笔词排在拼音之后**：`ga` 第一个是 开，`kai` 第一个仍是拼音的 开（编码以 `kai` 开头的词在后面）。
- 五笔编码最长 4 位，所以**敲到第 5 个字母时自动只剩拼音**，不用手动切。
- 同一个词两边都命中时只出现一次。
- 中英混输（句末夹英文词）只在拼音那半条路上，五笔编码本身不参与。
- 混输下小写 `v` / `u` / `i` 是字根键，[快捷输入](shortcuts.md) 的算式与问字同双拼一样改为按住 `Shift` 输入（`V1+2`、`U4e00`）；超过四个字母的输入只可能是拼音，拼写纠错照常。

反过来（主要用拼音、偶尔用五笔）也能用，只是一级 / 二级简码（`wo` 是 伙）会排在拼音首选前面——不想要就把五笔关掉。
