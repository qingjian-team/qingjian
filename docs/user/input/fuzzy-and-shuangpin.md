## 选择方案

「设置 → 输入」里有两个独立的设置：

| 设置 | 可选 |
| --- | --- |
| 拼音 | 全拼（缺省）、小鹤双拼、自然码、微软双拼、搜狗双拼、智能ABC、小浪双拼、首道双拼、拼音加加、紫光双拼，以及[自己做的双拼方案](../advanced/custom-schemes.md#自制双拼方案)；大千注音；关 |
| 形码 | 关（缺省）、五笔（86 版），以及自己做的形码方案，见 [五笔与混输](wubi.md) |

两边可以各自单开，也可以同时开（同时开着就是混输）。两个不能同时关：一边关着时，另一边的「关」是灰的。
全拼、双拼与注音共用同一份词库、整句与输入习惯，换方案后之前学到的照样有效。中英切换与选哪套方案无关。

## 全拼的几个写法

- `lue` / `nue` 与 `lve` / `nve` 等价；j / q / x / y 后的 `v` 也认（`tiqv` → 提取），带韵母时同样可用（`xvexi` → 学习、`jvan` → 卷、`yvn` → 云）。拼音行按汉语拼音的写法显示 ü：l、n 后写 `ü`（敲 `lve` 或 `lue` 显示 `lüe`，`nv` 显示 `nü`），j / q / x / y 后写 `u`（敲 `qv` 显示 `qu`，`jvan` 显示 `juan`）；双拼解出的全拼与九宫格的拼音行也一样。
- 「嗯」按习惯用 `en` 输入（`enen` → 嗯嗯）；单独敲 `ng` 也出「嗯」，与其他拼音连写时请用 `en`。同样单独敲 `hng` 出「哼」，`hm` 的候选里有「噷」。
- 双拼里单独敲 `ng`（各方案都是 neng 的键）时，「能」仍在第一，「嗯」排第二。
- `lo` 与 `luo` 同键，按 luo 处理。

## 模糊音

十条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing、eng/ong。缺省全部关闭。

在「设置 → 输入 → 模糊音」勾选，macOS 也可在输入法菜单的「模糊音」子菜单勾选。开启 z/zh 后输入 `zi` 也出 知 / 之，开启 f/h 后输入 `kaiha` 也出 开发。
输入正确的词仍然优先，模糊匹配的词排在其后。只敲一个音节时，模糊匹配的常用字排在正确读音的前 9 个字之后（`zi` 先出 子 字 自 等，接着是 只 知），不会落到生僻字后面。韵母四条只对完整音节生效。拼音为「关」时不可用。

### 自定义规则

上面十条之外的混淆可以自己加：在「设置 → 输入 → 模糊音」的「自定义规则」里写成「音=音」，几条用空格隔开，回车保存。

- 两边都是声母：`zh=j`，敲 `ji` 也出 知。
- 两边都是韵母：`ian=iang`，敲 `xian` 也出 想。和内置的韵母规则一样，只对完整音节生效。
- 两边都是完整音节：`fa=hua`，敲 `hua` 也出 发，别的音节不受影响。

加好的规则排在上面十条后面，可以随时勾选开关；从输入框里删掉就去掉。认不出的写法（两边一个声母一个韵母、拼错的音节）不会加，下面会提示。配置文件里是 `[fuzzy]` 分节的 `custom`（全部规则）与 `custom_off`（其中关着的），见 [配置文件](../advanced/config-file.md)。

## 双拼

九套方案：小鹤、自然码、微软、搜狗、智能ABC、小浪、首道、拼音加加、紫光。

- 应用的输入框与候选窗口的拼音行缺省都显示解出的全拼（`nihc` → `ni'hao`）。「设置 → 输入」里有两个开关，各管一处：打开「输入框显示按键」，应用的输入框里改为显示敲的键（`kdfa`）；打开「候选窗显示按键」，候选窗口的拼音行改为显示敲的键。两个都开就是两处都显示按键。macOS 与 Windows 支持「候选窗显示按键」。学习按解出的全拼记录。
- 双拼同样支持模糊音。开启 s/sh 后，自然码 / 微软 / 搜狗的 `sd`、小鹤的 `sl` 可以查到「双」。
- 整串键一个完整音节都配不出来时，按「每键一个声母」的简拼再读一次：拼音加加 `im` → 什么、`zm` → 怎么。能正常解出音节的输入不受影响，完整双拼码照旧。
- 双拼下不纠正拼写错误。
- 双拼下 v / u / i 都是音节键，算式与问字改用 `Shift + V`、`Shift + U` 开头，见 [日期、算式与特殊字符](shortcuts.md#换前缀字母)。

**同时用全拼**（默认关）：在「设置 → 输入」打开后，双拼方案下打全拼也出候选，同一段输入里两种打法还能混用。适合一台电脑上有人打双拼、有人打全拼：`nihao` 与 `nihc` 都出 你好，`kaifh`（前半全拼、后半双拼）也出 开发。两种读法都能读完整段时按整句得分比较，不会固定让某一种读法排在前面；关掉时只认选定的双拼方案。

各方案的不同之处：

- **零声母**：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）；智能ABC 也写 `o` + 韵母键，但韵母键按它自己的表（ei 是 `oq` 不是 `oz`），且不认双写元音（`aa` 是 zha、`ee` 是 che）；紫光同样只写 `o` + 韵母键（`oa` `or` `oj`），不认双写元音与双写韵母；小浪写 `aa` `ai` `ah` `ao`、`uu`（e）、`ui`（ei）、`un`（en/eng）、`ur`（er）、`oo`（o）、`ou`（ou）。
- **`;` 键**：微软 / 搜狗 / 紫光的 `;` 为 ing：打拼音时末尾有落单的声母，`;` 当拼音用（`x;` → xing）；其他情况下仍为标点。Android 的微软双拼键盘把 `;` 放在左下角原来 Shift 的位置（往上一划是 Shift），见 [Android：键盘与打字](../platforms/android.md#键盘)。
- **ü**：微软 / 搜狗的 ü 键为 `y`：`ny` / `ly` 输入女 / 绿，`jy` / `qy` / `xy` / `yy` 解为 ju / qu / xu / yu，原来的 `ju` / `qu` / `xu` / `yu` 也可继续使用。其他方案也接受各自 ü 键与 j / q / x / y 的组合，但同键已有的读法优先（微软 `jv` 仍为 jue，小浪 `jv` 仍为 jing）。
- **智能ABC**：翘舌声母以 `a` 为 zh、`e` 为 ch、`v` 为 sh（`ai` → zhi、`ei` → chi、`vi` → shi）。
- **小浪**：翘舌声母以 `e` 为 zh、`i` 为 ch、`v` 为 sh；`x` 为 ü（`lx` → lü，`nx` → nü，`jx` → ju）；`v` 兼作韵母 uai 与 ing；键位表没列出的韵母按原拼键输入。`en` 与 `eng` 同码（`un`），按 en 处理；`dia` / `dai` 同码按 dai，`lia` / `lai` 同码按 lai，`nen` / `niang` 同码按 niang。
- **首道**：翘舌声母以 `v` 为 zh、`i` 为 ch、`e` 为 sh；零声母双写首字母或照全拼输入（`aa` `ai` `an` `ao` `oo` `ou` `en` `er`），ang 为 `ay`，e / ei / eng 以 `u` 引导（`ue` `ui` `uf`）；ue 在 `l`（`jl` → jue），üe 单独在 `b`（`lb` → lüe）。`den` / `dia` 同码（`dk`），按 den 处理。
- **拼音加加**：翘舌声母以 `v` 为 zh、`u` 为 ch、`i` 为 sh（ch / sh 与小鹤、自然码相反）；主排高频韵母 ai→S、ao→D、an→F、ang→G、ei→W、en→R、eng→T，ing 在 `q`；ü 在 `v`（`nv` 女、`lv` 绿），üe 在 `x`（`jx` → jue、`nx` → nüe）；零声母以双写为主（`aa` `as` `af`、`ee` `er` `eq`、`oo` `op`，注意 en 是 `er`、er 是 `eq`），也兼容 o 前缀（`oa` `oe`）；不用 `;` 键。
- **紫光**：翘舌声母以 `u` 为 zh、`a` 为 ch、`i` 为 sh（`ui` → zhi、`ai` → chi、`ii` → shi，`a` 与 `i` 兼作韵母）；`;` 为 ing；ü 在 `v`（`nv` 女、`lv` 绿），üe 与 ue、ui 同在 `n`（`jn` → jue、`yn` → yue、`gn` → gui）；零声母只写 `o` + 韵母键，不认双写元音（`aa` 是 cha）也不认双写韵母 `ii` `uu`（那是 shi、zhu）。

键位不合手、或想用的方案不在上面，可以自己做一套，见 [自制方案与码表](../advanced/custom-schemes.md#自制双拼方案)（macOS、Windows）。

### 键位提示

记不住键位时，可以让候选窗口旁边显示当前方案的键盘：每个键标着它的韵母，占键的翘舌声母（zh / ch / sh）标在右上角。敲了声母之后，能接着拼成音节的键变绿并写出那个音节，拼不出的键变暗。

在「设置 → 输入」的「键位提示」里选：

- **卡住时显示**：敲到一半停顿一下，或者敲出拼不成音节的键时才出现，打得顺的时候看不到。出现之后这次输入一直留着，上屏后收起。
- **一直显示**：输入时一直显示。

「键位提示大小」「键位提示不透明度」调键盘的大小与不透明度。键盘放在候选窗口背向光标的一侧，不会盖住正在输入的那一行；哪儿都放不下时这次不显示。
macOS 与 Windows 支持；Windows 上需用青简渲染器显示候选窗口（缺省就是）。五笔的字根图用同一组设置，见 [五笔与混输](wubi.md#字根图)。

## 大千注音

Windows 与 Linux 支持（Android 也有注音键盘），macOS 暂无。「设置 → 输入」的「拼音」选「大千注音」后，按大千键盘布局敲注音符号，候选与全拼共用同一份词库。打拼音时的按键改为：

| 操作 | 按键 |
|---|---|
| 上屏高亮候选 | `Enter` |
| 将注音符号原样上屏 | `Shift + Enter` |
| 一声 / 轻声 | `Space` |
| 声调与符号（继续输入，不选词） | 数字键，`-` `;` `,` `.` `/` |

大千键盘把数字键与 `- ; , . /` 都分给了注音符号和声调，所以注音下这些键不再选词，选词用 `Enter`；`Space` 是一声。
敲了声调的音节，同声调的字词排在前面（ㄇㄚ 一声先出 妈，ㄇㄚˇ 先出 马），整句也按声调转（ㄨㄛˇ ㄒㄧㄤˇ ㄇㄞˋ 出 我想卖），不敲声调不限。
Linux 上敲完声调后再按 `Space` 也可选词。
