## 微信或企业微信切换到青简时退出

安装青简后，个别应用可能仍使用安装前保存的输入法列表，切换时会导致应用退出。

新版安装包会备份并更新微信、企业微信的旧输入法列表。安装完成后，请完全退出这两个应用，再重新打开。

若仍出现问题，可完全退出对应应用，在终端运行安装包附带的修复工具：

```bash
bash "/Library/Input Methods/Qingjian.app/Contents/Resources/repair-input-cache.sh"
```

工具会显示备份位置。运行结束后，请重新打开微信或企业微信。它只处理旧输入法列表，保留聊天记录、登录状态及其他数据；已更新的列表不会重复处理。

若提示找不到修复工具，请先安装包含该工具的新版青简。若修复后仍然退出，请提供应用版本、macOS 版本、发生时间及退出报告，见 [反馈](feedback.md)。
