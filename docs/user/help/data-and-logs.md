青简不上传任何数据。拼音转换、词库、学习、释义全部在本机完成，没有账号，没有统计上报。

## 本机文件

都在「~/Library/Application Support/Qingjian/」（访达里按 `⇧⌘G` 输入这个路径），纯文本，随时可以打开看。

| 文件 | 内容 | 含你打的内容 |
|---|---|---|
| `config.toml` | 配置 | 否 |
| `.env` | 云服务的密钥，填了才有；只有你这个账户能打开 | 否 |
| `user.tsv` | 每个词被选择的次数 | 选过的词 |
| `user-words.tsv` | 自动造词与云端选中的用户词 | 选过的词 |
| `user-choices.tsv` | 某段拼音下选过哪个词 | 拼音与选过的词 |
| `user-english.tsv` | 原样上屏过的英文词 | 英文词 |
| `user-typos.tsv` | 接受过的敲错纠正（敲成了什么、本来要什么） | 拼音音节 |
| `user-ngram.tsv` | 哪个词后面常接哪个词 | 连着打过的词 |
| `user-glossary-<语言>.tsv` | 云端补回来的个人释义 | 词与译词 |
| `user-vocab.tsv` | 每条译词被看到 / 上屏 / 打出的次数 | 译词，不含中文 |
| `usage.tsv` | 按天的汉字 / 词 / 上屏次数，只有数字 | 否 |
| `input-log.jsonl` | 输入日志：每次上屏的键、切分、候选、选了第几个 | 敲的键与上屏的文字 |
| `dicts/` | 你导入的词库 | 否 |

这些文件每次都是整个换新的，输入法哪怕中途崩溃也不会留下写了一半的文件。

## 云联想发什么

缺省关闭。打开后，组句时的拼音、光标前后各几十个字的上下文、本机给出的候选，会发给你自己在「云服务」页填写的 AI 服务商。
数据直接从你的电脑发到服务商，不经过青简：青简没有自己的服务器。

- 密码框（Secure Input）里绝不发送。
- 开着时，随包释义表没有译词的词在你打出它之后会单独发一次，只有那个词。
- 关掉「云服务」页的开关就不再发任何请求。

## 输入日志

测试版缺省开启。每次上屏在本机记一行：敲的键、切分、看到的前几个候选、选了第几个。只有敲的键与上屏的文字，不含应用里的上下文。
它只写在这台电脑上，用于离线回归评测和你自己的个人模型，不会自动发给任何人。

- 关掉：「偏好设置 → 高级」取消勾选「记录输入日志」。
- 清空：同一页的「清空输入日志」。
- 测试时如果愿意把这个文件发给作者，对改进排序帮助很大，但完全自愿。

## 运行日志

在「~/Library/Logs/Qingjian/」，按天分文件只留 7 天。缺省级别不记你敲了什么；只有在「高级」页打开「详细日志」才逐键记录，用于排查问题，查完记得关。
