青简不上传任何数据。拼音转换、词库、学习、释义全部在本机完成，没有账号，没有统计上报。

## 本机文件

- **macOS**：「~/Library/Application Support/Qingjian/」（访达中按 `⇧⌘G` 输入此路径）。
- **Windows**：「%APPDATA%\Qingjian」（在资源管理器地址栏中直接输入此路径）。

均为纯文本，可随时打开查看：

| 文件 | 内容 | 是否含输入内容 |
|---|---|---|
| `config.toml` | 配置 | 否 |
| `.env` | 云服务的密钥，填写后才有；仅当前账户可读 | 否 |
| `user.tsv` | 每个词被选择的次数 | 选过的词 |
| `user-words.tsv` | 自动造词与云端选中的用户词 | 选过的词 |
| `user-choices.tsv` | 某段拼音下选过的词 | 拼音与选过的词 |
| `user-english.tsv` | 原样上屏过的英文词 | 英文词 |
| `user-typos.tsv` | 被接受的输入错误纠正（输成了什么、本意是什么） | 拼音音节 |
| `user-ngram.tsv` | 词与词之间的接续 | 连续输入过的词 |
| `user-glossary-<语言>.tsv` | 云端补充的个人释义 | 词与译词 |
| `user-vocab.tsv` | 每条译词被看到 / 上屏 / 输出的次数 | 译词，不含中文 |
| `usage.tsv` | 按天的汉字 / 词 / 上屏次数，仅数字 | 否 |
| `input-log.jsonl` | 输入日志：每次上屏的按键、切分、候选、所选序号 | 按键与上屏的文字 |
| `dicts/` | 用户导入的词库 | 否 |

这些文件每次整体替换，即使输入法中途崩溃也不会留下写到一半的文件。

## 云联想发什么

缺省关闭。打开后，输入拼音时的拼音、光标前后各几十个字的上下文、本机给出的候选，会发送给用户在「云服务」页填写的 AI 服务商。
数据直接从本机发送到服务商，不经过青简：青简没有自己的服务器。

- 密码框中不发送。
- 开启期间，随包释义表中没有译词的词在输出后单独发送一次，只含该词。
- 关闭「云服务」页的开关后不再发送任何请求。

## 输入日志

测试版缺省开启。每次上屏在本机记录一行：按键、切分、看到的前几个候选、所选序号。只含按键与上屏的文字，不含应用中的上下文。
它只保存在本机，用于离线回归评测与个人模型，不会自动发送给任何人。

- 关闭：「偏好设置 → 高级」取消勾选「记录输入日志」。
- 清空：同一页的「清空输入日志」。
- 测试期间若愿意将此文件提供给作者，对改进排序有很大帮助；完全自愿。

## 运行日志

- **macOS**：「~/Library/Logs/Qingjian/」。
- **Windows**：「%APPDATA%\Qingjian\logs」；此外每个应用内的输入法部分另写一份到「%LOCALAPPDATA%\Qingjian\tsf.log」。

按天分文件，保留 7 天。缺省级别不记录输入内容；仅在「高级」页打开「详细日志」后才逐键记录，用于排查问题，排查完成后请关闭。
