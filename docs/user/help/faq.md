## 安装与升级

**安装后输入法列表中没有青简**
macOS 先注销后重新登录，仍没有再到「系统设置 → 键盘 → 输入法 → 编辑 → +」在简体中文下添加；Windows 注销后重新登录。
重启后仍然没有，请[反馈](feedback.md)并附上系统版本与安装方式。

**登录后当前输入法不是青简**（macOS）
已知问题，手动切换一次即可，待签名版解决。

**装了新版后行为没变**（Windows）
升级前已经开着的程序要重新打开才会用上新版，在其中切走输入法再切回没有用；资源管理器重启后，任务栏搜索框才用上新版。只改设置不受此影响。

## 候选窗口

**开始菜单、任务栏搜索框、「设置」里候选窗口被压在下面**（Windows）
两个原因会造成这种情况，打字与上屏本身都正常：

- 青简没装在默认位置（`C:\Program Files`）。请卸载后重装到默认位置。
- 测试版没有正式的代码签名，将在签名版中解决。

**候选窗口挡住了终端或编辑器自己的补全**
英文模式缺省只在浏览器、聊天和文档类应用中给候选，这些应用里不出；被挡住的是中文候选时，切到英文模式即可。见 [中英文](../input/english-mode.md#哪些应用里给候选)。

**某个应用里拼音显示异常**
可先在「设置 → 外观」更换「拼音显示位置」，例如改为「只在窗口」；并请把应用名称与现象[反馈](feedback.md)给作者。

**悬浮状态条不见了**（Windows）
它只在当前输入法为青简时显示，全屏应用中也会收起；确认「设置 → 中英文」里的「悬浮状态条」已打开，或在任务栏「中 / 英」图标的右键菜单里显示它。

## 打字

**打字时什么都不显示，拼音和候选窗口都没有**（Windows）
青简的后台程序可能没在运行。输入法发现后会自己把它重新启动，下一键即恢复；若仍无反应，从开始菜单启动「青简 Server」，或注销后重新登录。

**某个应用中无法切换到青简或输入没反应**（Windows）
注销后重新登录，或重启该应用。

**腾讯软件管理、电脑管家等安全软件里无法输入**（Windows）
这类软件会阻止第三方输入法进入它自己的窗口，青简与其他第三方输入法（系统自带的微软拼音除外）在其搜索框内都无法输入、也无法切换中英。这是该软件的安全机制，输入法一侧无法修复。

**按 Ctrl + Space 切到了别的输入法**（Windows）
`Ctrl + Space` 是 Windows 的「输入法 / 非输入法切换」，只装了青简时它切中英；装了英文键盘或别的输入法时 Windows 可能改用它切换输入法，这由系统决定。处理方法见 [中英文](../input/english-mode.md#改掉或关掉中-英切换)。

**Photoshop 等软件的单键快捷键（`W` `H` `V`）没反应**
切换到英文模式即可，英文模式下字母原样交给这类应用。

**非美式键盘布局下有些键不对**（Windows）
主键盘的数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 与组合音符输入仍有局限。

**某个应用中按键被吞、翻译选中文字读不到文字**
请把应用名称与现象[反馈](feedback.md)给作者。

## 设置

**设置窗口打不开或某项不生效**
可改用旧版设置，见 [设置窗口](../getting-started/settings.md#旧版设置)，并请反馈。

**手动改配置文件改错了**
青简沿用上一份可用的设置，macOS 的输入法菜单会多一条灰色的错误说明；按说明改回并保存即可。见 [直接编辑配置文件](../advanced/config-file.md)。
