## 开启与拖动

在「设置 → 候选窗口」开启「游戏候选窗」。默认用于 Dota 2，建议游戏使用无边框窗口。
打开游戏聊天框后正常输入拼音，拖动候选窗口顶部的拼音栏可调整位置；位置会按游戏分别保存，调整分辨率后会按比例恢复。
切换到其他应用、切换输入法或结束组句后，游戏候选窗口会隐藏。关闭开关即可恢复普通候选窗口。

## 兼容范围

此功能为 Windows 专用。已在 Dota 2 无边框窗口中验证候选显示与拖动；其他游戏需分别测试。
独占全屏可能遮挡桌面候选窗口。若游戏本身不接收青简的中文输入，显示候选窗口不能解决文字上屏问题。
此功能仅使用青简自己的窗口，不向游戏进程注入代码、不安装游戏钩子，也不绕过反作弊。

如需添加其他游戏，可在「设置 → 高级」打开配置编辑相应的游戏名单；配置示例见工程说明，目前没有自动识别所有游戏的功能。
