问题与建议请提到 [GitHub Issues](https://github.com/qingjian-team/qingjian/issues/new/choose)，按表单填写即可；表单会要求下面这些材料。
也可以加 QQ 群 [902314603](https://qm.qq.com/q/jBvn2gGTxm)（青简输入法用户内测体验交流群）直接交流。

## 反馈时请提供

1. 「偏好设置 → 关于 → 复制诊断信息」：版本、系统、加载的数据、配置原文、日志目录，写入剪贴板。API 密钥会被抹去。
2. 运行日志：点「关于 → 打包日志到桌面」，把生成的 zip 发来即可（含日志与配置文件，不含密钥）。也可自取：
   - macOS：「关于 → 打开日志目录」，「~/Library/Logs/Qingjian/」下的「qingjian.log.日期」；
   - Windows：「%LOCALAPPDATA%\Qingjian\logs」，含引擎、各应用内的输入法部分、设置程序三份日志。
3. 出现问题时所在的应用、输入的内容、预期结果与实际结果。

可复现时，先打开「高级 → 详细日志」再复现一次，日志中即有逐键记录；排查完成后请关闭。

## 常见情况

- **安装后输入法列表中没有青简**：macOS 到「系统设置 → 键盘 → 输入法 → 编辑 → +」在简体中文下添加，仍没有则注销后重新登录；
  Windows 注销后重新登录。重启后仍然没有，请[提交 issue](https://github.com/qingjian-team/qingjian/issues/new/choose)并附系统版本与安装方式。
- **开始菜单、任务栏搜索框、「设置」中候选窗口被压在下面**（Windows）：这类系统界面层级高于普通窗口，青简靠 Windows 的 uiAccess 机制把候选窗口抬到它们之上，
  而系统只对装在 `C:\Program Files`（`%ProgramFiles%`）里的程序启用它，装到其他目录或其他盘会静默失效。请卸载后重装到默认目录。测试版没有正式代码签名，同样会失效，将在签名版中解决；两种情况上屏本身都正常。
- **某个应用中无法切换到青简或输入无反应**（Windows）：注销后重新登录，或重启该应用。
- **腾讯软件管理、电脑管家等安全软件中无法输入**（Windows）：这类软件带有进程自我保护（反注入），会阻止第三方输入法加载进它自己的进程；青简与其他第三方输入法（系统自带的微软拼音除外）在其搜索框内都无法输入、也无法切换中英。这是该软件的安全机制，输入法一侧无法修复。
- **候选窗口遮挡了终端 / 编辑器自身的补全**：英文模式在这些应用中缺省不给候选；被遮挡的是中文候选时，切换到英文模式即可。
- **登录后当前输入法不是青简**（macOS）：已知问题，手动切换一次即可，待签名版解决。
- **悬浮状态条不见了**（Windows）：它只在当前输入法为青简时显示；确认「设置 → 候选窗口」中的开关已打开。它每次显示时都会被移回屏幕可见范围内，不会停留在屏幕之外。
- **配置文件改错**：macOS 输入法菜单会增加一条灰色的错误说明，此时沿用上一份可用的配置；按说明改回并保存即可。
- **某个应用中表现异常**（拼音渲染异常、按键被吞、无法读取选区）：请将应用名称与现象反馈给作者；可先在「候选窗口」页更换拼音显示位置作为临时处理。
