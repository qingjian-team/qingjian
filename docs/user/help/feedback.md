问题与建议请提到 [GitHub Issues](https://github.com/qingjian-team/qingjian/issues/new/choose)，按表单填写即可；表单会要求下面这些材料。
也可以加 QQ 群 [902314603](https://qm.qq.com/q/jBvn2gGTxm)（青简输入法用户内测体验交流群）直接交流。

先查一下 [常见问题](faq.md)，很多情况在那里有处理方法。

## 反馈时请提供

1. **日志包**：「设置 → 高级 → 日志文件 → 打包到桌面」，把日志与设置打包成一个文件放在桌面，反馈时附上。API 密钥会被抹去。
   也可以点同一处的「打开日志目录」自己取，位置见 [数据文件与日志](../advanced/data-files.md#运行日志)。
2. 出现问题时所在的应用、输入的内容、预期结果与实际结果。
3. 系统版本与青简的版本（「设置 → 关于」）。

能复现时，先在「设置 → 高级」打开「详细日志」再复现一次，日志中就有逐键记录；排查完成后请关闭，因为它会记下输入的内容。
