## 反馈时带上

1. 「偏好设置 → 关于 → 复制诊断信息」：版本、系统、加载的数据、配置原文、日志目录，写进剪贴板。API 密钥会被抹掉。
2. 「关于 → 打开日志目录」里当天的日志文件。
3. 出问题时在哪个应用、敲了什么、期望什么、实际什么。

能复现的话把「高级 → 详细日志」打开再复现一次，日志里就有逐键记录；查完记得关。

## 常见情况

- **装完输入法菜单里没有青简**：到「系统设置 → 键盘 → 输入法 → 编辑 → +」在简体中文下添加，还没有就注销再登录。
- **候选窗口挡住了终端 / 编辑器自己的补全**：英文模式在这些应用里缺省已经不给候选；被挡的是中文候选的话切到英文（`Caps Lock`）即可。
- **登录后当前输入法不是青简**：已知问题，手动切一次即可，等签名版再看。
- **配置文件改坏了**：输入法菜单会多一条灰色的错误说明，此时沿用上一份能用的配置；照说明改回来保存即可。
- **某个应用里表现不对**（拼音画得难看、按键被吞、读不到选区）：把应用名和现象告诉作者，「候选窗口」页的拼音显示位置可以先换一换试试。
