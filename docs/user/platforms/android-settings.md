以下都在「青简」应用里，开着的键盘立即生效。应用底部有三个页：首页、生词本、设置。

## 首页

- 还没把青简设成当前输入法时，首页显示两步引导：在系统设置里启用青简、切换成青简，做完的一步打勾。
- 设好以后，首页上方是今日字数（附英文词数）、最近 30 天每天的字数，以及近 7 天字数、首选率和每字键数；没有输入时显示 0 或「—」。点这张卡打开统计详情。
- 下面列出最近见过的几个生词，点「生词本」进生词本页；没有选学习语言或还没有生词时不显示。
- 最下面的「试一试」可直接试打。

## 生词本与统计

- 「生词本」页列出打字时候选旁见过的学习语言译词，最近见到的在前。词表上方右边的语言可直接改学习语言。
- 搜索框按词、对应的中文或例句查找，不分大小写，可与筛选一起用。
- 可按「生词 / 近 7 天新见 / 认识了」筛选（近 7 天含今天，滚动计算，不在周一或周日归零）；英语按 A1–C2、日语按 N5–N1 分级筛选。
- 点一个词查看它对应的中文、例句与次数，可标「认识了」（候选里不再标成生词）或从生词本删除。
- 统计详情：顶上切换今天、近 7 天、本月与累计，看这一段的字数与柱状图（今天按小时，其余按天）；下面是最多的一天、速度、首选率、一次打对与平均码长，以及学习语言各级词汇的进度。

## 设置页

「设置」页顶上显示青简是不是当前输入法，点「切换」弹出系统的输入法选择框。下面分组：

- **打字**：输入、键盘、外观、词库，各自是一页，见下文。
- **学语言**：学习语言，换了键盘上的译词立即换；选「不显示」时不显示译词，也不记生词。
- **剪贴板**：剪贴板与局域网同步，见 [Android：工具与 AI](android-tools.md#剪贴板与常用语)。
- **联网服务**：云端大模型与语音识别，都用自己填的服务，不填时青简不联网。云端大模型见 [Android：工具与 AI](android-tools.md#填写-AI-服务)，语音识别见 [Android：键盘与打字](android.md)。
- **数据**与**关于**，见文末。

每行右边显示当前的设定，例如在用的输入方案、主题。

## 输入

「设置 → 输入」：

- **中文输入方案**：拼音全键盘、九宫格、双拼、五笔或注音，点方块切换。选了双拼可选方案、可关掉键上的声韵母小字；选了五笔可与拼音混输。英文都用全键盘。
- **拼音**：
  - 模糊音：可选 z = zh、c = ch、s = sh、n = l、f = h、l = r、an = ang、en = eng、in = ing，见 [拼音方案与模糊音](../input/fuzzy-and-shuangpin.md#模糊音)。九宫格暂不支持。
  - 拼写纠错：拼音敲错时给纠正后的候选，敲的拼音照原样读得通时纠正只排在后面；缺省开启，与电脑版「输入 → 纠错」是同一项。
  - 分次选词先不上屏：缺省开，关闭后选了就上屏。
- **中英混打**：
  - 打拼音时也给英文词：输入 `hello`、`compa` 时候选中出现英文词；可再选「中文排在英文词前面」。
  - 英文键盘给候选：开着时要词点候选，空格、数字、标点前照敲的字母上屏；关闭后英文键盘的字母直接上屏，不出候选。
- **候选后面**：emoji、颜文字、符号三行，各选「不显示」或一次最多配 1–3 个（`kaixin` → 开心 😄、`ku` → 哭 (T_T)、`yuedengyu` → 约等于 ≈）；缺省 emoji 3 个、颜文字与符号各 1 个，与电脑版「候选」页的同名项一致。
- **标点与字形**：
  - 中文用全角标点：关闭后中文键盘的逗号、句号、问号等输出半角。数字后面的点始终是半角。
  - 繁体字形：功能面板「繁体」开启时使用的字形，可选台湾、香港或通用，见 [繁体输出](../input/traditional.md)。
- **学习输入习惯**：关闭后不再记住常选的词和新造的词，已学的继续参与排序。

## 键盘

「设置 → 键盘」：

- **尺寸**：键盘高度，也可点工具栏的 ↕ 直接在键盘上拖动；全面屏适配开启时，手势条两侧各放一个键，可选放什么；两侧都选「不放」时这一条收起，键盘下沉到手势条上方。
- **按键**：按键震动（关 / 轻 / 标准 / 重，标准是原来的手感）、键面字号（小 / 标准 / 大 / 特大，与候选字号分开）、按键气泡、布局（默认 / 左手便捷）。
- **手势**：滑行输入、上滑输入、长按出大写、空格滑动移动光标、长按空格说话、换语言时保留中文，见 [Android：键盘与打字](android.md)。
- **游戏键盘**：横屏时在勾上的应用里换成半透明的悬浮小键盘；透明度、大小、译词与用它的应用都在这一页，见 [Android：键盘与打字](android.md#游戏键盘)。

## 外观

「设置 → 外观」：

- 深浅色：跟随系统、浅色或深色，应用与键盘一起变（应用界面要 Android 12 及以上，更早的系统上应用界面跟随系统）。樱花、大肥鱼、初音未来、波奇酱只有浅色，选深色时仍是浅色。
- 主题：与电脑版相同的九个主题（青简绿、系统蓝、微信绿、素笺、玻璃、樱花、大肥鱼、初音未来、波奇酱），每张卡片显示候选条与键盘的样子。选中后键盘、候选条、符号与表情面板、快捷翻译条一起换成这个主题的颜色。
- 候选字号：小、标准、大、特大，候选与译词一起放大缩小，展开全部候选时也一样；字号调大时候选条随之变高。键面上的字另在「设置 → 键盘 → 键面字号」里调。

页面顶部的预览按当前的主题、深浅色和字号显示。

## 词库

「设置 → 词库」：

- 领域词库：法律、医学、地名、成语、诗词名句、IT 与计算机、财经、饮食、动物、汽车、历史人物，随应用附带，逐本开关。成语缺省开启。
- 导入词库：点「导入词库」，在系统文件选择器中选择文件，可多选。格式同电脑版的拼音词库，见 [词库](../personalize/dictionaries.md#导入自己的词库)。导入后显示名称与条数。
- 导入的词库可单独开关；「删除」后需重新导入。开关、导入和删除对正在使用的键盘立即生效。

## 导出与清空

「设置 → 数据」：

- 导出数据：把学过的词、生词本、输入统计和常用语存为一个 zip 文件，在系统的保存界面中选择存放位置。剪贴板记录与导入的词库不在其中。
- 清空学习数据：可选清空输入习惯（常选的词、造的词、英文词、个人的词序）、生词本（全部语言），或两样都清；确认后立即生效，无法恢复。输入统计、常用语、剪贴板、词库和设置不受影响。
