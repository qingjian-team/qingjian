以下都在「青简」应用里，开着的键盘立即生效。

## 生词本与统计

- 「生词本」页列出打字时候选旁见过的学习语言译词，最近见到的在前。右上方的语言可直接改学习语言。
- 搜索框按词、对应的中文或例句查找，不分大小写，可与筛选一起用。
- 可按「生词 / 近 7 天新见 / 认识了」筛选（近 7 天含今天，滚动计算，不在周一或周日归零）；英语按 A1–C2、日语按 N5–N1 分级筛选。
- 点一个词查看它对应的中文、例句与次数，可标「认识了」（候选里不再标成生词）或从生词本删除。
- 首页上方是输入统计：今日字数（打字够半分钟时附今天速度）、近 7 天与累计字数，最近 30 天每天的字数，以及首选率、一次打对、每字键数和有输入的天数。没有输入时显示 0 或「—」。
- 点首页任一张统计卡（或「我的」页的累计卡）打开统计详情：今天、近 7 天、本月与累计的字数，过去 24 小时与最近 30 天的柱状图，最多的一天、速度、首选率、一次打对与平均码长，以及学习语言各级词汇的进度。

## 词库

「我的 → 词库」（或「键盘设置 → 输入 → 词库」）：

- 领域词库：法律、医学、地名、成语、诗词名句、IT 与计算机、财经、饮食、动物、汽车、历史人物，随应用附带，逐本开关。成语缺省开启。
- 导入词库：点「导入词库」，在系统文件选择器中选择文件，可多选。格式同电脑版的拼音词库，见 [词库](../personalize/dictionaries.md#导入自己的词库)。导入后显示名称与条数。
- 导入的词库可单独开关；「删除」后需重新导入。开关、导入和删除对正在使用的键盘立即生效。

## 外观

「我的 → 外观」：

- 主题：与电脑版相同的八个主题（青简绿、系统蓝、微信绿、玻璃、樱花、大肥鱼、初音未来、波奇酱），每张卡片显示候选条与键盘的样子。选中后键盘、候选条、符号与表情面板、快捷翻译条一起换成这个主题的颜色。
- 深浅色：跟随系统、浅色或深色。樱花、大肥鱼、初音未来、波奇酱只有浅色，选深色时仍是浅色。
- 候选字号：小、标准、大、特大，候选与译词一起放大缩小，展开全部候选时也一样；字号调大时候选条随之变高。键面上的字不变。

页面顶部的预览按当前的主题、深浅色和字号显示。

## 键盘设置

「我的 → 键盘设置」：

- **中文键盘**：选择拼音 26 键、九宫格、双拼、五笔或注音；双拼可选方案，五笔可与拼音混输。
- **学习**：
  - 学习语言，换了键盘上的译词立即换；选「不显示」时不显示译词，也不记生词。
  - 学习输入习惯：关闭后不再记住常选的词和新造的词，已学的继续参与排序。
- **输入**：
  - 模糊音：可选 z = zh、c = ch、s = sh、n = l、f = h、l = r、an = ang、en = eng、in = ing，见 [拼音方案与模糊音](../input/fuzzy-and-shuangpin.md#模糊音)。九宫格暂不支持。
  - 中文用全角标点：关闭后中文键盘的逗号、句号、问号等输出半角。数字后面的点始终是半角。
  - 分次选词先不上屏：缺省开，关闭后选了就上屏。
  - 打拼音时也给英文词：输入 `hello`、`compa` 时候选中出现英文词；可再选「中文排在英文词前面」。
  - 英文键盘给候选：关闭后英文键盘的字母直接上屏，不出候选。
  - 繁体字形：功能面板「繁体」开启时使用的字形，可选台湾、香港或通用，见 [繁体输出](../input/traditional.md)。
  - 词库：进入词库页，见上文。
- **剪贴板**：见 [Android：工具与 AI](android-tools.md#剪贴板与常用语)。
- **云端大模型**：见 [Android：工具与 AI](android-tools.md#填写-AI-服务)。
- **尺寸**：键盘高度，也可点工具栏的 ↕ 直接在键盘上拖动；全面屏适配开启时，手势条两侧各放一个键。
- **按键**：按键震动、按键气泡、换语言时保留中文、长按空格说话、滑行输入，见 [Android：键盘与打字](android.md)。

## 导出与清空

「我的 → 高级」：

- 导出数据：把学过的词、生词本、输入统计和常用语存为一个 zip 文件，在系统的保存界面中选择存放位置。剪贴板记录与导入的词库不在其中。
- 清空学习数据：可选清空输入习惯（常选的词、造的词、英文词、个人的词序）、生词本（全部语言），或两样都清；确认后立即生效，无法恢复。输入统计、常用语、剪贴板、词库和设置不受影响。
