macOS 与 Windows 版是测试版，功能基本相同，按键按各自系统的习惯设计。Linux 版使用 Fcitx 的候选面板，需手动启动。Android 版处于开发阶段，需从源码构建。

「✓」为支持，「—」为暂不支持或不适用。
