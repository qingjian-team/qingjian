青简 Android 版是预览版，功能比桌面版少，也还没有本地整句模型，长句的首选不如桌面版。安装包是 arm64 的 APK，支持 Android 8.0 及以上，在 [GitHub Releases](https://github.com/qingjian-team/qingjian/releases/latest) 下载 `qingjian-<版本>-android-arm64.apk`，在手机上打开安装；系统提示时允许浏览器或文件管理器「安装未知应用」。新版本同样下载 APK 覆盖安装，输入习惯与设置都会保留。想自己构建的，步骤见源码仓库 `apps/android` 目录的说明。
拼音转换、词库、学习与统计全部在手机上完成；只有翻译、补充译词、云联想与语音输入需要联网，且需自行填写服务商。

本组另外两页：[Android：工具与 AI](android-tools.md)、[Android：生词本与设置](android-settings.md)。

## 启用

打开「青简」应用，首页上方的提示卡给出两步：在系统设置中启用青简，再把青简切换为当前输入法。
首页的「试一试」输入框可以直接试打。

## 键盘

- 点工具栏的键盘图标选择输入方式：拼音 9 键、拼音 26 键、双拼、五笔（86 版）、注音（大千）、英文 26 键、日语罗马音（测试版）。
- 中英键按下在中文与另一种语言之间切换，键角小字是将要切到的语言；长按中英键可选择其他语言。
- 九宫格左侧一列在输入拼音时列出同键的拼音，点击可定下这个音节；不在输入时放常用标点。
- 「123」进数字键盘；中文键盘的「符」打开分类符号，英文键盘的「!?#」打开常用符号页。
- 长按空格左右滑动可移动光标；回车键按输入框的用途显示「发送」「搜索」「前往」等。
- 密码、网址、邮箱输入框中按键直接上屏，不进入拼音输入，也不学习。
- 应用标为私密的输入框（如浏览器的无痕标签页）中照常打字，但不学习输入习惯、不记生词，翻译、补充译词与云联想也不发送。

## 候选与译词

- 候选下方附带学习语言的译词，橙色表示生词，见 [候选旁的译词](../learning/translation.md)。学习语言可选英语、日语、西班牙语、越南语、德语，或不显示。
- 长按一个候选弹出它的译词，手指滑到某条译词上松开，上屏这条译词；滑出气泡则取消。
- 能删除的候选（自己造的词、学过的词、英文词）在气泡末尾多一项「删除」：删掉自己造的词，或清除对这个词的学习记录。没有译词的候选，气泡中只有「删除」，需要手指往上滑进气泡才会选中。
- 候选条右端的 ⌄ 展开全部候选。
- 一段拼音分几次选时，先选的词留在输入框里，整段选完再一起上屏；选错了按删除键撤回上一次选择，重新选。按回车连同剩下的拼音原样上屏。不想这样可在键盘设置关掉「分次选词先不上屏」。

## 日期与算式

- 输入 `rq`、`sj`、`xq` 得到当天日期、当前时间和星期；输入 `riqi`、`shijian`、`xingqi` 时，同样的写法紧跟在「日期」「时间」「星期」之后。
- 九宫格中，`77` 这类数字不当作 `rq`；在左侧拼音列依次点 r、q 后才出日期。`7474`（riqi）出「日期」时同样带日期写法。
- 全键盘输入 `v` 后点「123」，接着输入算式，如 `v1+2`，候选给出 `3` 与 `1+2=3`；`v123` 给出中文数字与金额写法。
- 在数字键盘上直接输入 `3+4` 上屏后，候选条给出 `7` 与 `3+4=7`：点 `7` 把算式换成结果，点 `3+4=7` 在后面补上 `=7`。输入 `3×4=` 后候选给出 `12`。日期（`2026-10-19`）和电话号码不当作算式。

## 语音输入

先在青简应用「我的 → 语音识别」中选识别服务。现在可选火山引擎的豆包流式语音识别：在火山引擎控制台开通「豆包流式语音识别」，创建 API Key 填在这里，计费方式选开通的那种（小时版或并发版），可点「测试连接」检查。
这里的设置与翻译用的「云端大模型」分开，互不影响；密钥加密保存在手机上。没选识别服务时，语音入口只提示还不能用。

- 三处入口：按住空格不动片刻（「键盘设置 → 按键 → 长按空格说话」，缺省开启）、工具栏的话筒、全面屏底栏的语音键。第一次使用时系统会询问是否允许青简使用麦克风。
- 说话时听出来的字直接出现在输入框里（带下划线，还没定下），说完后定下。
- 按住空格说：松手结束；滑到左边「撤回输入」上松手，这一段不要了；滑到右边那块上松手，定下后直接执行输入框的动作（聊天框里是发送）。按住空格左右滑动仍是移动光标。
- 点按进来：点下面的话筒或键盘图标说完、回到键盘；点 ⌄ 说完并收起键盘；两块弧也能点。
- 说话时录音发往火山引擎识别，会产生流量和服务费用。识别结果同打出来的字一样计入输入统计，繁体输出开着时转成繁体。

## 滑行输入

打开「键盘设置 → 按键 → 滑行输入」（缺省关闭）后，在拼音全键盘与英文键盘上，手指不抬起依次划过一个词的字母，松手就按划出的形状认出最像的词：拼音键盘认拼音（划 nihao 出「你好」，只划一个音节也行），英文键盘认英文单词。
直线上顺路经过的字母、连着两个相同的字母（hello 的 ll）不用特意绕。认出的字母像点出来的一样给候选，英文键盘不出候选时直接上屏（Shift 亮着首字母大写）。

- 只认词库里有的拼音与英文单词，词库外的新词请点按打。
- 形状几乎一样的词（to 与 too、拼音的 z 与 zh）按常用程度取，不对时退格重来或点按改。
- 打开后的第一次滑行要先准备词表，会稍慢。
- 九宫格、双拼、五笔、注音与日语不支持滑行。
