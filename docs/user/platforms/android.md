青简 Android 版是预览版，功能比桌面版少，也还没有本地整句模型，长句的首选不如桌面版。安装包是 arm64 的 APK，支持 Android 8.0 及以上，在 [GitHub Releases](https://github.com/qingjian-team/qingjian/releases/latest) 下载 `qingjian-<版本>-android-arm64.apk`，在手机上打开安装；系统提示时允许浏览器或文件管理器「安装未知应用」。新版本同样下载 APK 覆盖安装，输入习惯与设置都会保留。想自己构建的，步骤见源码仓库 `apps/android` 目录的说明。
拼音转换、词库、学习与统计全部在手机上完成；只有翻译、补充译词、云联想与语音输入需要联网，且需自行填写服务商。

本组另外两页：[Android：工具与 AI](android-tools.md)、[Android：生词本与设置](android-settings.md)。

## 启用

打开「青简」应用，首页上方的提示卡给出两步：在系统设置中启用青简，再把青简切换为当前输入法。
首页的「试一试」输入框可以直接试打。

## 键盘

- 工具栏左端的青简标打开功能面板，右端收起键盘；中间一排可以自己定：功能面板「常用功能 → 定制工具栏」里，上面一排是工具栏上现在放的，点右上角的「−」移除；下面是全部工具（表情、切换键盘、语音、符号、剪贴板、翻译、键盘高度、常用语、切换输入法、设置），已放的高亮，点没放的加到末尾、点已放的移除，工具栏按加的先后排。右上角「恢复默认」回到原来的样子。改好点左上角的 ✓ 保存并回到键盘，按系统返回键则不保存。放了五个以上时工具栏可以左右滑。
- 点工具栏的键盘图标选择输入方式：拼音 9 键、拼音 26 键、双拼、五笔（86 版）、注音（大千）、英文 26 键、日语罗马音（测试版）。
- 中英键按下在中文与另一种语言之间切换，键角小字是将要切到的语言；长按中英键可选择其他语言。
- 九宫格左侧一列在输入拼音时列出同键的拼音，点击可定下这个音节；不在输入时放常用标点，所以九宫格底排不再单放逗号和句号，空格更宽。
- Shift 点一下只大写下一个字母，快速点两下锁定大写，再点一下解锁。只大写一次时 Shift 键亮着，锁定时亮着且右上角多一个小点。
- 「123」进数字键盘；中文键盘的「符」打开分类符号，英文键盘的「!?#」打开常用符号页。
- 电话号码、数字、日期时间这类输入框弹出的直接是数字键盘，点「返回」仍可换回字母；换到别的输入框回到原来的键盘。
- 键上角的数字或符号：在键上往上一划就上屏它（九宫格划出的是数字），不用长按；中文键盘上 `;` `?` `!` 这类标点跟着「中文标点」设置出全角。只看方向：往上偏左、偏右都算，划出这个键的范围也算，上屏的总是按下的那个键；横着划、往下或中途拐弯就不算。可在「设置 → 键盘 → 手势 → 上滑输入」关掉，缺省开启。
- 在删除键上往上一划，删掉光标前的全部文字（最多 5000 字），候选条上出现「撤销」，点一下原样放回，接着打字就收起；打拼音时上划只清空拼音；按住删除键已经开始连删后再往上划不算。可在「设置 → 键盘 → 手势 → 上划删除键清空」关掉，缺省开启。
- 长按字母弹出气泡（大写、角标符号、小写），手指左右滑选一项再松开；不滑直接松开上屏角标符号。想长按直接出大写，打开「设置 → 键盘 → 手势 → 长按出大写」，缺省关闭。
- 分类符号面板一行排偶数个，成对的括号与引号（【】《》“”）在同一行。
- 打拼音时点候选条上方的拼音行，光标停到点的位置，接着打的字母和删除都在那里，用来补漏打的、改敲错的字母。光标在中间时候选只按光标前的拼音给，选完接着打后面的；光标在开头时按删除键从末尾删。双拼的拼音行显示全拼时按音节停（停在离点的位置最近的两个音节之间），显示敲的键时按键停；九宫格按键停，光标前后仍按挪之前拼音行上的读法显示（`ni'hao` 点在 ni 后，前面还是 ni，后面还是 hao），接着打的数字插在光标处。按住拼音行左右拖，光标跟着手指一格一格挪，每过一格轻震一下。
- 按住空格左右滑动移动光标，滑过的距离越长移得越多，一格一个字；打拼音时不响应，先选词或按回车再挪，拼音里挪光标用点拼音行。可在「设置 → 键盘 → 手势 → 空格滑动移动光标」关掉，缺省开启。
- 回车键按输入框的用途显示「发送」「搜索」「前往」等。
- 英文键盘：候选条给英文词，要哪个词点哪个；空格、数字、标点与回车照敲的字母上屏，不换成候选里的词，验证码、型号这类字母串直接敲就行。打字中途也能点 Shift 换大写。
- 双拼键上的声韵母小字可在「设置 → 输入」（选了双拼时）的「键上显示声韵母」关掉。
- 微软双拼的 `;`（ing）在左下角原来 Shift 的位置：点它是 `;`，往上一划是 Shift（快速划两次锁定大写，`;` 键像 Shift 键一样亮起、锁定时多一个小点），第二排和全拼一样是 9 个键。其他用 `;` 的方案（搜狗、紫光）仍在第二排末尾多一个 `;` 键。
- 「设置 → 键盘 → 按键 → 布局」可从「默认」换成「左手便捷」（键盘功能面板的「左手布局」也能切）：分类符号面板的分类竖排在左边一列、「返回」在左下角，右边一列只剩删除与锁定。
- 密码、邮箱输入框中按键直接上屏，不进入拼音输入，也不学习。
- 浏览器地址栏这类网址框照常打中文；标点保持半角，打拼音时敲 `.`、`/` 会把字母原样落下（`github.com`）。
- 应用标为私密的输入框（如浏览器的无痕标签页）中照常打字，但不学习输入习惯、不记生词，翻译、补充译词与云联想也不发送。

## 候选与译词

- 候选下方附带学习语言的译词，橙色表示生词，见 [候选旁的译词](../learning/translation.md)。学习语言可选英语、日语、西班牙语、越南语、德语，或不显示。
- 长按一个候选弹出它的译词，手指滑到某条译词上松开，上屏这条译词；滑出气泡则取消。
- 能删除的候选（自己造的词、学过的词、英文词）在气泡末尾多一项「删除」：删掉自己造的词，或清除对这个词的学习记录。没有译词的候选，气泡中只有「删除」，需要手指往上滑进气泡才会选中。
- 候选条右端的 ⌄ 展开全部候选；展开后顶上点「单字」只列单字，点「全部」或收起回到全部候选。
- 开了「设置 → 词库 → 通讯录」后，打名字的拼音或简拼，通讯录里的人出现在第一页，右上角带人头；上屏名字后，候选条接着给出这个人的电话、邮箱，点了才上屏，接着打字就收起；这时按删除或重输只收起号码，不删已经上屏的名字。
- 一段拼音分几次选时，先选的词留在输入框里，整段选完再一起上屏；选错了按删除键撤回上一次选择，重新选。按回车连同剩下的拼音原样上屏。不想这样可在「设置 → 输入」关掉「分次选词先不上屏」。
- 选完一个词，候选条接着给可能跟在后面的词（打了「我们」后给「一起」「都」），先按你自己常接的、再按常见搭配；点一下直接上屏，接着再给下一批，可以一路点下去。
  空格、回车、数字和标点照常输入，不会选中联想词；接着打字或挪开光标就收起。不需要可在「设置 → 输入」关掉「上屏后联想」，缺省开启。

## 日期与算式

- 输入 `rq`、`sj`、`xq` 得到当天日期、当前时间和星期；输入 `riqi`、`shijian`、`xingqi` 时，同样的写法紧跟在「日期」「时间」「星期」之后。
- 九宫格左侧的拼音列列出开头这几个键能拼成的所有音节和单个字母，长的在前：打 `643` 时有 nie、mie、ni、mi 和 m、n、o，点 ni 就按 ni 往下拼。
- 在拼音列定下的音节在拼音行上带下划线。按删除键时先撤回已选的字；末尾（或点拼音行挪过去的光标前）是定下的音节就先取消选定、退回成按键，可以重选（`ni'hao` 退一下成 `ni` 加 hao 的三个键），之后一个个删按键。退回后拼音行和候选仍按你选过的音节读，不换成别的读法（`ni` 退回后还是 ni，不会变成 mi）。
- 叹词也能从拼音列选：`64` 选 ng 出「嗯」，`46` 选 hm 出「噷」，`464` 选 hng 出「哼」；只打一个 `6` 并选 n 或 m 时也有「嗯」「呣」。
- 九宫格中，`77` 这类数字不当作 `rq`；在左侧拼音列依次点 r、q 后才出日期。`7474`（riqi）出「日期」时同样带日期写法。
- 全键盘输入 `v` 后点「123」，接着输入算式，如 `v1+2`，候选给出 `3` 与 `1+2=3`；`v123` 给出中文数字与金额写法。
- 在数字键盘上直接输入 `3+4` 上屏后，候选条给出 `7` 与 `3+4=7`：点 `7` 把算式换成结果，点 `3+4=7` 在后面补上 `=7`。输入 `3×4=` 后候选给出 `12`。日期（`2026-10-19`）和电话号码不当作算式。

## 语音输入

先在青简应用「设置 → 语音识别」中选识别服务。现在可选火山引擎的豆包流式语音识别：在火山引擎控制台开通「豆包流式语音识别」，创建 API Key 填在这里，计费方式选开通的那种（小时版或并发版），可点「测试连接」检查。
这里的设置与翻译用的「云端大模型」分开，互不影响；密钥加密保存在手机上。没选识别服务时，点语音入口会在工具栏的位置出一行提示，点它进入「语音识别」页。

- 三处入口：按住空格不动片刻（「设置 → 键盘 → 手势 → 长按空格说话」，缺省开启）、工具栏的话筒、全面屏底栏的语音键。第一次使用时系统会询问是否允许青简使用麦克风。
- 说话时听出来的字直接出现在输入框里（带下划线，还没定下），说完后定下。
- 按住空格说：松手结束；滑到左边「撤回输入」上松手，这一段不要了；滑到右边那块上松手，定下后直接执行输入框的动作（聊天框里是发送）。按住空格左右滑动仍是移动光标。
- 点按进来：点下面的话筒或键盘图标说完、回到键盘；点 ⌄ 说完并收起键盘；两块弧也能点。
- 说话时录音发往火山引擎识别，会产生流量和服务费用。识别结果同打出来的字一样计入输入统计，繁体输出开着时转成繁体。

## 滑行输入

打开「设置 → 键盘 → 手势 → 滑行输入」（缺省关闭）后，在拼音全键盘与英文键盘上，手指不抬起依次划过一个词的字母，松手就按划出的形状认出最像的词：拼音键盘认拼音（划 nihao 出「你好」，只划一个音节也行），英文键盘认英文单词。
直线上顺路经过的字母、连着两个相同的字母（hello 的 ll）不用特意绕。认出的字母像点出来的一样给候选，英文键盘不出候选时直接上屏（Shift 亮着首字母大写，锁定时全大写）。

- 只认词库里有的拼音与英文单词，词库外的新词请点按打。
- 形状几乎一样的词（to 与 too、拼音的 z 与 zh）按常用程度取，不对时退格重来或点按改。
- 打开后的第一次滑行要先准备词表，会稍慢。
- 九宫格、双拼、五笔、注音与日语不支持滑行。

## 游戏键盘

横屏玩游戏时，普通键盘几乎盖满屏幕。给某个应用打开游戏键盘后，在它里面横屏打字时换成一块半透明的悬浮小键盘，键盘外的地方照常点游戏，竖屏还是普通键盘。

- 打开：在那个应用里横屏打字时点工具栏左端的青简标，功能面板「常用功能」里点「游戏键盘」，马上换成悬浮键盘；再点一下关掉。也可以在「设置 → 键盘 → 游戏键盘」里勾，那里只列出横屏用青简打过字的应用。
- 按住键盘顶上那一条拖到任意位置，位置按应用记住。
- 顶上左边的半圆按钮在 不透明 / 20% / 40% / 60% 之间换透明度；旁边的键盘按钮换回普通键盘，并给这个应用关掉游戏键盘；右边的 ⌄ 收起键盘。
- 「设置 → 键盘 → 游戏键盘」还能改透明度、键盘大小（小 / 中 / 大），以及候选旁边要不要显示译词（缺省不显示；不显示时也不记生词）。总开关关掉后，勾着的应用也用普通键盘。
- 悬浮键盘总是深色，候选、面板与工具栏和普通键盘一样能用。
