## 剪贴板与常用语

- 工具栏的剪贴板图标打开剪贴板与常用语。复制过的文字和图片保存在手机上，点击即上屏；密码管理器复制的密码不保存。
- 剪贴板中的一条可加为常用语，或用「拆词」按词选出其中一部分。
- 常用语可分组，可设置输入码；输入输入码即可在候选中直接得到这条常用语。
- 「键盘设置 → 剪贴板」可关闭记录，或设置最多保存的条数。

## 填写 AI 服务

快捷翻译、翻译选中的文字、补充译词与云联想都要用 AI 服务：在青简应用「我的 → 键盘设置 → 云端大模型」中填写兼容 OpenAI 接口的接口地址、模型和 API 密钥，可点「测试连接」检查。
密钥加密保存在手机上，卸载青简后无法恢复。使用会产生流量与服务商的费用。

## 快捷翻译

工具栏的翻译图标打开快捷翻译条，在翻译框中输入原文，译文实时出现在外面的输入框中，点「确定」或回车保留译文，点「取消」撤掉。
中文译成学习语言，其他语言译成中文。翻译框中输入的文字不计入今日字数。

## 翻译选中的文字

在任意应用中选中文字后，在系统的文字选择菜单中点「青简翻译」（部分系统收在菜单的「更多」中），屏幕底部弹出翻译卡片：上方是原文，下方是译文。中文译成学习语言，其他语言译成中文；学习语言选「不显示」时译成英语。

- 复制：把译文放进剪贴板。
- 替换：用译文替换选中的文字。只在能编辑的输入框中出现。
- 翻译失败时，卡片上显示红色的「翻译失败」提示和原因，不提供复制与替换，可点「重试」。
- 点卡片外或按返回键关闭。

AI 服务没填写时卡片上有「去设置」。

## 补充译词

个别词在释义表中没有译词，候选旁空着。在「云端大模型」中打开「补充译词」后，这样的词上屏时交给 AI 补写一条译词，保存在手机上，之后再打这个词，候选旁就有译词，同样计入生词本。
发送的只有这个词本身。缺省关闭；AI 服务没填好时不能开启。学习语言选「不显示」或在私密输入框中时不发送。

## 云联想与整句补全

在「云端大模型」中打开「云联想与整句补全」后，打拼音时停顿片刻，青简把拼音和光标前后的一小段文字交给 AI，它给出的词和整句排在第一个候选之后，前面带小云朵、字是青色的；展开全部候选时也一样。点整句即上屏整句。

- 九宫格同样可用，发送的是拼音行上显示的拼音。
- 「只在 Wi-Fi 下使用」缺省开启：用移动数据时不发送，快捷翻译与补充译词不受影响。
- 缺省关闭；AI 服务没填好时不能开启。私密输入框中不发送。
