青简的输入、词库、学习与译词都在本机完成，不联网。AI 服务是可选的补充，**缺省关闭**，需自行填写一家 AI 服务商（如 DeepSeek）。
数据直接从本机发送到你填写的服务商，不经过青简：青简没有自己的服务器。

## 能做什么

| 功能 | 说明 | 平台 |
|---|---|---|
| [云联想与整句补全](predict.md) | 打拼音时补几个 AI 候选词，并给出一条完整的句子 | macOS、Windows、Linux |
| [问字](question-and-translate.md#问字) | 用拼音提问「三个木是什么字」 | macOS、Windows、Linux |
| [翻译选中的文字](question-and-translate.md#翻译选中的文字) | 把应用里选中的文字译成学习语言或译回中文 | macOS、Windows、Linux |
| [自动补充译词](sentence-translation.md#自动补充译词) | 释义表里没有译词的词，补一条译词 | macOS、Windows |
| [生词本整句翻译](sentence-translation.md#生词本整句翻译) | 把打完的整句翻译后记进生词本 | macOS、Windows |
| [整句候选翻译](sentence-translation.md#整句候选翻译) | 在整句候选右侧显示一条译文 | Windows |

Android 的 AI 功能见 [Android：工具与 AI](../platforms/android-tools.md)。

## 开启

1. 在 AI 服务商的网站上开通服务，取得 API 密钥。任何兼容 OpenAI 接口的服务均可，缺省填好的是 DeepSeek 的地址。
2. 打开「设置 → 云服务」，填写「接口地址」「模型」「API 密钥」。输入框按 `Enter` 或离开时保存，`Esc` 放弃修改；密钥框不显示已保存的密钥。
3. 点「测试连接」：用填写的内容发送一条最短的请求，成功时显示模型名与耗时，失败时显示原因。
4. 打开「启用」，以及需要的各项功能。

关着的时候也可以填写与测试，测试通过再开启。macOS 菜单栏的「中 / 英」后面带 ☁︎ 表示已开启，输入法菜单里也有开关。
Linux 上也可以直接编辑配置文件开启，见 [直接编辑配置文件](../advanced/config-file.md#AI-服务)。

- 密钥只保存在本机，不随配置文件导出，也不会出现在反馈用的日志包里。
- 输入法由系统启动，不读取终端里设置的代理；需要通过代理访问服务商时，请设置系统代理，或使用 TUN 模式的代理工具。
- 使用会产生服务商的费用；用了多少见 [统计](../learning/statistics.md#AI-服务用量)。

## 会发送什么

- **云联想**：正在打的拼音、本机给出的切分与候选。macOS 和 Linux 在应用提供时，还可能附带光标前后的文字（Linux 前后各最多 80 个字，选中的文字除外）；Windows 不附带。
- **问字**：你用拼音打出的问题。
- **翻译选中的文字**：选中的文字（最多 500 字），只在按了翻译快捷键时读取并发送。
- **自动补充译词**：缺译词的那一个词本身。
- **生词本整句翻译**：上屏的整句（两个字以上）或分几次打完的一句话（四个汉字以上），攒几句一起发送；同一句只发一次。
- **整句候选翻译**：当前一条整句候选与目标语言；不发送拼音、应用里的文字或其他候选。

密码框与应用标为私密的输入框中一律不发送。Linux 的 Fcitx4 只能认出密码框，认不出其他私密输入框，使用时请留意。
关闭 AI 服务后不再发送任何请求。
