云联想缺省关闭。打开后，输入拼音时会将当前拼音与光标附近的文字发送给**用户自行填写的** AI 服务商，换回候选词与整句补全。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

## 开启

「偏好设置 → 云服务」：打开开关，填写服务地址、模型、API 密钥。缺省为 DeepSeek，任何 OpenAI 兼容的服务均可。
密钥只保存在本机，不随配置文件导出。菜单栏「中 / 英」之后带 ☁︎ 表示联想已开启。
填写完成后点「测试连接」，将以当前地址、模型、密钥发送一条最小请求，结果显示在窗口底部：成功时显示模型名与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

发送的内容：所敲字母、本机的切分、光标前后各几十个字的上下文、本机给出的候选。详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

Windows AI 候选版默认**按需调用**：输入拼音后按 `Ctrl+Alt+J`，AI 给出的词按推荐顺序排在候选**最前面**，默认最多两项（「云服务」页可调整），带云朵标记。同文的本地候选合并为一项，数字键按当前显示顺序选择，上屏消耗整段拼音。快捷键在「设置 → 快捷键」修改（配置 `[shortcut] predict`）。

需要自动调用时，在「云服务」打开「停顿后自动联想」。默认持续停键 800 毫秒才发送，最短请求间隔为 3000 毫秒；两个时间均可调整。等待期间只保留最新输入，选词上屏、清空或切换输入框会取消尚未发送的请求。快捷键跳过停键等待，仍遵守最短请求间隔；缓存命中直接复用结果。macOS 默认仍自动联想。

每次请求仅含固定系统提示和当前拼音、候选与上下文，历史对话不累计；总 token 用量随请求次数累加。服务商的提示缓存可降低重复前缀的费用，减少调用次数仍是控制用量的主要方式。配置示例：

```toml
[predict]
enabled = true
automatic = false
debounce_ms = 800
min_interval_ms = 3000

[shortcut]
predict = "ctrl+alt+j"
```

已有配置中的等待时间继续沿用；升级后可在设置页调整。已经发送给服务商的请求可能已产生用量，取消功能针对尚未发送的请求。

- AI 结果到达前先显示本地候选；结果到达后，`Space` 上屏当前高亮项，默认是 AI 首选。
- 移动高亮或翻页开始选词后，当前候选顺序保持稳定；继续输入新拼音时再更新。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。
- 只敲声母（简拼，如 `fhyq`）时云端不再给词，只给整句补全——按声母凑出来的词大多不是真词。

## 小字云续写（整句补全）

同一次请求还返回一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧。
`Tab` 接受，继续输入则替换。有应用上下文时接着上下文续写。

Windows「设置 → 云服务 → 小字云续写」可单独关闭（配置 `[predict] sentence = false`）。关闭后只向 AI 请求候选词，省去续写提示内容与续写生成用量，拼音右侧的小字续写收起；AI 候选置顶、停顿后联想与 `Ctrl+Alt+J` 继续生效。只敲声母的简拼原本只请求续写，关闭后使用本地候选，不发送该请求。请求次数与节省的 Token 随输入而变化，可在「统计」页查看实际用量。

## 译词自动补充

Windows AI 候选版关闭后台译词补充，选词上屏不额外发送请求。macOS 中，随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），返回的译词存入本机的个人释义表，下次候选旁即有显示。
关闭云服务后不再发送任何请求。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。
