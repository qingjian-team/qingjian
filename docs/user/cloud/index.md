云联想缺省关闭。打开后，输入拼音时会将当前拼音发送给**用户自行填写的** AI 服务商，换回候选词与整句补全。macOS 和 Linux 在应用支持时还可附带光标附近文字。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

Windows 版还可独立开启[整句候选翻译](sentence-translation.md)：它只发送当前一条本地整句候选，不发送拼音或应用上下文。

## 开启

「设置 → 云服务」：打开「启用」，填写接口地址、模型、API 密钥，可先点「测试连接」。缺省为 DeepSeek，任何 OpenAI 兼容的服务均可。
Linux 也可编辑 `~/.config/qingjian/config.toml` 的 `[predict]` 配置，保存后约一秒内生效，见 [Linux 安装说明](../getting-started/linux.md#可选开启云联想)。
密钥只保存在本机，不随配置文件导出。菜单栏「中 / 英」之后带 ☁︎ 表示联想已开启。
填写完成后点「测试连接」，将以当前地址、模型、密钥发送一条最小请求，结果显示在窗口底部：成功时显示模型名与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

发送的内容：所敲字母、本机的切分与候选；macOS 和 Linux 在应用支持时还可能发送光标前后的文字。详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

输入拼音时停顿 300 毫秒后，云端给出的词补入候选第一页**末尾**两格（「云服务」页可调为 0 至 4），带云朵标记，数字键正常选择，上屏消耗整段拼音。

- 前面的本地候选位置不变，`Space` 上屏的仍是本地首选。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。
- 只敲声母（简拼，如 `fhyq`）时云端不再给词，只给整句补全——按声母凑出来的词大多不是真词。

## 整句补全

同一次请求还返回一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧（Linux 显示在候选面板辅助行）。
`Tab` 接受，继续输入则替换。有应用上下文时接着上下文续写。

## 译词自动补充

随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），返回的译词存入本机的个人释义表，下次候选旁即有显示。
整句上屏的中文没有现成译词，会攒几句一起发送翻译，译文只记进本机的 [生词本](../learning/translation.md#生词本) 时间线；不想发送的话在「云服务」页关闭「生词本整句翻译」，云联想照常可用。
Linux 当前不提供这两项。
关闭云服务后不再发送任何请求。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。

## 联想请求节奏

启用云联想后，默认停键 300 毫秒发出自动请求，两次请求的起始时间至少相隔 3000 毫秒。间隔内继续输入只保留最新拼音；选词、清空或进入私密输入会取消尚未发出的请求。缓存命中复用结果，仍按停键等待，不额外联网。

配置文件的 `[predict]` 中，`debounce_ms` 设置停键等待，`min_interval_ms` 设置最短间隔。云端候选继续补在首页末尾。

普通失败按最短间隔等待，密钥无效或余额不足时保留暂停 10 分钟的保护。模型明确拒绝关思考参数时，仍会去掉该参数重试一次，因此这次联想最多发送两次实际请求。

## API 用量记录

青简记下每次实际发出的 API 请求：请求、响应、失败和没拿到用量的次数，以及接口返回的输入、输出、总 Token 和缓存输入 Token。缓存输入算在输入 Token 里；接口没给用量时单独记为未知。模型拒绝关思考参数后的那次重试单独计数。在设置的「统计」页切到「云服务」就能看到。

## 手动联想（Windows）

Windows 版可以关掉自动联想，只在需要时手动要：组句中按 `Ctrl + Alt + J`，云端结果排到候选最前面；自动联想的结果仍补在第一页末尾。

- 「云服务」页可以关掉「自动联想」，也能调停键等待和最短请求间隔。
- 「快捷键」页可以改手动联想的组合键，改完马上生效，不用重启。
- 移动高亮或翻页之后，晚到的云端词不再插进候选，免得挪动正在选的那一格；拼音右边的整句补全照常显示，按 `Tab` 接受。
- 配置文件里对应 `[predict] automatic` 和 `[shortcut] predict`。
