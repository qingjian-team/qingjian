云联想缺省关闭。打开后，组句时会把当前拼音和光标附近的文字发给**你自己填写的** AI 服务商，换回候选词和整句补全。
数据直接从你的电脑发到服务商，不经过青简；密码框里绝不发送。

## 打开

「偏好设置 → 云服务」：打开开关，填接口地址、模型、API 密钥。缺省是 DeepSeek，任何 OpenAI 兼容接口都行。
密钥只保存在这台电脑上，不随配置文件导出。菜单栏「中 / 英」后带 ☁︎ 表示联想开着。
填完点「测试连接」，会用当前填的地址、模型、密钥发一条最小请求，结果显示在窗口底部：通了显示模型名和用时，不通显示原因。
输入法进程由系统启动，看不到终端里设置的代理变量；如果你靠代理才能访问服务商，要在「系统设置 → 网络」里设系统代理，或者用 TUN 模式的代理工具。

发出去的内容：敲的字母、本机的切分、光标前后各几十个字的上下文、本机给出的候选。详见 [隐私](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

组句中停键 300 毫秒后，云端给的词补进候选第一页**末尾**两格（「云服务」页可调 0 到 4），带云朵标记，数字键照常选，上屏吃掉整段拼音。

- 前面的本地候选一格不挪，空格上屏的仍是本地首选。
- 没到、没词、超时都什么都不变，不预留、不画占位。
- 选中词库里没有的云端词会记成你的词，下次本地直接出。
- 云端可以纠错：`zhgdoima` 也能给出「这个东西吗」。

## 整句补全

同一次请求还给一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵画在拼音右侧。
`Tab` 接受，继续敲键就换掉。有应用上下文时接着上下文写。

## 译词自动补

随包释义表里没有译词的词，你打出它之后会单独问一次云端（只发那个词），回来的译词存进本机的个人释义表，下次候选旁边就有。
关掉云服务就不再发任何请求。

## 什么时候不联想

上屏之后不联想；英文模式、表达式模式不联想；密码框里不联想。
