随包的释义表只有词的译词。开启 AI 服务后，下面三项用它补上缺的部分，见 [AI 服务](index.md)。

## 自动补充译词

macOS 与 Windows 上，释义表里没有译词的词，上屏后单独询问一次（只发送这个词），返回的译词存在本机，下次候选旁即有显示，同样记进生词本。
学习语言选「不显示」或在私密输入框中时不发送。Linux 暂不提供。

## 生词本整句翻译

整句上屏的中文没有现成译词。macOS 与 Windows 上，「设置 → 云服务」的「生词本整句翻译」（缺省开启）打开时，
打完的整句会攒几句一起发送翻译，译文只记进本机的[生词本](../learning/vocabulary.md#时间线)时间线，不显示在候选里。

- 计入的是一次上屏的整句（两个字以上），以及分几次上屏、写完时有四个汉字以上的一句话。
- 同一句只发一次。不想发送整句的话关掉这一项，云联想等其他功能照常。Linux 暂不提供。

## 整句候选翻译

目前仅 Windows 提供。「设置 → 云服务」打开「整句候选翻译」后，本地整句候选（一串拼音转成的一句中文）右侧显示一条译文。它不改变候选排序，也不产生 AI 候选词或整句补全。

- 可单击译文上屏，也可按 `Ctrl + 数字` 上屏对应候选的译文。
- 每次只发送当前这一条整句候选与目标语言，不发送拼音、应用里的文字或其他候选；密码框和私密输入框中不发送。
- 输入继续变化时，旧请求的结果丢弃；上屏、删空拼音或按 `Esc` 时，还没发出的请求撤销。
