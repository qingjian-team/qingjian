整句候选翻译目前仅在 Windows 版提供。它需要联网，并使用「云服务」页中填写的 AI 服务。

本地整句候选（例如把一串拼音转换成一句中文）可以在候选右侧显示一条译文。它不会改变候选排序，也不会生成云端候选词或整句补全。

## 开启

在「设置 → 云服务」打开“整句候选翻译”，再填写服务地址、模型与 API 密钥。

服务须兼容 OpenAI 聊天接口。密钥只保存在本机，不随配置文件导出。

## 使用

译文返回后，可单击译文上屏，也可按 `Ctrl + 数字` 上屏对应候选的第一条译文。

## 发送的内容

每次只发送当前的一条本地整句候选文本以及目标语言，不发送拼音、光标前后上下文或其他候选。密码框和应用标为私密的输入框中不会发送。

输入继续变化时，旧请求的结果会丢弃。上屏、删空拼音或按 `Esc` 取消输入时，尚未发出的联想和翻译请求会撤销，不会占用下一次联想的请求间隔；整句翻译关闭时也一样。
