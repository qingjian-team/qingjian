## 问字

缓冲区为空时敲 `?`（中文模式也可以用问字键 `u`），再用拼音敲问题：

- `?sangemushishenmezi`（三个木是什么字）
- `?mumumu`（报部件）
- `?faguoshoudu`（短事实问答）

停键后云端答字或短答案，带云朵和带声调的读音（森 sēn），数字键选中上屏。`?` 在中英文模式下都能用；`?` 后面紧跟的不是字母就还原成问号上屏
（Windows 上还原后方向键等功能键不再交给应用，回车两个平台都只上屏问号）。

没开云联想时也能进问字模式，但等不到答案，回车上屏原文。

## 翻译选中的文字

在应用里选中一段文字（500 字以内），按 `⌃⌥T`（Windows：`Ctrl+Alt+T`）：

- 选区主要是汉字，译成学习语言；有假名或拉丁字母不少于汉字，译回中文。
- 候选窗口先显示「翻译中…」，译文到了作为唯一候选显示。
- `回车` / `空格` / `1` 用译文替换选区；`Esc` 保留原文；其他键放弃并照常交给应用。

云服务关着、密码框、应用不支持读选区（部分 Electron 应用）时快捷键原样交回应用。快捷键在「偏好设置 → 快捷键」可改；
Windows 上改完要切到别的输入法再切回青简（或重开应用）才生效。
