## 问字

中文模式下以 `u` 开头，再用拼音输入问题：

- `usangemushishenmezi`（三个木是什么字）
- `umumumu`（报部件）
- `ufaguoshoudu`（简短的事实问答）

停顿后返回答字或简短答案，带云朵与带声调的读音（森 sēn），数字键选中上屏。

- `u` 后接的一整串恰好是英文词时（`unchanged`、`us`）不当成问题，直接给英文候选，也不联网；继续拼成不是英文词的问题（`usangemu`）后照常提问。
- 英文词表里没有的词（如 `uber`）仍会进问字：在英文模式下打过一次，它就被记住，之后中文模式里也直接给英文候选。不常用问字的话，也可以在「设置 → 快捷键」把问字的前缀换成 `i`。
- 双拼与五笔拼音混输下 `u` 是编码键，问字改用 `Shift + U` 再接拼音。
- 没开启 AI 服务时同样可进入问字，但不会得到答案，`Enter` 输出原文。

### 用问号进入问字

`?` 缺省只是问号。在「设置 → 快捷键」打开「? 也进问字」后，没在打拼音时输入 `?` 再接拼音同样进入问字，中英文模式下均可用。
这时 `?` 之后接的不是字母时，它还原为普通问号：`Space`、`Enter` 只输出问号本身；逗号等标点跟在问号之后正常输出；`Backspace` 删除它。

## 翻译选中的文字

在应用中选中一段文字（500 字以内），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`；Linux：`Alt + Shift + T`）：

- 选中的以汉字为主时译为学习语言；假名或拉丁字母不少于汉字时译回中文。学习语言选了「不显示」时译成英语。
- 候选窗口先显示「翻译中…」，译文返回后作为唯一候选显示。
- `Enter` / `Space` / `1` 用译文替换选中的文字；`Esc` 保留原文；按其他键放弃翻译，键照常交给应用。

在线与离线翻译均未启用、在密码框里，或应用不提供选中的文字（部分应用）时，快捷键原样交给应用。
快捷键可在「设置 → 快捷键」修改；Windows 上改完要切到其他输入法再切回青简（或重开应用）才生效。

Linux 上的限制：

- 应用需向 Fcitx 提供选中的文字。Fcitx4 在 X11 下还能读取当前应用的系统选区；Wayland 原生应用只能用前一种。
- 从较早版本升级上来、配置文件里写着旧翻译快捷键的，安装更新不会改掉它，需自己改成 `Alt + Shift + T`，见 [直接编辑配置文件](../advanced/config-file.md#AI-服务)。

Android 在系统的文字选择菜单里点「青简翻译」，见 [Android：工具与 AI](../platforms/android-tools.md#翻译选中的文字)。

## 离线翻译（Windows 实验功能）

Windows 提供中英双向的本地翻译。在「设置 → 实验功能 → 离线句子翻译」点击下载模型，下载完成并校验后自动启用。
首次下载需要联网，之后断网也能用，无需 API 账号，也不需要单独启动翻译程序。

仍然是先选中文字，再按 `Ctrl + Alt + T`；译文出现后按 `Enter`、`Space` 或 `1` 替换，`Esc` 保留原文。
Windows 配套版本在「翻译中…」时提前按确认键会继续等待；译文出现后再次确认才使用，不会因提前确认而取消翻译。
支持中文与英语，学习语言设为英语时中文选区译为英语，英文选区译为中文；长内容请分段选择。它只翻译主动选中的文字，不会自动改写正在输入的拼音。
加载或推理失败时保留原文，不会自动把选区发送给在线服务；可在实验功能页关闭离线翻译。

### Windows 输入框兼容模式

选中文字后按翻译快捷键时，青简先尝试通常的选区读取方式。应用不提供选区时，再通过 Windows 辅助功能接口读取；Notepad++ 使用编辑控件提供的选区。
备用读取只在你主动按翻译快捷键时进行，不会持续监视窗口，不模拟复制按键，也不读取剪贴板。密码或已声明私密的输入框不启用它；选区仍限 500 个 UTF-16 单元（常见汉字占一个，部分表情占两个）。

兼容模式会提示「Enter / 空格 / 1 复制译文；Esc 取消；不自动替换原文」。等译文出现后按确认键，看到「译文已复制」再自行按 `Ctrl+V` 粘贴；你也可以先按 `Esc` 关闭候选窗再粘贴。确认前不会改剪贴板，取消也不会覆盖原文。复制失败时保留译文，按 `Enter` 可重试。

正常方式读到的选区仍可直接替换，但回填前会核对文档、焦点、选区位置和原文；发生变化时取消回填。兼容模式在无法读取、读取超时或模型没有返回译文时会显示原因。读取或翻译尚未完成时，请等待候选中的译文出现；兼容模式下提前按确认键只继续等待，不会变成聊天发送键。

模型来自 [Helsinki-NLP OPUS-MT](https://github.com/Helsinki-NLP/Opus-MT)，由 [Xenova](https://huggingface.co/Xenova) 导出 ONNX，中译英采用 CC-BY-4.0，英译中采用 Apache-2.0，见各原始模型卡。机器翻译可能误解术语、人名或语气，确认后再替换。
