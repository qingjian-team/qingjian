## 问字

中文模式下以问字键 `u` 开头，再用拼音输入问题：

- `usangemushishenmezi`（三个木是什么字）
- `umumumu`（报部件）
- `ufaguoshoudu`（短事实问答）

停顿后云端返回答字或简短答案，带云朵与带声调的读音（森 sēn），数字键选中上屏。

`?` 缺省只是问号。在「偏好设置 → 快捷键」勾选「没在输入拼音时敲 ? 也进入问字」后，未输入拼音时输入 `?` 再接拼音同样进入问字，
中英文模式下均可用。双拼下 `u` 是音节键，问字改用 `Shift`+`U` 再接拼音。此时输入 `?` 之后接的不是字母时，它还原为普通问号输出（中文模式遵循「默认中文标点」设置，英文模式使用半角）：
`Space`、`Enter` 只输出问号本身；逗号等标点跟在问号之后正常输出；`Backspace` 删除它。

未打开云联想时同样可进入问字，但不会得到答案，`Enter` 输出原文。

## 翻译选中的文字

在应用中选中一段文字（500 字以内），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）：

- 选区以汉字为主时译为学习语言；假名或拉丁字母不少于汉字时译回中文。
- 候选窗口先显示「翻译中…」，译文返回后作为唯一候选显示。
- `Enter` / `Space` / `1` 用译文替换选区；`Esc` 保留原文；其他键放弃翻译并正常交给应用。

云联想关闭、密码框、应用不支持读取选区（部分 Electron 应用）时，快捷键原样交给应用。快捷键在「偏好设置 → 快捷键」可修改；
Windows 上修改后需切换到其他输入法再切回青简（或重启应用）才生效。

## 离线翻译扩展（Windows）

安装中英双向的本地翻译扩展后，同样选中文字并按 `Ctrl + Alt + T`。
译文出现后按 `Enter` 替换原文，按 `Esc` 放弃；英文选区会译回中文。
一次选择 500 字以内，较长内容分段选择。仅支持中文与英语，其他学习语言需要另外安装相应模型。

设置页面仍沿用「云服务」名称，但扩展使用本机翻译模型，断网也能翻译。
它不会读取剪贴板，也不会保存原文和译文。第一次准备时需要下载模型，之后无需 API 账号。
