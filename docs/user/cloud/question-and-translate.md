需先开启 AI 服务，见 [AI 服务](index.md)。

## 问字

中文模式下以 `u` 开头，再用拼音输入问题：

- `usangemushishenmezi`（三个木是什么字）
- `umumumu`（报部件）
- `ufaguoshoudu`（简短的事实问答）

停顿后返回答字或简短答案，带云朵与带声调的读音（森 sēn），数字键选中上屏。

- `u` 后接的一整串恰好是英文词时（`unchanged`、`us`）不当成问题，直接给英文候选，也不联网；继续拼成不是英文词的问题（`usangemu`）后照常提问。
- 英文词表里没有的词（如 `uber`）仍会进问字：在英文模式下打过一次，它就被记住，之后中文模式里也直接给英文候选。不常用问字的话，也可以在「设置 → 快捷键」把问字的前缀换成 `i`。
- 双拼与五笔拼音混输下 `u` 是编码键，问字改用 `Shift + U` 再接拼音。
- 没开启 AI 服务时同样可进入问字，但不会得到答案，`Enter` 输出原文。报部件（`umumu`）在本地就能出字，不需要 AI 服务，见 [按部件拆字](../input/shortcuts.md#按部件拆字)。

### 用问号进入问字

`?` 缺省只是问号。在「设置 → 快捷键」打开「? 也进问字」后，没在打拼音时输入 `?` 再接拼音同样进入问字，中英文模式下均可用。
这时 `?` 之后接的不是字母时，它还原为普通问号：`Space`、`Enter` 只输出问号本身；逗号等标点跟在问号之后正常输出；`Backspace` 删除它。

## 翻译选中的文字

在应用中选中一段文字（500 字以内），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`；Linux：`Alt + Shift + T`）：

- 选中的以汉字为主时译为学习语言；假名或拉丁字母不少于汉字时译回中文。学习语言选了「不显示」时译成英语。
- 候选窗口先显示「翻译中…」，译文返回后作为唯一候选显示。
- `Enter` / `Space` / `1` 用译文替换选中的文字；`Esc` 保留原文；按其他键放弃翻译，键照常交给应用。

AI 服务关着、在密码框里，或应用不提供选中的文字（部分应用）时，快捷键原样交给应用。
快捷键可在「设置 → 快捷键」修改；Windows 上改完要切到其他输入法再切回青简（或重开应用）才生效。

Linux 上的限制：

- 应用需向 Fcitx 提供选中的文字。Fcitx4 在 X11 下还能读取当前应用的系统选区；Wayland 原生应用只能用前一种。
- 从较早版本升级上来、配置文件里写着旧翻译快捷键的，安装更新不会改掉它，需自己改成 `Alt + Shift + T`，见 [直接编辑配置文件](../advanced/config-file.md#AI-服务)。

Android 在系统的文字选择菜单里点「青简翻译」，见 [Android：工具与 AI](../platforms/android-tools.md#翻译选中的文字)。
