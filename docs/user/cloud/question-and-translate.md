## 问字

中文模式下以问字键 `u` 开头，再用拼音输入问题：

- `usangemushishenmezi`（三个木是什么字）
- `umumumu`（报部件）
- `ufaguoshoudu`（短事实问答）

停顿后云端返回答字或简短答案，带云朵与带声调的读音（森 sēn），数字键选中上屏。

`?` 缺省只是问号。在「偏好设置 → 快捷键」勾选「没在输入拼音时敲 ? 也进入问字」后，未输入拼音时输入 `?` 再接拼音同样进入问字，
中英文模式下均可用。双拼下 `u` 是音节键，问字改用 `Shift`+`U` 再接拼音。此时输入 `?` 之后接的不是字母时，它还原为普通问号输出（中文模式遵循「默认中文标点」设置，英文模式使用半角）：
`Space`、`Enter` 只输出问号本身；逗号等标点跟在问号之后正常输出；`Backspace` 删除它。

未打开云联想时同样可进入问字，但不会得到答案，`Enter` 输出原文。

## 翻译选中的文字

在应用中选中一段文字（Windows 20,000 字以内，macOS 500 字以内），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）：

- 选区以汉字为主时译为学习语言；假名或拉丁字母不少于汉字时译回中文。
- 候选窗口先显示「翻译中…」，译文返回后作为唯一候选显示。
- `Enter` / `Space` / `1` 用译文替换选区；`Esc` 保留原文；其他键放弃翻译并正常交给应用。

云联想关闭、密码框、应用不支持读取选区（部分 Electron 应用）时，快捷键原样交给应用。快捷键在「偏好设置 → 快捷键」可修改；
Windows 上修改后需切换到其他输入法再切回青简（或重启应用）才生效。


## 长文翻译基础

长文翻译支持最多 20,000 个字符。长段落按句尾和段落拆分，后段附带前段的少量原文与译文作为参考；整篇成功后才返回结果。某一段失败时保留原文，不返回半篇译文。数字或指定术语未保留、回复被截断时视为失败，最多尝试三次；认证或余额错误直接停止。此检查不能保证模型的语义准确性，正式使用前仍应核对译文。

每段默认等待最多 30 秒，整篇最多 10 分钟。翻译复用用户自行填写的云服务配置，不附带任何服务密钥。支持的开关与参数位于配置文件 `[predict]`：

```toml
sentence_translation = false
translation_timeout_ms = 30000
terminology = ["项目=Project|プロジェクト"]
```

`sentence_translation` 控制停止输入后为完整中文候选请求译文，默认关闭。开启后仅显示当前学习语言的一条译文，不增加英、日候选行，也不改变中文候选顺序。当前支持学习语言为英语或日语。关闭不影响原有中文云联想。

本节对应各平台共用的翻译基础能力。Windows 已接入长选区读取、安全替换、显式英／日快捷键与原生设置开关；macOS、Linux 的选区长度和界面仍以各自平台实现为准。

可将 `provider = "offline"` 设为只查常用短句缓存；没有本地大模型，缓存未命中不会自动调用收费接口。`selection_provider = "inherit"` 默认跟随此设置，`"cloud"` 表示用户明确允许翻译使用现有云服务，`"disabled"` 关闭翻译请求。启用云服务会将待翻译的原文、少量前段上下文和术语发送到用户配置的服务商。


## Windows 长文与自动翻译

在「偏好设置 → 云服务」打开「长句自动翻译」，选择英语或日语作为学习语言。输入中文拼音后停顿，完整中文候选右侧补充译文；使用原有译词快捷键可上屏。关闭此开关会停止自动翻译，中文输入和中文云联想保持可用。

选区翻译不要求打开自动翻译，但需要启用云服务并填写自己的 API Key：

| 操作 | Windows 默认快捷键 |
|---|---|
| 按原有规则翻译选区 | `Ctrl + Alt + T` |
| 将选区译为英语 | `Ctrl + Alt + Shift + E` |
| 将选区译为日语 | `Ctrl + Alt + Shift + J` |

译文显示后按 Enter / Space / 1 替换整篇，Esc 保留原文。等待期间按确认键仍会继续等待，不会提交空文本。候选窗口只显示前 180 字预览，确认时提交完整译文。失败时提示保留原文，可按 Esc 后重试。如果翻译期间改变选区或改动原文，将取消替换，避免覆盖其他内容。

显式英、日快捷键在「高级 → 打开配置文件」的 `[shortcut] translate_selection_en` / `translate_selection_ja` 中配置；修改后需切换输入法或重新打开应用，使 Windows 重新登记快捷键。应用必须支持标准选区读取与替换，不能保证所有游戏、自绘输入框均支持。
