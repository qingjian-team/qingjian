# 自动组词实现计划

按已确认设计内联执行，不创建分支、不提交，不覆盖现有 Linux 改动。

1. 配置与拼音：新增 `AutoPhraseConfig`（默认开启、4 字，读取钳位 2～10）；Core `set_auto_phrase(bool, usize)` 同时约束相邻词与整段两条路径，保留 2/3 次阈值。先测试默认、边界、关闭和原阈值。
2. 五笔词码：码表缓存最长单字编码，Core `CodeScheme` 显式声明五笔组词规则；测试 2/3/4～10 字、简码、不支持的字与自定义方案。
3. 学习存储：Learner 增加按方案查询/学习编码词，MutedLearner 遵循学习和隐私开关；FrequencyLearner 原子保存、重读、删除、导出清空清单；测试方案隔离、坏行、重启保留。
4. Core 连续输入：有界五笔组合链，首次上屏即学习，查询合并静态与个人码表并去重；测试标点/编辑/焦点/方案边界、关闭、隐私、混输和一级简码顺序。
5. 平台与设置：各桌面壳传全局配置，设置输入页增加开关和长度下拉、搜索入口，中英文本同步；验证配置热加载。
6. 文档与验证：同步用户中文/英文和 crate-notes，运行定向测试、workspace 测试、clippy、fmt；受平台限制的验证如实记录。

审查重点：拼音两条学习路径都受控；形码来源隔离；最长 10 字但编码仍 4 字；关闭不删除已学词；新存储必须纳入数据管理。
