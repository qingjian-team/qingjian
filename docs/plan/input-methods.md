# 输入法横评与可借鉴点

2026-11-23 整理。目的不是评谁好，而是把各家的长处拆成青简能做的条目；每条后面标 `[ ]` 编号对应 [`backlog.md`](backlog.md) 里的任务。

## 桌面

### 搜狗输入法

定位：词库最全、云候选最准，全平台商业输入法。

值得借鉴：

- **专业输入模式**（2026-09 上线，首批 13 个领域：医疗、法律、数学、物理、化学、生物、历史、地理、哲学、金融、建筑、计算机、音乐）。所选领域作为独立候选来源参与排序，不把专业词无脑置顶；还做符号与缩写关联，比如「偏导」联想 `∂`、「DMSO」关联「二甲基亚砜」。医疗词库 100 万+、法律 200 万+ 词条。→ 青简可做「领域词库包」，见 B1。
- **细胞词库**：按学科、行业、游戏订阅，可导入导出。→ B2。
- **U 模式**（拆字/笔画写生僻字）、**V 模式**（数字、日期、大小写转换）。青简问字模式已有拆字与笔顺，V 模式类转换还没有。→ A1。
- **输入法层面撤销**：误上屏能回退。青简三桌面壳已有退格撤销，Android 还没有。→ A2。
- **中英混输自动判边界**、标点随语境切换。青简已有混输与智能标点。→ 已做。
- **候选词拼音提示**（生僻词看发音）。青简候选可显示拼音，已有开关。→ 已做。
- **多用户配置**：同机不同账号词库独立。青简按账户数据目录已隔离。→ 已做。
- **无障碍模式**：字体、对比度放大。青简没有。→ G1。
- **云同步词库/习惯**跨端。青简不做云同步（隐私取向），已有局域网剪贴板同步。→ 不做。

### 微信输入法

定位：轻、干净、跨设备协同。

值得借鉴：

- **跨设备复制粘贴 / 词库与常用语同步**。青简已有局域网剪贴板同步（macOS/Windows），可扩到手机。→ F1。
- **常用语**（地址、账号一键上屏）。青简自定义短语已有，但缺「分组/变量」。→ A3。
- **符号配对、符号转换**。青简有符号面板与成对符号。→ 已做。
- **中文状态下轻按「/」上屏「、」** 这类细节。青简键位可配，但缺预设。→ A4。
- 安装包 206 MB 起步——反面教材：青简安装包 78 MB 仍偏大。→ E1。

### 微软拼音

定位：系统原生、无广告、占用低。

值得借鉴：

- **零配置开箱即用**，默认词库与联想够用。青简默认词库偏小，首次输入体验有差距。→ B3。
- **与系统 Emoji / 符号面板联动**。青简有 emoji 面板（9587 条），但没有系统级入口。→ F2。
- **U 模式 / V 模式**同搜狗。→ A1。
- **自学习词库与云候选**（Win11 进步明显）。青简有本地学习，无云候选（刻意离线，云联想可选）。→ 已做/可选。

### Rime（小狼毫 / 鼠须管）

定位：开源、完全可定制、隐私零担忧。

值得借鉴：

- **配置即代码**：方案、词库、短语全是文本，可版本管理。青简的自定义方案/码表已是文本 + TOML。→ 已做。
- **反查、辅码、拆字**一条链路（雾凇拼音的 `radical_pinyin` 方案）。青简有辅码与拆字，但辅码 Linux 未接。→ A5。
- **百万级精校词库**（雾凇拼音长期维护）。青简词库来自 qingjian-dicts，规模 8.7 万条，差距明显。→ B4。
- **方案选单**（`Ctrl+` ` 或 F4` 切换方案）。青简有方案切换菜单。→ 已做。
- 上手门槛高是反面：青简设置项应保持「能看懂」。

### Fcitx5（小企鹅）

定位：Linux 桌面主流框架，轻量、插件化。

值得借鉴：

- **云拼音**（可关、可选 Google/百度后端、最小拼音长度、代理）。青简云联想是整句补全，不是云拼音候选；可考虑「云候选」只补候选不整句。→ C1。
- **模糊拼音按对勾选**（z/zh、c/ch、s/sh、n/l 等）。青简模糊音有 10 条内置规则，但缺「逐对开关」。→ A6。
- **词库格式开放**：`.dict` 二进制 + 可导入搜狗 `.scel` 与文本。青简的 `.qj`/`.qjz` 是自有格式，导入搜狗细胞词库是空白。→ B5。
- **自定义词组**：`输入,顺序=词组`，右键置顶即保存。青简自定义短语是 TOML 列表，缺「右键即存」。→ A7。
- **卷轴模式、笔画筛选、备份恢复、命令行接口**。青简有 CLI（`qingjian-cli`），备份恢复没有。→ F3。
- **JS 插件 / 主题编辑器**。青简主题是 TOML + 内置十套，无编辑器。→ G2。

### 百度 / QQ / 讯飞（简）

- 百度：云输入、手写、语音、皮肤商店；词库量大。可借鉴「手写补字」→ A8。
- QQ：表情、GIF、游戏词库；可借鉴「游戏术语包」→ B1。
- 讯飞：语音转写强；青简已有 `qingjian-voice`，但只在 macOS 接了语音输入？→ C2。

## 移动

### Gboard

定位：轻快、多语言混输、系统集成。

值得借鉴：

- **多语言同时启用、自动识别语言**（150+ 语言）。青简有中文/英文/越南语三输入法，切换是手动的，缺「同句混输自动判语言」。→ A9。
- **滑行输入（glide typing）**。青简 Android 没有。→ A10。
- **语音输入、手写、表情搜索、GIF、翻译**。青简有语音（部分平台）、emoji 面板；GIF/贴纸没有。→ G3。
- **单手模式**。青简 Android 键盘无。→ G4。

### SwiftKey

定位：预测引擎强、高度个性化、剪贴板管理。

值得借鉴：

- **预测条 + 统计**（用得多越准）。青简有候选与统计页。→ 已做。
- **剪贴板管理器**（历史、固定）。青简有 `qingjian-clipboard` 独立应用 + 局域网同步。→ 已做。
- **多语言混输、主题**。同 Gboard。→ A9 / G2。
- 安装包 230 MB——青简 Android 56 MB 随包数据已算克制，但仍可裁。→ E2。

### 微信键盘 / 搜狗手机 / 小企鹅 Android

- 微信键盘：跨设备、常用语、符号配对。→ F1 / A3。
- 搜狗手机：专业模式（移动端先上）、细胞词库、语音。→ B1 / B2。
- 小企鹅 Android：Rime 插件、方案可选、完全离线。→ 已做。

## 结论

青简的底子（离线、四平台同号、辅码/拆字/混输、轻量）已经在开源输入法那一档；差距集中在三块：

1. **词库规模与领域包**（最影响日常命中率）；
2. **移动端交互**（滑行、单手、手写、跨设备）；
3. **可配置的精细度**（模糊音逐对、词库导入、主题编辑）。
