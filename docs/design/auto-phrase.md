# 自动组词

## 已确认的行为

- `[auto_phrase] enabled = true, max_chars = 4`：所有输入方案共用，最大词长允许 2～10 个汉字，越界钳位；不改变编码长度。
- 拼音、双拼保留现有阈值：同段拼音分次选词重复 2 次，分段连续输入重复 3 次。
- 整句一次接受时保留上游「路径只包含多字词」的过滤与 6 字保护上限，并受全局开关、最大词长和 2 次阈值约束；不会绕过拼音的学习确认次数。
- 上游 `BufferPhrase::created` 的撤销语义保留：本次刚造成的用户词，在整段退格后对同一输入改选时删除，已有词只回退选择记录。
- 五笔首次连续输入即学；按单字全码生成词码：二字 2+2，三字 1+1+2，四字及以上取前三字和末字首码。
- 五笔连续输入使用有界滚动窗口，最多保留配置字数；只学习完整上屏词的连续组合，不从长词中截字。
- 标点、英文、原样上屏、焦点变化、编辑撤销、方案切换打断连续输入。拼音与形码来源互相打断组词，混输不拿拼音按键造五笔词。
- 关闭只阻止新词学习，不删除已有用户词，不关闭词频排序；学习总开关和私密输入优先。
- 自定义形码须在 `scheme.toml` 明确声明 `phrase_rule = "wubi86"`，默认不造词。

## 实现边界

Core 负责连续组合与编码规则，Dictionary 提供单字反查，Learning 分方案保存用户编码词；平台只传配置。
新增 `user-code-words.tsv` 纳入学习数据导出与清空清单，格式为方案键、词、编码三列；主码表只读。
设置 → 输入 → 自动组词：全局开关与 2～10 字选择器，关时禁用长度项。中文、英文文案与用户文档同步。

自动学习沿用已有用户词的保存周期和删除入口；退格打断后续组词，不推断用户正在编辑的外部文本。
