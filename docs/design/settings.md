# 设置程序的页面与设置项

设置程序 `apps/settings` 三个平台共用一份，替掉了 macOS 偏好设置和 Windows 设置程序（两者留一个版本作回退）；Linux 以前没有设置界面，也用它。
本文定的是：分哪几页、每一项放哪页、页里怎么分组排序、标题怎么写、用什么控件。

## 原则

- **按用户想改的事分页，不按代码里的分节分页。** 配置文件是 `[general]` 一大节，以前的「通用」页照搬了这一节，结果什么都往里放。
- **标题就是说明。** 能用一个短语说清的不加说明行。少数必须解释的，放进标题右边的 ⓘ，鼠标悬停（或键盘聚焦）才显示，页面上不出现大段灰字。
- **一件事只在一处。** 以前「打包日志到桌面」「打开日志目录」在「高级」和「关于」各有一份，这次每项只出现在一页。
- **只在某个平台有的项**，在别的平台不显示，不显示成灰的。哪项在哪个平台显示由 `src/support/` 的表决定：每项登记三个平台是支持、不适用还是待实现，后两种都不显示。
- **跟别的设置有依赖的项**（比如字体只对青简渲染器生效）显示成灰的，不另写说明；ⓘ 里写清依赖哪一项。

## 各页

下表里「控件」一列：**开关**是 Switch，**分段**是 Segmented，**下拉**是 Select，**步进**是 Stepper，**勾选**是 Checkbox，**按键**是录键按钮（点一下再按键），**文本**是单行输入框。
「ⓘ」一列是悬停说明的全文，空着就是没有。

| 标题 | 控件 | 配置 |
|---|---|---|

页底一个「恢复默认」按钮，下面用小字列出组句中固定、不能改的键（空格、1–9、回车、Esc 等），这是全页唯一保留的一段说明文字。

模式键只有 v、u、i 三个能选，选了另一个正在用的字母就两个对调，不报错。
录键：点一下按钮进入录制（显示提示），按下的键能用就写进配置、结束录制；不能用（缺修饰键、跟另外两组修饰键撞了、
翻译键不是字母数字）就在这一行下面说原因、接着等；Esc 或点别处取消。修饰键只按着不算，要再按一个键。
字符键按不带修饰键时的字认（⌥1 记成 ⌥ 加 1），Windows 上 ⌘ 那一位记的是 Win 键。
Windows 旧设置程序里「翻译选中文字」只能改修饰键，这里整组都能录。「恢复默认」不动辅码触发键（它在「输入」页）。

### 6 自定义短语

每条一行：开关（勾选，标签是输入码）、第几位、内容的第一行（太长截断）、「编辑」；末尾一行「新增…」。
新增、编辑在对话框里：输入码、位置（步进 1–9）、内容（多行，回车换行），「取消」「保存」，编辑时左边多一个「删除」（点两下）。
保存时整张表交给 `Config::set_custom_phrases` 校验（输入码 1–32 个小写字母、同码同位不能重复），不过就在卡片里说原因、草稿留着；
打开编辑后这条在别处被改了，保存不覆盖。Esc 或「取消」扔掉草稿，换页也关掉卡片。
表下面一行开关「也用系统的文本替换」（只 macOS，`general.system_text_replacements`）。

Windows 和 Linux 以前没有这一页，这次都有了。

### 7 词库

**随包词库**：十一本领域词库排成两列勾选（`dictionaries.domains`），名字去掉统一的「青简领域词库：」前缀，后面跟条数。基础词库一直启用，不列。

**导入的词库**：每行勾选 + 名称 + 条数 + 许可证 + 移除（`dictionaries.disabled`）；末尾一行「导入词库」，可多选文件。
转换在后台线程（大的 Rime 词库要几秒），每个文件一行结果显示在按钮下面；导入成功的同名词库若之前关过会重新打开。
移除是挪进目录里的 `removed/`，不真删；输入法发现文件变了自己重载。清单进这一页时扫一次，导入、移除后重扫。
随包词库的位置：macOS 先找设置程序自己所在的 `.app`，再找装好的 `Qingjian.app/Contents/Resources/dicts`；其他平台在随包根的 `data/generated/dicts`。

### 8 云服务

| 标题 | 控件 | 配置 | ⓘ |
|---|---|---|---|
| 启用 | 开关 | `predict.enabled` | 打字时把光标附近几十个字发给下面的服务，密码框里不发 |
| 云端词 | 步进 0–4，0 显示「不要」 | `predict.slots` | 补进第一页末尾这几格 |
| 整句补全 | 开关 | `predict.sentence` | 按 Tab 采用 |
| 接口地址 | 文本 | `predict.base_url` | |
| 模型 | 文本 | `predict.model` | |
| API 密钥 | 文本（密文），已设置时占位符写「已设置」 | `predict.api_key` | 只存在这台电脑的配置文件里，打包日志时会抹掉 |
| 连接 | 「测试连接」按钮，结果显示在按钮下面 | | |

云联想关着时「云端词」「整句补全」变灰；地址、模型、密钥照样能填能测，先测通再打开。
输入框回车或离开时才存（离开包括换页），Esc 扔掉没存的改动；密钥框不显示已存的密钥。macOS 以前缺「整句补全」，这次补上。

**密钥存哪**：三个平台都写进配置文件的 `[predict] api_key`。macOS 偏好设置以前写在配置同目录的 `.env`，
可输入法重读 `.env` 时不覆盖已有的环境变量，换密钥要重启输入法才生效；写进配置文件热加载就生效，Windows 一直是这么存的。
旧的 `.env` 照样读（设置程序启动时也读进来，好显示「已设置」），配置文件里写了的优先。

### 9 统计

顶上分段切「输入 / 云服务」两层（不做侧栏折叠：侧栏只为一页多一层展开状态不值）；云服务层只在记用量的平台显示（`support` 表的 `ApiUsage`）。
两层结构一样，切换时布局不跳、只换数：今天 / 本周（周日起，同 GitHub 的提交日历）/ 本月 / 累计四张数字卡，近一年按天的格子图（一列一周、周日在上，颜色按当天量相对一年里最多那天开方后分四档），
过去 24 小时的柱状图（最右是现在这个钟点；比「今天」好：早上打开不是空的，跨零点的夜里也连着），再下面详情。图表是 bamboo-slip 的 `Heatmap` / `BarChart`，悬停浮出说明。
输入层详情：最多的一天、日均、速度（今天 / 平均 / 最快一天，只算键间停顿不超过 5 秒的时间）、首选率、一次打对（上屏前没删过的比例）、平均码长、跟一本书比；末尾是词汇一组
（见过、看熟、上屏过、直接打出过、本周新见一句话，有等级表时一张按级的表）。云服务层详情：最多的一天、请求次数一句、Token 表。
数据由输入法写在数据目录（`usage-hourly.tsv` 与只读的老 `usage.tsv`、`api-usage.json` 与 `api-usage-hourly.tsv`、`user-vocab.tsv`），设置程序进这一页时读一次，不写。
`--png` 截图在最后装一份样例数据（`offscreen/sample.rs`）拍这两层。
等级表的位置：macOS 在 `Qingjian.app/Contents/Resources/levels-<语言>.tsv`，其他平台在随包根的 `assets/levels/`。

## 实施顺序

1. 只用现有控件的页：输入（触发键与码表列表除外）、候选、中英文、外观、高级、关于。引擎为此加了折行的段落。
2. 文本输入 + ⓘ：云服务。引擎为此加了输入框（输入法组字、选区、复制粘贴）、悬停说明的浮层、后台线程叫醒窗口。
3. 录键：快捷键、辅码触发键。引擎为此加了录键按钮，修饰键补上原样的 ⌃ / Ctrl 与 ⌘ / Win，字符键按不带修饰键时的字认。
4. 列表、文件对话框：词库、码表。文件选择用 rfd（与 Windows 旧设置程序同一个），清单是普通的分组行，没有另做列表控件。
5. 弹出卡片、多行文本：自定义短语。引擎为此加了对话框（盖住整窗的底加一张卡片）与多行输入框，列表仍用分组行，没做表格。
6. 统计。到这一步十一页都有内容了。
7. 搜索：搜设置行、分组标题、勾选项的标题，行里控件上的字（分段的各项、下拉框的全部选项、录好的键），以及 ⓘ 全文，按这个顺序排；记不清标题时搜选项里的字也能找到那一行。
   输入时侧栏的导航换成结果，点结果（或回车取第一条）跳到那页，那一行滚进视野、铺一层底色再淡出，Esc 清空。
   索引不手写：设置行这些控件建树时自己登记，开始搜时离屏把每页建一遍收来，所以按当前配置藏起来的项（别的平台的、依赖没开的）也搜不到。
8. 换掉旧设置程序：新程序装进安装包，输入法菜单「设置…」、Windows 状态条的 ⚙、开始菜单与 Linux 应用菜单的「青简设置」打开它。
   - 安装位置：macOS 是 `Qingjian.app/Contents/Applications/QingjianSettings.app`（独立的 .app，自己的 Dock 图标与名字，`open` 打开；随包数据从外层 `Qingjian.app` 读）；
     Windows 是与 Server 同目录的 `qingjian-settings.exe`（只开一个，第二次启动把已开的带到前台）；Linux 是 `<前缀>/bin/qingjian-settings` 加一个 `.desktop`。
   - 回退：旧的 macOS 偏好设置（菜单「旧版设置…」）与 Windows 设置程序（`qingjian-settings-legacy.exe`，任务栏「中 / 英」右键菜单「旧版设置…」与开始菜单「青简旧版设置」）留一个版本，下个版本删。
     新程序打不开时用旧版；某项不生效靠测试拦：`config_keys` 离屏点遍每一页的控件，变了的键用输入法的 `Config` 读回核对。
   - ⓘ 可点：悬停仍是短说明，末尾一行「点一下 ⓘ 打开文档」，点了打开官网文档对应的一段（`docs.rs` 一张表，按页与行标题对到 `docs/user/` 的某个标题，
     锚点照官网的 `headingId` 生成）。测试核对表里每一段在文档里真有这个标题、每一行在那页上真有 ⓘ，文档改标题时测试报错。
   - 用户文档 `docs/user/settings/preferences.md` 按新的页与组重写，别处的「偏好设置 → 通用」这类指路改成新的页名。
   - 「复制诊断信息」还没有：要输入法把运行状态写成文件，留到以后；反馈时先用「高级 → 打包到桌面」。
