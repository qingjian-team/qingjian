# iOS 键盘扩展 spike 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `apps/ios` 建容器 App + 键盘扩展，Rust Core 链进扩展，26 键全拼出候选、能上屏，装到真机后测含章模型能否装进键盘扩展的内存上限。

**Architecture:** Core 一行不动。`apps/ios/core` 是 Rust staticlib，手写 C ABI 暴露建引擎 / 按键 / 选词 / 取上屏文本 / 渲染位图 / 加载模型；Swift 键盘扩展用 UIKit 画键，候选条由渲染器出位图贴图。Xcode 工程用 XcodeGen 从 `project.yml` 生成，`.xcodeproj` 不进仓库。

**Tech Stack:** Rust 1.96（`aarch64-apple-ios` / `aarch64-apple-ios-sim`），qingjian-core / render / lm / neural，Swift 5 + UIKit，XcodeGen（已装在 `/opt/homebrew/bin/xcodegen`），Xcode 26。

**与 spec 的一处偏差：** spec 写「`qj_render` 画整帧 + `qj_hit_test` 在 Rust 里命中」。渲染器横排输出不带各候选的 x 区间，补命中表要改渲染器。spike 改成**每个候选单独渲染一张位图**（`qj_render_candidate(i)`），Swift 一张一个按钮，命中由视图层天然完成，不需要 hit test。Task 11 同步改 spec。

**约定提醒（见 `docs/contributing.md`）：** 一个类型一个文件、新文件 `//!` 头、注释中文、`thiserror` 不用 `anyhow`、不写装饰性分隔注释、提交信息 Conventional Commits 中文说明、提交末尾加 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`。每个任务提交前 `cargo fmt --all` 与 `cargo clippy -p qingjian-ios --all-targets -- -D warnings`（pre-commit 钩子会跑整 workspace）。

```rust
//! iOS 的字体文件清单。系统字体散在 `/System/Library/Fonts/` 下几个子目录里，各版本目录名有变，
//! 所以按文件名在几个候选目录里找，找不到的角色留空由 cosmic-text 回退。

use std::path::PathBuf;

const FONT_DIRS: &[&str] = &[
    "/System/Library/Fonts/Core",
    "/System/Library/Fonts/CoreUI",
    "/System/Library/Fonts/CoreAddition",
    "/System/Library/Fonts/LanguageSupport",
    "/System/Library/Fonts/AppFonts",
    "/System/Library/Fonts/Extra",
    "/System/Library/Fonts",
];

/// 界面字体：SF UI；都没有就退到 Helvetica。
pub(super) fn ui_fonts() -> Vec<PathBuf> {
    locate(&["SFUI.ttf", "SFUIText.ttf", "SFNS.ttf", "Helvetica.ttc"])
}

/// 汉字：PingFang；加日文作为日语译文的回退。
pub(super) fn script_fonts(locale: &str) -> Vec<PathBuf> {
    let mut fonts = Vec::new();
    if !locale.starts_with("ja") {
        fonts.extend(locate(&["PingFang.ttc", "PingFangUI.ttc"]));
    }
    fonts.extend(locate(&["ヒラギノ角ゴシック W4.ttc", "HiraginoSans-W4.ttc"]));
    fonts
}

pub(super) fn emoji_fonts() -> Vec<PathBuf> {
    locate(&["AppleColorEmoji.ttc", "Apple Color Emoji.ttc"])
}

/// 每个文件名在候选目录里找第一个存在的；一个都没有就不列。
fn locate(names: &[&str]) -> Vec<PathBuf> {
    names
        .iter()
        .filter_map(|name| {
            FONT_DIRS
                .iter()
                .map(|dir| PathBuf::from(dir).join(name))
                .find(|path| path.is_file())
        })
        .collect()
}
```

```rust
//! 组装 Engine：装的东西与 Linux Server 的 `assembly` 一致，但只认全拼，不装英文词表 / emoji / 码表。
//! 词库 `dict.qj`（或 `dict.tsv`）必需，释义表 `glossary-en.qj`（或 `.tsv`）与语言模型 `lm.qj` 缺了就少那个功能。

use std::path::{Path, PathBuf};

use qingjian_core::{Engine, Language};
use qingjian_dictionary::Dictionary;
use qingjian_learning::FrequencyLearner;
use qingjian_lm::BigramModel;
use qingjian_translate::Glossary;

use crate::error::IosError;

pub fn assemble(resources: &Path, user_dir: Option<&Path>) -> Result<Engine, IosError> {
    let dict = first_existing(resources, &["dict.qj", "dict.tsv"])
        .ok_or_else(|| IosError::MissingDictionary(resources.join("dict.qj")))?;
    let dictionary = Dictionary::from_path(&dict)?;
    let learner = match user_dir {
        Some(dir) => load_learner(dir),
        None => FrequencyLearner::default(),
    };
    tracing::info!(entries = dictionary.len(), learned = learner.len(), "词库与学习数据已加载");
    let mut engine = Engine::new(dictionary).with_learner(Box::new(learner));
    if let Some(path) = first_existing(resources, &["glossary-en.qj", "glossary-en.tsv"]) {
        match Glossary::from_path(Language::English, &path) {
            Ok(glossary) => engine = engine.with_translator(Box::new(glossary)),
            Err(error) => tracing::warn!(%error, "释义表加载失败，继续中文输入"),
        }
    }
    if let Some(path) = first_existing(resources, &["lm.qj"]) {
        match BigramModel::from_path(&path) {
            Ok(model) => engine = engine.with_language_model(Box::new(model)),
            Err(error) => tracing::warn!(%error, "语言模型加载失败，使用词频整句"),
        }
    }
    Ok(engine)
}

fn first_existing(dir: &Path, names: &[&str]) -> Option<PathBuf> {
    names.iter().map(|n| dir.join(n)).find(|p| p.is_file())
}

/// 读不了就退回只在内存里学，不拿空表覆盖用户文件。
fn load_learner(dir: &Path) -> FrequencyLearner {
    let path = dir.join("user.tsv");
    match FrequencyLearner::from_path(&path) {
        Ok(learner) => learner,
        Err(error) => {
            tracing::error!(path = %path.display(), %error, "学习数据读取失败，本次只在内存里学习");
            FrequencyLearner::default()
        }
    }
}
```

```rust
//! Swift 送来的按键类型。字母 / 数字走 `Char` 带字符，其余是功能键。

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u8)]
pub enum KeyKind {
    Char = 0,

    Backspace = 1,

    Space = 2,

    Return = 3,

    Escape = 4,
}

impl KeyKind {
    pub fn from_u8(value: u8) -> Option<Self> {
        Some(match value {
            0 => Self::Char,
            1 => Self::Backspace,
            2 => Self::Space,
            3 => Self::Return,
            4 => Self::Escape,
            _ => return None,
        })
    }
}
```

`key/outcome.rs`：

```rust
//! 一次按键 / 选词的结果，告诉 Swift 接下来做什么。

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[repr(u8)]
pub enum Outcome {
    /// 吞掉了，重画候选条即可。
    Consumed = 0,

    /// 有文本要上屏，用 `qj_take_commit` 取；取完重画。
    Commit = 1,

    /// 没在组句，这个键归宿主应用（Swift 自己 insertText / deleteBackward）。
    Passthrough = 2,
}
```

```rust
//! 一个键盘会话的全部状态：Engine、渲染器、当前候选布局、待上屏文本。FFI 的 `QjEngine*` 就是它。
//! 单线程，Swift 在主线程调。

mod keys;
mod model;
mod render;
#[cfg(test)]
mod tests;

use qingjian_core::{CandidateLayout, Engine};
use qingjian_render::{Preedit, Rendered, Renderer};

/// 一页放几个候选；手机候选条横排，先给 5 个，Swift 可横向滚。
const PAGE_SIZE: usize = 5;

pub struct Handle {
    pub(crate) engine: Engine,

    /// 字体库建不起来时为 `None`，候选只能走文本（Swift 用 `candidate_text`）。
    pub(crate) renderer: Option<Renderer>,

    /// 当前组句的候选；没在组句是 `None`。
    pub(crate) layout: Option<CandidateLayout>,

    /// 当前拼音行；没在组句是 `None`。
    pub(crate) preedit: Option<Preedit>,

    /// 待 Swift 取走的上屏文本。
    pub(crate) pending_commit: String,

    /// 最近一次渲染结果，`qj_render_*` 返回的指针指向它，下次渲染前有效。
    pub(crate) last_rendered: Option<Rendered>,

    /// 加载中的含章模型是否已挂上 Engine（调试面板用）。
    pub(crate) model_loaded: bool,
}

impl Handle {
    pub fn new(engine: Engine) -> Self {
        let renderer = match qingjian_render::FontLibrary::system("zh-CN") {
            Ok(library) => Some(Renderer::new(library)),
            Err(error) => {
                tracing::warn!(%error, "字体库建不起来，候选条只给文本");
                None
            }
        };
        Self {
            engine,
            renderer,
            layout: None,
            preedit: None,
            pending_commit: String::new(),
            last_rendered: None,
            model_loaded: false,
        }
    }

    pub fn candidate_count(&self) -> usize {
        self.layout.as_ref().map_or(0, CandidateLayout::len)
    }

    pub fn candidate_text(&self, index: usize) -> Option<&str> {
        self.layout
            .as_ref()?
            .candidate(index)
            .map(|c| c.text.as_str())
    }

    pub fn preedit(&self) -> Option<&Preedit> {
        self.preedit.as_ref()
    }

    /// 取走待上屏文本。
    pub fn take_commit(&mut self) -> String {
        std::mem::take(&mut self.pending_commit)
    }

    /// 学习数据落盘；扩展失活时调。
    pub fn flush(&mut self) {
        self.engine.flush_learning();
    }
}
```

```rust
//! 按键怎么作用到 Engine。规则是 Linux Server `dispatch/key/input.rs` 的全拼子集：
//! 字母进拼音、空格上屏高亮（第一个）、回车原样上屏拼音、退格 / Esc 编辑缓冲，没在组句时功能键归应用。

use qingjian_core::{CandidateLayout, MarkedKind};
use qingjian_render::{Preedit, PreeditSegment, PreeditStyle};

use super::{Handle, PAGE_SIZE};
use crate::{KeyKind, Outcome};

impl Handle {
    pub fn key(&mut self, kind: KeyKind, ch: char) -> Outcome {
        let composing = !self.engine.composition().is_empty();
        match kind {
            KeyKind::Char if ch.is_ascii_lowercase() => {
                self.engine.push(ch);
                self.recompose();
                Outcome::Consumed
            }
            KeyKind::Char if composing && ch.is_ascii_digit() && ch != '0' => {
                let index = (ch as u8 - b'1') as usize;
                self.select(index)
            }
            KeyKind::Char => Outcome::Passthrough,
            KeyKind::Backspace if composing => {
                self.engine.backspace();
                self.recompose();
                Outcome::Consumed
            }
            KeyKind::Escape if composing => {
                self.engine.clear();
                self.recompose();
                Outcome::Consumed
            }
            KeyKind::Space if composing => self.select(0),
            KeyKind::Return if composing => {
                let raw = self.engine.take_raw();
                self.commit(raw)
            }
            KeyKind::Backspace | KeyKind::Escape | KeyKind::Space | KeyKind::Return => {
                if kind == KeyKind::Return {
                    self.engine.note_passthrough('\n');
                }
                Outcome::Passthrough
            }
        }
    }

    /// 选第 `index` 个候选（跨页下标）；越界就当没按。
    pub fn select(&mut self, index: usize) -> Outcome {
        let Some(candidate) = self.layout.as_ref().and_then(|l| l.candidate(index).cloned()) else {
            return Outcome::Consumed;
        };
        let text = self.engine.commit(&candidate);
        self.commit(text)
    }

    fn commit(&mut self, text: String) -> Outcome {
        self.pending_commit.push_str(&text);
        self.recompose();
        Outcome::Commit
    }

    /// 缓冲变了：重查候选，重建布局与拼音行。
    pub(super) fn recompose(&mut self) {
        if self.engine.composition().is_empty() {
            self.layout = None;
            self.preedit = None;
            return;
        }
        match self.engine.query() {
            Ok(query) => {
                let segments = query
                    .marked_segments()
                    .into_iter()
                    .map(|s| PreeditSegment {
                        text: s.text,
                        style: match s.kind {
                            MarkedKind::Typed => PreeditStyle::Typed,
                            MarkedKind::Rest => PreeditStyle::Rest,
                            MarkedKind::Corrected => PreeditStyle::Struck,
                            MarkedKind::AuxCode => PreeditStyle::AuxCode,
                        },
                    })
                    .collect();
                self.preedit = Some(Preedit {
                    segments,
                    cursor: query.marked_cursor(),
                });
                self.layout = Some(CandidateLayout::new(query.candidates.items, PAGE_SIZE, 0));
            }
            Err(_) => {
                // 查询失败（上屏后剩下不可切分的残余）：显示原始拼音、无候选，与 Linux 的 Composed::Raw 一致
                let composition = self.engine.composition();
                let text = composition.text().to_owned();
                let cursor = text[..composition.cursor()].chars().count();
                self.preedit = Some(Preedit::plain(&text, cursor));
                self.layout = None;
            }
        }
    }
}
```

```rust
//! 候选条的位图：每个候选单独一张（Swift 一张一个按钮，命中由视图做），拼音行一张。
//! 横排、无阴影、内置浅色主题；`scale` 是点到像素的倍数（iPhone 为 3）。

use qingjian_core::{Candidate, CandidateKind};
use qingjian_render::{Frame, Layout, Rendered, Row, Theme, Tone};

use super::Handle;

impl Handle {
    /// 第 `index` 个候选（跨页下标）的位图；越界或没有渲染器是 `None`。
    pub fn render_candidate(&mut self, index: usize, scale: f32) -> Option<&Rendered> {
        let candidate = self.layout.as_ref()?.candidate(index)?.clone();
        let frame = Frame {
            rows: vec![row(&candidate)],
            highlighted: None,
            ..Frame::default()
        };
        self.render_frame(&frame, scale)
    }

    /// 拼音行的位图；没在组句或没有渲染器是 `None`。
    pub fn render_preedit(&mut self, scale: f32) -> Option<&Rendered> {
        let frame = Frame {
            preedit: Some(self.preedit.clone()?),
            ..Frame::default()
        };
        self.render_frame(&frame, scale)
    }

    fn render_frame(&mut self, frame: &Frame, scale: f32) -> Option<&Rendered> {
        let renderer = self.renderer.as_mut()?;
        match renderer.render(frame, Layout::Horizontal, &Theme::light(), scale, None) {
            Ok(rendered) => {
                self.last_rendered = Some(rendered);
                self.last_rendered.as_ref()
            }
            Err(error) => {
                tracing::warn!(%error, "渲染失败");
                None
            }
        }
    }
}

/// 序号不画（手机上点，不按数字选）；译文作 annotation。规则与 Windows `ui/candidates/row.rs` 一致的子集。
fn row(candidate: &Candidate) -> Row {
    let mut annotation = Vec::new();
    if let Some(translation) = &candidate.translation {
        for (i, sense) in translation.senses().iter().enumerate() {
            if i > 0 {
                annotation.push((" · ".to_owned(), Tone::Faint));
            }
            let tone = if sense.fresh { Tone::Fresh } else { Tone::Gloss };
            for segment in sense.furigana() {
                annotation.push((segment.text, tone));
            }
        }
    }
    Row {
        index: String::new(),
        text: candidate.text.clone(),
        code: None,
        annotation,
        cloud: candidate.kind == CandidateKind::Cloud,
    }
}
```

```rust
//! C ABI。`QjEngine` 是 [`Handle`](crate::Handle) 的不透明指针；字符串进来是 NUL 结尾 UTF-8，出去写进调用方的缓冲。

mod engine;

mod keys;

use std::path::PathBuf;

use crate::Handle;

/// 不透明句柄；C 侧只见指针。
pub type QjEngine = Handle;

/// NUL 结尾 UTF-8 → 路径；空指针或非 UTF-8 是 `None`。
unsafe fn path_arg(ptr: *const c_char) -> Option<PathBuf> {
    if ptr.is_null() {
        return None;
    }
    // SAFETY: 调用方保证是 NUL 结尾字符串
    let s = unsafe { CStr::from_ptr(ptr) }.to_str().ok()?;
    Some(PathBuf::from(s))
}

/// 把 `text` 拷进调用方缓冲，返回写入字节数；放不下就截在字符边界。
fn copy_out(text: &str, buf: *mut u8, cap: usize) -> usize {
    if buf.is_null() || cap == 0 {
        return 0;
    }
    let mut end = text.len().min(cap);
    while !text.is_char_boundary(end) {
        end -= 1;
    }
    // SAFETY: 调用方保证 buf 至少 cap 字节
    unsafe { std::ptr::copy_nonoverlapping(text.as_ptr(), buf, end) };
    end
}
```

```rust
use std::ffi::c_char;

use super::{QjEngine, path_arg};

/// `resources_dir` 必需；`user_dir` 可为 NULL（只在内存学习）。失败返回 NULL 并写日志。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn qj_engine_new(
    resources_dir: *const c_char,
    user_dir: *const c_char,
) -> *mut QjEngine {
    // SAFETY: 由调用方保证两个指针要么 NULL 要么指向 NUL 结尾字符串
    let Some(resources) = (unsafe { path_arg(resources_dir) }) else {
        return std::ptr::null_mut();
    };
    let user = unsafe { path_arg(user_dir) };
    match assemble(&resources, user.as_deref()) {
        Ok(engine) => Box::into_raw(Box::new(Handle::new(engine))),
        Err(error) => {
            tracing::error!(%error, "Engine 组装失败");
            std::ptr::null_mut()
        }
    }
}

/// 释放；NULL 安全。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn qj_engine_free(engine: *mut QjEngine) {
    if !engine.is_null() {
        // SAFETY: 指针来自 qj_engine_new，且只释放一次
        drop(unsafe { Box::from_raw(engine) });
    }
}

/// 学习数据落盘。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn qj_flush(engine: *mut QjEngine) {
    // SAFETY: 指针来自 qj_engine_new 且未释放
    if let Some(handle) = unsafe { engine.as_mut() } {

    }
}
```

```rust
pub unsafe extern "C" fn qj_candidate_count(engine: *const QjEngine) -> usize {

    unsafe { engine.as_ref() }.map_or(0, |h| h.candidate_count())
}

/// 第 `index` 个候选的文本写进 `buf`（渲染器不可用时的退路），返回字节数。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn qj_candidate_text(
    engine: *const QjEngine,
    index: usize,
    buf: *mut u8,
    cap: usize,
) -> usize {
    // SAFETY: 同上
    let Some(text) = (unsafe { engine.as_ref() }).and_then(|h| h.candidate_text(index)) else {
        return 0;
    };
    copy_out(text, buf, cap)
}

/// 渲染第 `index` 个候选，填 `out`；越界或没有渲染器返回 false。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn qj_render_candidate(
    engine: *mut QjEngine,
    index: usize,
    scale: f32,
    out: *mut QjBitmap,
) -> bool {
    // SAFETY: 同上；out 由调用方提供
    let (Some(handle), Some(out)) = (unsafe { engine.as_mut() }, unsafe { out.as_mut() }) else {
        return false;
    };
    match handle.render_candidate(index, scale) {
        Some(rendered) => {
            *out = QjBitmap::from_rendered(rendered);
            true
        }
        None => false,
    }
}

/// 渲染拼音行；没在组句或没有渲染器返回 false。
#[unsafe(no_mangle)]
pub unsafe extern "C" fn qj_render_preedit(
    engine: *mut QjEngine,
    scale: f32,
    out: *mut QjBitmap,
) -> bool {
    // SAFETY: 同上
    let (Some(handle), Some(out)) = (unsafe { engine.as_mut() }, unsafe { out.as_mut() }) else {
        return false;
    };
    match handle.render_preedit(scale) {
        Some(rendered) => {
            *out = QjBitmap::from_rendered(rendered);
            true
        }
        None => false,
    }
}
```

```swift
//  Rust Core 的 Swift 包装：把 C 指针与缓冲收在一个类里，键盘其他部分只见 Swift 类型。
import UIKit

enum KeyKind: UInt8 { case char = 0, backspace, space, `return`, escape }
enum Outcome: UInt8 { case consumed = 0, commit, passthrough }

final class Engine {
    private let raw: OpaquePointer

    /// 资源目录是扩展 bundle 的 `data/`；用户目录是 App Group 容器。建不起来返回 nil。
    init?() {
        guard let resources = Bundle.main.resourceURL?.appendingPathComponent("data").path else { return nil }
        let user = FileManager.default
            .containerURL(forSecurityApplicationGroupIdentifier: "group.app.qingjian")?
            .appendingPathComponent("Qingjian", isDirectory: true)
        if let user { try? FileManager.default.createDirectory(at: user, withIntermediateDirectories: true) }
        guard let engine = qj_engine_new(resources, user?.path) else { return nil }
        raw = engine
    }

    deinit { qj_engine_free(raw) }

    func key(_ kind: KeyKind, _ ch: Character? = nil) -> Outcome {
        let scalar = ch?.unicodeScalars.first?.value ?? 0
        return Outcome(rawValue: qj_key(raw, kind.rawValue, scalar)) ?? .passthrough
    }

    func select(_ index: Int) -> Outcome {
        Outcome(rawValue: qj_select(raw, index)) ?? .passthrough
    }

    func takeCommit() -> String {
        var buf = [UInt8](repeating: 0, count: 1024)
        let n = qj_take_commit(raw, &buf, buf.count)
        return String(decoding: buf[..<n], as: UTF8.self)
    }

    var candidateCount: Int { qj_candidate_count(raw) }

    func candidateText(_ index: Int) -> String {
        var buf = [UInt8](repeating: 0, count: 256)
        let n = qj_candidate_text(raw, index, &buf, buf.count)
        return String(decoding: buf[..<n], as: UTF8.self)
    }

    func candidateImage(_ index: Int, scale: CGFloat) -> UIImage? {
        var bitmap = QjBitmap()
        guard qj_render_candidate(raw, index, Float(scale), &bitmap) else { return nil }
        return Self.image(from: bitmap)
    }

    func preeditImage(scale: CGFloat) -> UIImage? {
        var bitmap = QjBitmap()
        guard qj_render_preedit(raw, Float(scale), &bitmap) else { return nil }
        return Self.image(from: bitmap)
    }

    func loadModel(named name: String) -> Bool {
        guard let path = Bundle.main.path(forResource: name, ofType: "qjm", inDirectory: "data") else { return false }
        return qj_load_model(raw, path)
    }

    func unloadModel() { qj_unload_model(raw) }
    var modelLoaded: Bool { qj_model_loaded(raw) }
    func flush() { qj_flush(raw) }

    /// 预乘 RGBA → CGImage。像素归 Rust、下次渲染前有效，所以这里拷一份。
    private static func image(from b: QjBitmap) -> UIImage? {
        let count = Int(b.width * b.height * 4)
        guard let pixels = b.pixels, count > 0 else { return nil }
        let data = Data(bytes: pixels, count: count)
        guard let provider = CGDataProvider(data: data as CFData),
              let cg = CGImage(width: Int(b.width), height: Int(b.height), bitsPerComponent: 8, bitsPerPixel: 32,
                               bytesPerRow: Int(b.width) * 4, space: CGColorSpaceCreateDeviceRGB(),
                               bitmapInfo: [.byteOrder32Big, CGBitmapInfo(rawValue: CGImageAlphaInfo.premultipliedLast.rawValue)],
                               provider: provider, decode: nil, shouldInterpolate: false, intent: .defaultIntent)
        else { return nil }
        return UIImage(cgImage: cg, scale: CGFloat(b.scale), orientation: .up)
    }
}
```

```swift
//  内存足迹：phys_footprint 是 jetsam 用的那个数；os_proc_available_memory 是离上限还有多少。
import Foundation

enum MemoryProbe {
    static var footprintMB: Double {
        var info = task_vm_info_data_t()
        var count = mach_msg_type_number_t(MemoryLayout<task_vm_info_data_t>.size / MemoryLayout<natural_t>.size)
        let result = withUnsafeMutablePointer(to: &info) {
            $0.withMemoryRebound(to: integer_t.self, capacity: Int(count)) {
                task_info(mach_task_self_, task_flavor_t(TASK_VM_INFO), $0, &count)
            }
        }
        guard result == KERN_SUCCESS else { return -1 }
        return Double(info.phys_footprint) / 1_048_576
    }

    static var availableMB: Double {
        Double(os_proc_available_memory()) / 1_048_576
    }

    static var summary: String {
        String(format: "足迹 %.1f MB · 剩余 %.1f MB", footprintMB, availableMB)
    }
}
```

```swift
        keys.onDebug = { [weak self] in self?.showDebug() }
        bar.onSelect = { [weak self] index in
            guard let self, let engine = self.engine else { return }
            self.apply(engine.select(index), engine: engine)
        }
    }

    override func viewWillDisappear(_ animated: Bool) {
        super.viewWillDisappear(animated)
        engine?.flush()
    }

    private func handle(_ kind: KeyKind, _ ch: Character?) {
        guard let engine else {
            // Engine 建不起来时退化成直接敲字母，至少能看出键盘活着
            if let ch { textDocumentProxy.insertText(String(ch)) }
            return
        }
        apply(engine.key(kind, ch), engine: engine, kind: kind, ch: ch)
    }

    private func apply(_ outcome: Outcome, engine: Engine, kind: KeyKind? = nil, ch: Character? = nil) {
        switch outcome {
        case .consumed:
            break
        case .commit:
            textDocumentProxy.insertText(engine.takeCommit())
        case .passthrough:
            switch kind {
            case .backspace: textDocumentProxy.deleteBackward()
            case .space: textDocumentProxy.insertText(" ")
            case .return: textDocumentProxy.insertText("\n")
            case .char: if let ch { textDocumentProxy.insertText(String(ch)) }
            default: break
            }
        }
        bar.reload(from: engine, scale: view.window?.screen.scale ?? 3)
    }

    private func showDebug() {
        #if DEBUG
        guard let engine, !view.subviews.contains(where: { $0 is DebugPanel }) else { return }

        panel.translatesAutoresizingMaskIntoConstraints = false

            panel.leadingAnchor.constraint(equalTo: view.leadingAnchor),
            panel.trailingAnchor.constraint(equalTo: view.trailingAnchor),
        ])
        #endif
    }
```
